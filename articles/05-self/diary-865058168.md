# 从愚痴到痛苦的旅程

主题：自我、情绪与人际关系

页120-121：“我们可以肯定地说，完美的贞洁就像完美的爱一样，单靠人的努力无法达到。你必须寻求上帝的帮助，甚至在你寻求之后，有很长一段时间你也可能觉得上帝没有给你帮助，或者给你的帮助不够。没有关系。每次失败之后都去祈求上帝的宽恕，振作起来，重新尝试。上帝一开始帮助我们获得的往往不是美德本身，而是这种不断去尝试的力量。……这个过程打破了我们对自己的幻想，教导我们要依靠上帝。一方面，我们认识到，即使在我们最完美的时候，我们也无法依靠自己；另一方面，即使在最不完美的时候，我们也不必绝望，因为我们的失败得到了宽恕。唯一致命的是，干一切事情都满足于不完美，不再继续努力。”

一个人是否适合宗教信仰，很大程度上来自基因。出生在宗教氛围浓厚的家庭或者社会，可能让他不由自主地接受了宗教信仰，成为有宗教信仰的人，但他信仰的虔敬程度，还是有很大程度是天生的。阿难和提婆达多出生在同样的家庭，是亲兄弟，但他们所适合的宗教信仰决然不同。阿难是个适合用一生的大部分时间给别人做侍者的，但提婆达多不适合。虽然说他们的染色体都来自同样的男人和女人。就我个人看来，劝说别人信教未必是明智之举，因为别人真的不像自己那么需要。佛教里有个表述叫“种性”，一个人如果是某个种性，他自然而然就会显露某些方面的倾向。倾向不一定能够萌芽、生长，这些有很大的偶然性。但如果不是这个种性，暂时是没办法的。这里的暂时，通常至少是一辈子。也就是说，起码这辈子，他是很难改变的。尤其是做出你想要的改变。包括你自己，寄希望于自己这辈子做出什么改变，改变成气质完全不同的人，很多时候也只是妄想。

“干一切事情都满足于不完美”，究竟致不致命？是否满足于不完美，很大程度上是镌刻在基因上的。这是人和人天生性格的差别。总体上看，追求完美的人更容易痛苦。但这不是他自己所能改变的。因为他生下来就这样了。当然，后天的学习和调教，如果方向正确，有望帮助他缓解追求完美的倾向，但难以连根拔除。在承受了种种挫败之后，他更容易倾向从宗教中寻求帮助。有两种人容易有幻想，容易生活在幻想中，一种是愚痴的人，一种是追求完美的人。但这两种人实际上是一种，追求完美本身就是愚痴。完美在世间是绝无可能的。

当转向上帝或者佛菩萨的庇佑之后，追求完美的人会暂时谦卑下来。注意，往往只是暂时的谦卑。也就是说，他的骄傲并没有连根拔除，只是在痛苦和挫败的面前，丧失了发作的机缘。当他面对现实的挫败，看清了自己的无能之后，内心深处仍然不愿意放弃幻想，于是内心深处不能放弃的幻想就人格化为神明。神明一方面离自己很近，因为一刻也不曾离开自己的内心；另一方面离自己很远，因为幻想总是在彼岸而不在此岸。佛经中说，忆佛念佛，必定见佛。因为忆念而必定见到的佛，就是永恒驻留在自己内心同时又在彼岸世界而不在现实的。

在这样的神明面前，一个因幻想而挫败，虽挫败而不能放弃幻想的人，也会谦卑下来，正视自身在现实中的无能。一旦正视这种无能，接受现实的瑕疵，就足以得到安慰，平缓拧巴的痛苦。而这个世界上，原本就有另外一种人，他们的生活很少拧巴，他们平实而切近，较少幻想，天生容易与生活和解，因此也就没有那么迫切地需要内心神明的照耀。也就是说，在他们自己看来，也能没有那么需要上帝和佛菩萨的帮助。但是，在需要的宗教徒看来，他们太需要帮助了，太可怜了。

佛教刻画了一批生活安逸的人，他们居住在北俱卢洲。出生地成为他们解脱的严重障碍。因为他们不太了解什么叫苦。这类似路易斯表达的“致命”。只是对他们而言，完全不觉得这有什么致命。他们生活得很好，完全没有紧绷的态度。他们可能不是那么明智和锐利，却也不坏，没什么恶行，对自己和周围人都很好。

北俱卢洲的障碍，有时候甚至让我觉得，是南阎浮提洲人的自我安慰。世间的确充满了苦，但有些人比其他人更苦。世间的确不完美，但有些人的生活只是小有瑕疵，而另一些人的生活碎得稀烂。面对碎得稀烂的生活，你能怎么办？最常见的安慰是，从稀烂中看出好来。比如：阎浮提洲最苦，但阎浮提洲的人可能觉悟、有望成佛，所以阎浮提洲比北俱芦洲，比色无色界都好。

色界无色界没有痛苦的感受，因此，生在那里的人没有办法见道，也就是迈出觉悟的第一步。我们固然把色无色界也称为苦，但那种苦不是身体的痛苦，也不是精神的担忧；而是美好不能永续的苦。那种苦更类似于沉闷或者不寂静。就像优渥的人在明净的下午无所事事，这种苦和欲界众生身体的痛苦完全不可同日而语。

完美的事物，在有瑕疵的世间无法获得。所以路易斯说，你必须寻求上帝的帮助。问题是：寻求上帝的帮助就能让你获得吗？实际上还是获得不了。所以路易斯接下来说：甚至在你寻求之后，有很长一段时间你也可能觉得上帝没有给你帮助，或者给你的帮助不够。的确如此。但这时候，你就很容易告诉自己：这是我对上帝的寻求还不够。你知道上帝没有理由无条件地满足你的一切。但如果没有上帝，你固执地认为一切完美要靠自己的无限努力去获得，就会不断地头撞南墙。当看见上帝显现在南墙上，一个人就愿意停止头撞南墙的愚蠢行为了。那么，这时候他有必要去批评那些一开始就没有头撞南墙的人吗？有资格认为那些人的满足于不完美是致命的缺陷？

身为并不典型的佛教徒，我很多时候讨厌宗教徒包括佛教徒身上散发的气息。比如面对不认识的人，上来称呼对方“师兄”，自称“末学”，随后用貌似谦卑的话给出对别人的指导和纠正，并把自己的行为看成慈悲和同情。

南阎浮提的苦所暗示的解脱，是痛苦中无从遁逃的人的自我安慰。但这安慰有时候竟然成了炫耀的资本。就像一个因贫困而吃低保的人，以吃低保为荣，叹息别人无法吃到低保，对别人流露出极大的同情和惋惜。宗教徒如果做到这个份上，可以说太失败了。自以为在慈悲度人，殊不知浑身散发出恶心的酸腐，让别人连同对宗教本身也丧失了好感。

大乘佛教讲：佛法在世间，不离世间觉。世间是庸俗的、势利的。庙宇金碧辉煌，是道场的法相庄严，还是世间的庸俗势利？都是。如果世间不是庸俗势利，庙宇不一定要金碧辉煌，佛像不一定要塑成金身。但恢弘的殿宇显然比破败的小庙对大多数人更有感染力。如果不是世人势利，净土也就不必金沙布地、七宝庄严了。

在充满瑕疵的世间，任何看起来美好的东西都藏污纳垢。世人艳羡的高端中藏着低级庸俗，世人以为的清净之地喧嚣骚动，世人竞相追逐的奢华可厌可鄙。这就是苦谛，是佛陀教导的真相，是真相中最重要的部分。

不过，在低级庸俗中，也隐匿着并非庸俗之物。在喧嚣中，也含藏着寂静。在可厌可鄙中，也潜伏着希有的美德。这是大乘佛教所揭示的。

但大乘佛教的揭示，是必定以看见世间的可厌可鄙为前提的。有两个天女，黑耳和吉祥，黑耳令人厌恶，吉祥令人欢喜。她们总是在一起的。但人们往往不能同时看见二者。

路易斯说，即使在我们最完美的时候，我们也无法依靠自己。佛教则认为，世间根本就没有完美的时候。我们只有在幻想的时候，才误以为自己最完美，越是觉得自己完美，就越深地沉溺在幻想里。一旦迈出幻想，完美的错觉就会碎成一地。这时候你就不由不谦卑下来，开始祷告，祈求上帝的宽恕，或者佛菩萨的庇佑。

一个人越是痛苦绝望的时候，越接近真实，那也正是他开始寻求或者重新寻求庇佑的时候，是骄傲暂时隐没谦卑暂时生起的时候。当一个人感到幸福并充满希望的时候，他就远离真实，寻求庇佑的心也就变得寡淡，于是谦卑隐没骄傲生起，又一次奔赴从愚痴到痛苦的旅程。
