# 迅速识别敌人

法喜尊者发来一篇文章，读完，我对其中圣喜长老的故事印象深刻。咂摸了三天，觉得还是来聊聊。

圣喜长老曾收到一个供养的包裹，打开，里面是个多功能手电筒，很好用，他有点高兴。随即，他意识到自己生起了贪心，并“为自己的出家生活感到悲伤”，就把包裹连同手电筒转手供养给别人了。从那以后，他再得到什么供养，都不打开，直接转手送出去。因为他觉得这次是由于打开包裹引起的麻烦。

我在意的有三点。不按顺序说。

第一点是，平常经常有人说，“你要去历练”，“要去看世界”，同样的意思放在这儿：“没看包裹不起贪算什么？有本事你把所有包裹都打开，都看看，还能不起贪，才叫本事嘛！”

吹牛的人常这么说。谁要觉得有道理，听信了，就完了。

修行不是这次第。就像头一次去健身房的人，见别人举起很重的杠铃，也想试试，一试，很沉，心里想：我就不信我举不起来！使劲儿，果然举起来了，很高兴：人家练了半年，我第一次就举动了。结果回到家，过了三天腿还疼。

我们对贪欲的抵抗力，在未经训练的情况下，不可能有很高的水平。就像对抗病毒，体内有抗体和没抗体，不是一样的概念。所谓靠意志力战胜病毒，那是玄学；而靠抗体战胜病毒，是科学。

单纯说“抵抗力”，是很空泛的概念；但测定出的抗体水平，就是实在的指标。我们对贪欲的抵抗力也类似。每个人对不同品类、不同程度的诱惑，也有着不同的抵抗水准。要让一个正常人保持健康，一般来说应该尽量远离有病毒的、污染的环境——有少量病毒，一般人的免疫系统能扛得住也可以，因为完全清洁的环境太罕见了。但谁要是说，“让一个人去锻炼锻炼”，把他放到充满各种病毒的实验室，“炼”他的免疫系统，他就废了，不可能扛住的。《西游记》里孙悟空在太上老君炼丹炉里炼，那是小说，孙悟空是石猴，成份是二氧化硅，我们去炼，就成火化了。

圣喜长老这种“看都不去看”的做法，是“都摄六根”。就像我们防范病毒，正确的做法是戴好口罩，在危险环境中甚至要穿上防护服，戴上护目镜。——都摄六根不就是这样吗？防止病毒——贪从各个缝隙侵入。修行的起初，要“具身心远离，无不足大欲”，身心的远离是非常重要的。

第二点，是正念正知。

过去有句话，“不怕念起，只怕觉迟”，禅宗祖师常用这句话来提撕自己，但这不是禅宗特有的手段。这是佛陀说的“正念正知”。用今天的话说，要迅速认清敌人。

“谁是我们的敌人，谁是我们的朋友，这是革命的首要问题。”从这个故事里了解到，圣喜长老，在他对手电筒起贪的那一刻，不是断掉了欲贪的人。或者他之前始终没有断掉欲贪，或者是他在看到手电筒后，欲贪又生起了——由此我们能知道，他在那时候并没有成就禅定（欲贪和禅定是不能同时成就的）。换句话说，圣喜长老和我们很接近，也是个普通人，并不是拥有禅定、神通的人。

但同时，圣喜长老又和我们很不一样，他非常不普通，因为他几乎在第一时间意识到自己生起了欲贪。——其实，修行和不修行、修行好和不好的差别，关键就在这里，不是在有没有禅定和神通，也不是在证得的是初果还是四果。

很多人喜欢鼓吹禅定和神通，着迷于种种天花乱坠的传说，而佛陀的教导，真正重要的地方，是正念正知。正念正知就体现在：你能不能在最短的时间里发现敌人，然后用最短的时间打一场漂亮的阻击战。

我们在碰到好东西的时候，不会那么迅速地留意到自己的欲贪生起了。会想：“真不错！确实是好东西！”

当接触的对象引起了我们的兴趣，我们喜欢研究它、把玩它、琢磨它、分析它、思考它——面向对象的分析思考，常常被认为是理性的态度。但理性的成立，有个前提：你的立场是否客观？你的态度是否中立？你本人是否利益相关？

换句话说，情绪有没有渗透到你的思考中，左右你的判断？因此，清醒理智的思考，首先还不是问所接触的对象是什么、好不好，而是问：我在接触它的时候，生起的情绪是怎样的？

实际上，对感兴趣的东西把玩、琢磨，这看似“理智”的研究中，情绪在一层层地渗透，缘它的贪在持续滋长。阿毗达磨叫“所缘随增”。生起的贪在不知不觉中，超过了自己所能抵抗的限度。一个爱好赌博的人、喝酒的人、对什么事情产生瘾的人，其实，在最早，瘾不强的时候，都是有望扛得住的，像兵法说的“十则围之，五则攻之”，贪刚刚滋生苗头，一般都有望把它摁下去。但它滋长的速度非常快，而我们又不能及时留意，等过患明显的时候，形势已经成了贪的力量强、自己的抵抗弱了。逃是不好逃的，因为贪往往是伴随着舒服的感受生起的，让人留恋缠绵。

因此，检验修行好坏的标准，主要是看能否在第一时间识别敌人，并采取正确的应对。

谁是敌人？在这个故事里，是手电筒吗？

不是手电筒。是贪瞋慢。贪瞋慢，是要沿着境界爬上来的。就像过去攻城，如果城门紧闭，只能靠爬城墙。因此，面对境界，首先不是问境界是什么，而是问境界对自己产生了什么效果？具体来说：

在这件事情上，我有没有生起贪？

在这件事情上，我有没有生起瞋？

在这件事情上，我有没有生起慢？

不是问自己有没有断掉贪瞋慢——在未曾用功的情况下，贪瞋慢一定是没有断掉的。就像一篇古文，你从来没背过，肯定不会背。只有下过功夫背过，才有可能会背。没有打过某种疫苗，也没有感染过，绝不可能自然就有抗体。

“断烦恼”，对我们来说太难了。所以，问的是“是否生起”。

如果再往前倒推一步，就到“感受”层面了。

一样事物，如果给我们的感受是“好”，就会生起贪。越是“好”，贪的程度就越强。

如果给我们的感受是“不好”呢？——这里需要稍作区分，我们对一样事物的评价是“不好”，和它给我们带来的感受是“不好”，不大一样。带来的感受不好，也就是说它让我不舒服了，那么，随着不舒服的程度，会生起相应的瞋。但评价是“不好”，还要看我们和这事物的关系，如果把事物看成“我的”，就会引起感受的“不好”；否则，就不一定，如果把事物看成是“与我对立一方的”，甚至会引起感受的“好”。就像有人看别人跌了一跤，哈哈大笑，第一名看第二名比自己差了很多分，差的分越多，他越高兴。

如果事物和他人有关，而评价为“不好”，容易引起“慢”。——觉得别人比自己菜。不好是属于别人的，更衬出了自己的好。

因此，如果不是碰到中舍的境界，“贪、瞋、慢”就非常容易滋生。

痴呢？——在生起贪瞋慢的一切过程中，都包含着痴。

第三点，当我认出敌人——生起的贪瞋慢之后，应该如何应对？

圣喜长老的做法是，把手电筒送给别人，而且决定以后再也不打开任何供养的包裹。

我们很容易采取另一种思路：我已经意识到生起的贪，也为此惭愧了，但不管怎么说，别人把手电筒送给我，而我日常生活中确实需要这么一把手电筒，它能减少我的麻烦，带来很多便利，为什么不留下用呢，只是在使用过程中，更留意由它引生的贪不就好了吗？

乍听，似乎也有道理。——能让生活更便利的工具，为什么不使用？

但这，很可能是一种自欺。如果你真的接受了，你会不断体验到它的便利，心底会隐隐觉得“还是值得的”。也就是说，你会把接受这次供养看作至少是一个“不好不坏”的事情，起码不是坏事。这样想的时候，其实已经把它看成好事了。那么，贪就不仅是、不再是沿着手电筒这条藤爬上来，而是沿着“供养的包裹”这条更大的藤爬上来。——这比手电筒本身还要可怕得多。

我常想到学诚法师的事情。也听到过一些“只坐头等舱”之类的传闻，不知真假。有个故事，说佛陀和阿难走在地里，佛陀看到了什么，说：毒蛇。阿难也看到了，说：毒蛇。两个人就这么走过去了。

他们看到了什么？金子。

他们很清楚那丢在路边的一小块东西意味着什么、会带来什么。并不像“万花丛中过，片叶不沾身”“酒肉穿肠过，佛祖心中留”之类段子里塑造的洒脱不羁又自在的形象。他们很谨严，很慎重。

如果接受这包裹，你会期待下一个包裹、更好的包裹。下次比这还好，你会有点高兴。没有这次好，可能会有淡淡的失落。那么，无论来什么包裹，乃至不来包裹，都会成为烦恼攀爬的蔓藤。

而一旦铁心做了决断：今后无论收到什么包裹，都不打开、不经手，直接供养出去，那么，除非自坏誓言，烦恼不可能再顺着这条藤爬上来了。

这是勇敢、明智的决断。

我们经常说“无我”“无我”，但所吃的每一口饭，好吃还是不好吃，到嘴里的味道总有差别。

“对这包裹作无我观，不取著它，给什么就接受什么，不给也不希求，既不取著，也不排斥，不很好吗？”

——那是大话。一个人越是了解自己的程度，就越不敢轻易说那样的话。如果所有包裹都看都不看转手供养给别人，那就是“事上”的无我观——你就是不作无我观，包裹也是“非我”的：你不是给人家了吗？当然不是自己的。否则，哪怕给之前看上一眼，都还不算彻底。实际上，即使觉得自己不贪著包裹的内容，我们也很可能会盘算一下什么样的包裹给谁合适，如果是食物的话，可能要看看保质期，以免送到别人手里已经过期了，甚至会考虑假如送出的东西太廉价，而收到的人地位尊贵，会不会有些不相称之类的问题，一旦这样想，就不是“非我”了。

不妨换个角度考虑：假如我是菜鸟驿站的快递员，每天分发别人的包裹，会不会有这些顾虑？

快递员每天收发包裹，但不会对包裹起贪：你不打开包裹，也不知道里面是什么，但很清楚，里面不管是什么，都不是我的，唯一可能是我的的，是外包装，如果人家当场拆开，没准儿扔掉的纸箱还能再次利用或者卖废品。所以，真能对包裹起“非我”想，就会连看一眼的兴趣都没有。

大千世界那么多东西，都不是我的。为之起贪起瞋，值得吗？
