# 说一切都是为你好，是骗你

主题：自我、情绪与人际关系

睡前看视频。有位结婚五年的妻子，坚信丈夫爱自己，某机构就对她丈夫做了个钓鱼实验，派一位身材曼妙的姑娘去搭讪。妻子通过远程监控观看。
姑娘装作问路，走进丈夫的杂货店。丈夫指完路，姑娘说，其实我不是要问路啦，我是想跟你搭讪，你好帅。丈夫笑。姑娘问，我漂亮吗？丈夫说，当然。姑娘说，要不，咱们约？丈夫说，好啊。
监控室里的妻子，脸上露出愤怒。姑娘问，你有女朋友吗？男人犹豫了一下，伸出戴婚戒的手。妻子舒了口气，嘴角上扬，露出微微笑意。姑娘又说，噢，原来你结婚了，那你还愿意跟我约吗？男人说，当然。妻子脸色煞白，骂道：婊子！
姑娘问，你妻子介意吗？男人说，不会，我的意思是，不会让她知道。姑娘说，你是说，你老婆不在的时候就能约？男人说，没错，我老婆现在就在出差。姑娘说，那太好了，我今晚就能约你？男人说，是的。姑娘问：你家有避孕套吗？男人说，当然。监控室里的妻子已经抑制不住大哭，边哭边骂：该死的婊子！
当天下午，她丈夫果然拨了姑娘的号码。
视频到这里就结束了。十有八九，那位哭得一塌糊涂的妻子，不会离婚。她可能会把视频摔到丈夫面前，逼他发誓，下不为例，再给他一些惩罚，通过惩罚来说服自己，他还是爱我的。然后把这件事情藏起来，当作从未发生。
这并非出于宽容和谅解，而是出于懦弱和欲望。
这个女人的过失，比男人大。
她从头到尾，都没骂过丈夫一句，却一直骂做实验的姑娘：死婊子。
别人没有任何错。
有一种观念很难建立起来，听起来是严重的政治不正确，但那是问题的要害：如果你的伴侣被第三者勾引走了，是伴侣的错，还是第三者的错？
都不是，是你的错。
对妻子来说，那种丈夫是不能要的。但你放心，她一定舍不得她的丈夫，哪怕他出轨。所以，她从头到尾只骂别的女人是婊子。
在大学校园里，我亲眼见过男生劈腿，女朋友在路上堵住小三打，男朋友护小三。女生一边哭，一边要砍小三，不砍男朋友。
不是她的错，还是谁的错？
她被那个男的吃定了。吃定了，就毫无吸引力了。你让自己对伴侣没有吸引力，不是你的错，是谁的错？自己不能保证永远有吸引力，至少可以保证离开他吧？
正确的做法是什么？看到视频，二话不说，起身，回家，离婚。
但她铁定做不到。为什么人的眼里容得下沙子？因为克服不了自己的欲望。
想要一样东西，舍不得，就会被牢牢套死。
注意，当丈夫向钓他的姑娘露出婚戒时，妻子愤怒的脸突然舒展，露出自负的微笑。这一笑正是她最可怜的地方。
丈夫是什么样的人，并不因为这场实验而改变。如果你的情绪只是因为了解到真相而崩溃，错误一定在你。
很多人因为不敢面对真相，所以看不到真相。
女人如果肯直面真相，一开始就不会和男人结婚。那样，也许只能找个又丑又穷，完全不解风情的人嫁掉。
男人也一样，如果他知道面前火辣的姑娘是来钓他的，一定非常生气。可惜他不知道。
但凡动动脑筋，想想自己这样一个猥琐大叔，怎么可能有十分漂亮的姑娘在毫无缘由的情况下投怀送抱，就能识破骗局。
男人之所以出示婚戒，并不代表对妻子忠贞，而是想省却麻烦。这是个逆向筛选机制。他想白捡便宜，让姑娘跟他睡觉但不因为他隐瞒了婚姻而大闹。——他妻子误解了这点，所以才露出自负的笑。
很多难以承受的痛苦，源于不敢接受真相，又在不经意间看见了真相。
一事无成的人，爱听别人说他有本事，他急切需要这种声音。这个看杂货店的男人，急切需要一位身材曼妙的姑娘投怀送抱，藉此证明自己的魅力。
屌丝永远相信自己会被女神垂青。这正是他们之所以成为屌丝的缘故。——他们唯一能证明自己不是屌丝的手段，就是女神的垂青。
但凡属于自己的，都是自己应得的；但凡不是应得的，都不会属于自己。
女人的愤怒，不是丈夫的背叛，不是自己不能掌控丈夫的心，而是不能控制自己的欲望。她想要的一切，都要靠丈夫赐予。但是，别人赐予的，终究不是你的。
因为愤怒而骂“我真是瞎了眼”的时候，是最接近真相的时候。真相就是自己瞎了眼。但骂归骂，骂完还是不信自己瞎了眼。
街头常有“重金求子”的广告。有年轻的少妇陪你睡觉，还倒贴你一大笔钱，这种骗局永远有人相信。这和电信诈骗还不一样，骗局有技术驱动的，有信息驱动的，有欲望驱动的。“重金求子”，就是纯粹的欲望驱动的骗局，在这种骗局里上当，只能说活该。
如果你碰到一件事情完完全全都是对你有利，你应该想：这件事对别人有什么利？这么好的事，凭什么落到我头上？如果听到别人讲一句话：我都是为了你好。他铁定是在骗你。
讲这句话，会造很大的业，甚至只是想想都会造很大的业，因为它完全颠倒了真相。
一个大叔手把手教小姑娘，可能是完全为她好？如果只是为了让小姑娘替自己干活，那就谢天谢地了。中年谢顶的男人为什么爱对小姑娘实习生讲为人处事的道理，他怎么不上大街上摆摊儿给过路的人讲为人处事的道理呢？
一个男生追姑娘，给她送花、送手机、刮风下雨接送得无微不至，要说完全是为姑娘好，那是鬼扯。如果一个人对另一个人好到变态的地步，他肯定是变态。
菩萨度有情众生，从来不讲“我是为了众生好”，想都不那么想。实际上，菩萨之所以度众生，全是为了自己好。
菩萨在无明住地的一切烦恼，都来自众生，度众生是菩萨断烦恼的需要。为了自己断烦恼，才去度你。菩萨意思是“觉有情”，觉有情、度众生、断烦恼、证菩提，四个词指的完完全全是一件事。众生和烦恼，是同义词，度和断，是同义词。自利和利他是一件事，自觉和觉他是一件事。通过利益众生，来利益自己，这是消除自他对立的过程，也是破所知障的过程。菩萨心里很清楚：我所做的一切，归根结底，全是为了我自己。
我关心你，照顾你，为你担忧挂念，本质上，都是为了自己好。跟别人讲，“我都是为了你好”，是欺人；自己这么想，是自欺。
要相信，别人为你所做的一切，都是为了他自己。这样就不会轻易被人感动，也不会轻易对人失望。我接受你的关心，是对你的恩赐，赐给你爱别人的机会，我拒绝你的关心，是对你的呵护，让你免于陷入情感的执着。
同时，要相信，自己为别人所做的一切，也都是为了自己。我去关怀人，是恳求他给我学习爱的机会，我去帮助人，是请他给我积攒福德的机会。这样就不会对外物抱有期待，也不会对生活失望。
凤凰新闻客户端主笔 王路
