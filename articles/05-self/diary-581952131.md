# 请照顾一个人最后的体面

演员乔任梁昨晚去世，先是小道消息爆出死于SM，性虐待，流言在朋友圈和微博发酵一两小时后，又出现了澄清的说法，说是抑郁症自杀。
假如最初传出来的消息就是抑郁症自杀的话，不会有那么多人兴致勃勃地发朋友圈——真的是兴致勃勃，仿佛在看一场好戏，用“你们城里人就是会玩儿”、“这次玩大发了吧”的口吻。
他们在转死于SM的传言时是带着亢奋的。那种亢奋劲儿和过去围观群众看见杀人犯强奸犯游街示众时的情绪没有什么区别。
过去当众召开的宣判大会和游街示众是很糟糕的东西。它打着警示世人的幌子，其实是在刺激世人，让世人通过咂摸别人的罪行来抚慰自己犯罪的冲动。
在朋友圈转流言的人，十之八九，对SM的兴趣比对乔任梁更大。
人固有一死，或死于真相，或死于流言。或死于抑郁，或死于性虐。身为名人，在现代社会，你没有办法静悄悄地死。
何止名人，就连普通老百姓，也没有办法阻止死后蜂起的议论，无论它是真是假。真假已经不再重要，就算是流言，营造出来的情绪也会真实地落到每个人心里，今后别人想起这个人，就会记得这则传言。
从小听过很多类似的事。比如说某个老汉，在乡下赁了一间屋子，和某个女人同居，每天都发生性关系。有一天，正在做的时候，心脏病发作，赶紧推了三轮要往医院拉，刚上三轮就不行了。
很少人知道那个老汉是谁，但那些故事，数不胜数。添油加醋，绘声绘色，精确到每一处细节，就像事发现场有摄像头把一切都记录了下来，甚至还是全方位多角度地记录。没有人管传言怎么来的，但很多人津津乐道。
为什么传呢？也许有种嫉妒和复仇的快意：你一个六十多的老汉还能享受夜夜声色犬马的生活，我们都享受不到啊！死了活该。
像乔任梁这样的人，难免不被嫉妒。年少成名，颜值爆表，坐拥一大堆女粉丝。对乔任梁来讲，或许只是工作所致。但在外人看来，就是过人的艳福。很多人不喜欢看到别人有艳福，在别人的艳福之下会照出自己的穷矬。这大概也是为什么SM致死这种传言更容易发生在乔任梁身上。很多人诅咒他们嫉妒的对象，乐于看见别人拥有而自己不能拥有的东西毁灭掉，并从围观这种毁灭中得到快意。
每一个热衷传播这些故事的人，在大嚼细节的时候，一定来不及想象自己和亲人也有死亡的时候，他们离开这个世界时究竟以怎样的方式，也不得而知。
没有人能保证自己死得体面。更没有人能保证自己的死在别人的流言里体面。唯一可以明确的是，在一个有教养的、文明的环境里，人们愿意用最大的善意来对待每个人的离开，让他们的亲属、朋友、周围的人得到安慰。
越是落后的地方，愚昧的地方，五浊盛行的地方，讥讽诟病的声音越多过安慰惋惜的声音。过去的乡下，如果两家有嫌隙，经常听到这样的话：等哪天某某死了，我要摆大酒、演电影。
居住在那种环境里是没有安全感的，你不知道哪天会有谁为一些鸡毛蒜皮的小事跟你产生纠纷，大打出手。你种一棵树，离他宅基地近了一点，他就诅咒你不得好死。你家洗衣服的水，倒在院子里，流过他家屋后，他就要骂你断子绝孙。
这种心，并不因为人们从乡下搬到城市而有本质的改变。很多自称逼格高的网站——其实，仅仅是流行逼格一词，逼格就已经低了——评论区里充斥的谩骂、侮辱，毫无理由的地域歧视，人身攻击，就可以见出环境的糟糕。
几个月前，有一位企业家在景区游览，碰到猴子蹬落山上石块，砸中脑袋，不治身亡。这条新闻被广泛传播，某门户网站甚至把标题拟为“某董事长被猴子弄死”。后来，由于被谴责对生命缺乏基本的尊重，该网站公开道歉。但要知道，那家网站是一向很懂得什么标题易于传播的网站。也就是说，他们之所以做这种标题，除了编辑的个人趣味之外，更多是屈于KPI的考量。他们的职业经验让他们判断出，“被猴子弄死”这种标题一定是大多数读者喜闻乐见，容易分享的。
在恶劣的环境下，人们喜欢把别人逼良为娼，再骂她是婊子，从而得到道德上的优越感。
乔任梁到底是怎么死的，已经不太重要。朋友圈和微博风靡的迹象已经透露出消息：大众期望看到一个当红小生因SM而死，这是一道够味的下酒菜，满足大家的食欲。
这是很悲哀的。任何一个生命的逝去，都有可能被别人当成笑话看。要说活得不好，辛辛苦苦挣钱，被人当成笑话看就算了，死了还要继续被人当成笑话看。
不过，真正的不体面并非属于乔任梁，而属于那些期待看见乔任梁不体面的人。他们对着一面镜子，痛骂镜子里的人丑，想通过诋毁他人丑来衬出自己美，而不知镜子里的人就是自己。
对于死去的人，别人怎么看待他已经不再重要。毕竟他的身躯将要化作尘土灰烬，在这个世界上烟消云散了。但他留给这个世界的记忆还在。但凡对他有记忆的人，他的亲属、朋友、关心他的人，都还活着。他们的生活依然要受那些看法和议论的影响。那些纷起的议论是一面镜子，照出我们所在的世界，是洁净的世界，还是污浊的世界，是充满温情慰藉的世界，还是充满冷漠讥讽的世界。
凤凰新闻客户端主笔 王路
