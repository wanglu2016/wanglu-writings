# 分手后希望对方过得怎么样？

[文集首页](../../README.md) · [本类目录](../../catalog/05-self.md)

作者／署名：王路  
主题：自我、情绪与人际关系  
页面时间：2017-11-14 14:36:25

很多人分手之后，希望对方过得不如以前好。女生的前男友又找了新女友，她会在意那人是不是比自己漂亮，如果人家很平庸，她就好受些。男生分手后，如果女生的新男友比他富有、英俊、出色，他就会有点失落。

其实，既然已经分手，别人再找什么样的对象，是别人的生活，好也好，坏也好，都跟自己没关系。那为什么偏偏希望别人碰见的下一个人不如自己呢？

他们希望对方后悔。在对方的后悔中，他们感到自己很重要。他们宁愿对方过得不好，宁愿对方并不幸福，以此来确认自己的重要性。

对一个曾经有过恩情的人，这样期待真的好吗？

其实，无论你怎样期待，期待对方更幸福，还是更不幸福，都只是自己的一厢情愿。对方往后的生活，是她自己选择的，你已经无权参与。不过，你的期待，会影响到你自己的心，你希望别人离开你后过得不好，自己的心就会越来越染污。

不仅谈恋爱如此，共事上，也是一样。很多人，看见别人选择了一条他不认可的道路，内心是希望别人翻船的。别人翻船了，他就很高兴：看，我说对了吧，我早就说过，他这样根本行不通，他不听，现在好了吧？

这样的人，把自己看得很重，把别人看得很轻，慢慢地，越来越难遇到能和自己相处很好的人，尊重自己的人。因为他从根本上，并不尊重别人。

昨天，有读者问，现在谈的男朋友很不好，怎样才能和平分手？我说，比较安全的办法是，让他觉得你很差，主动和你分手。

这个做起来很难。几乎所有人，都不愿别人觉得自己差。无论你接下来要继续和他相处，还是再也不来往，都不希望自己在他心中，是个废材。

不过，别人把自己看成废材，并没有什么不好。只要自己内心清楚，自己并不是废材，而且完全有力量支撑生活的时候，让某些人觉得你是废材，并不坏。这样，那些人就不会来骚扰你，不会想从你这儿觊觎些什么。要是人人都觉得你本事很大，天天一大堆人来找你，认识的，不认识的，都要应付，你还能有多少时间为自己而活呢？

但是，人们对于自我很执著。总是希望，越多的人觉得自己有本事越好。能乐于接受自己在别人眼中是废材的人，并不多。

有一种并不算坏的分手方式，但很多人觉得糟糕透了：对方劈腿并提出分手。

如果只是在谈恋爱，没有结婚，也没有孩子，自己没有什么过失，对方见异思迁，喜欢上了别人，提出分手。很多人会非常痛苦。但这其实不是坏事。第一，这表示这个人不值得相处。第二，既然是他主动提出，一般来讲，后顾之忧非常小，比你主动提出他不同意要好得多。但是，这让人很难接受，很痛苦，痛苦的原因，在于自己的价值遭到了质疑。本来是对方的过错，但因为对方的过错，开始怀疑自己不够好，比不过别人，痛苦由此产生。

很多时候，受伤害不是坏事情。已经产生的小伤害，往往给你提供了一个避免未来更大伤害的机会。如果你选择接受，更大伤害发生的因缘就消失了，再也不会出现。如果不接受，牵缠滚打，大的伤害一定会到来。最幸运的人生就是，每一次小伤害，都把潜在的大伤害避掉，生活就会如履平地。你看到有些人生活很艰难，那种艰难，不全是环境的原因，一定有他自己的选择在的。

有些人屡屡出轨，出轨之后，又苦苦哀求，请对方原谅。他的兴奋点并不止是出轨一件事情，求对方原谅是另一个兴奋点。他通过出轨，来确认自己的价值。人在从事危险行为的时候，是比从事庸常行为更紧张的。在紧张中，他体验到自己的存在感。人们不容易发现自己是渺小的、无力的这一现实，更不肯承认，可他又无法通过常规路径打破，就想靠违反道德、法律、禁忌来营造一种打破庸常的错觉。

出轨之后，请求原谅，是另一个兴奋点。他业已伤害了别人，又求对方原谅，目的是想确认对方离不开自己。如果对方真的离开了自己，他会痛苦，痛苦并不是因为失去了对方，而是因为自己的价值没能得到确认——原来别人离了我照样活，而且活得很好。一旦对方“原谅”了自己——实质上是谈不上原谅的，她由于舍不得他，而丧失了原谅的资格，不得不接受，这就会让他兴奋，因为确认了自己的意义。

实际上，没有谁离不开谁。这世间，人与人，人与物，一旦会合，终要别离。产生“自己离不开别人”、“别人离不开自己”的念头，终究是错觉，是假象。如果能相信，没有谁离不开谁，就会愈发珍惜短暂相聚的因缘。因为别离是长久的，而相聚是不易的。不了解这一点，就会不断地用伤害来彼此试探，实在太愚蠢了。

相爱是不必相杀的。只有愚蠢的相爱才会相杀。愚蠢的相爱就是，把本不属于我的，据为我之所有，对他人有要求，希望他人按照自己的意志来行事。

有人喜欢相亲。相亲常常不是好事情。尤其是自身条件好的人去相亲。相亲中，很多人最怕的是，自己看上了对方，对方没看上自己。其实这是好事情。对方没看上你，也就意味着你没有伤害对方。但因为自己的价值得不到确认，心里往往会不舒服。

如果对方看上了你，而你没看上对方。很多人都会把这视为好事。其实这并不好。这意味着，你有可能伤害了别人。也许别人很好，只是跟你不合适，但你的拒绝可能多少会让别人产生一种自己还不够好的印象，并因此而失落。

有些自身条件很好的人喜欢相亲，通过相亲，找到自信，因为绝大多数时候，别人会看上他。但这很不好。因为他的自信，是通过挫伤别人的自信甚至自尊来实现的。所以，如果下次你去相亲，别人没看上你，你不必苦恼，因为你至少没有伤害别人。

很多时候，别人喜欢你，对你有所要求，又无法满足，他就会痛苦。哪怕你什么也没做，其实已经对别人造成了伤害。当然，从根源上讲，伤害来自别人本身不够清净的心。任何人，只要对外物有要求，有期待，就是染污的心，因为外物没有必然满足你的要求的道理，别人没有必然按照你的意志来的道理。但是，把别人染污的心激发出来，你是要负一些责任的。

有人讲，女生打扮得妩媚性感，是欲界的善业。这是不恰当的。是不是善业，取决于发心，如果你打扮得体是为了表现对别人的尊重，并且你有智慧让自己的打扮和举止不误导助长别人染污的念头，这就是善业。即便别人由于自身原因产生了染污的念头，那也不是你的过错。

但如果你是为了让别人着迷，本身就希望别人迷上你，甚至渴望那些不该对你着迷的人也迷上你，那就绝对不是善业。有人喜欢讲，“我可以骚，你不能扰”，别人是不能扰，但这并不代表你怎么骚都是正义的。那不是钓鱼执法吗？

不过，很多人还是渴望迷恋自己的人越多越好，耽溺于同时跟不同的人暧昧，她通过这种举动，确认自己的价值。很多人通过影响别人的生活来确认自己的价值，而不问这种影响是积极的还是消极的，是向清净的方向去，还是向染污的方向去。

有些不一定说得上很漂亮，但是很有风致的人，别人跟她接触时，总会不经意间被她迷住，好像她身上有什么魔力似的。再加上她也说不上很漂亮，别人更加怀疑这是爱情。她耽溺于很多人对自己的迷恋中，由此发现并享受自己的魅力和机灵，但这并不是善意的发心。去考察这样的人，会发现她们后来往往要经历很大的挫败和痛苦的。如果是出于染污的心，往染污的方向去影响别人，对别人影响越大，自己最终要承担的过失就越多。

人没有办法让所有人都迷恋自己，也不应该渴望这样。所有人都迷恋你，除非你是人民币。

我们常说好人坏人，实际上，人是没有好坏之分的，只有好的行为，坏的行为。有些人，虽然大多数时候很坏，但在接近某些人某些场合的时候，也会表现出恭敬心、清净心，如果他不以恭敬心、清净心前来，就没有接触清净的行为、清净的场合的机缘。

佛教常说净土。所谓净土，就是清净因缘的聚合。把不清净的因缘排除在外，就是净土。不清净的因缘聚合起来，就是秽土。

有人经常提，要拓展你的人脉。尝试了很多方法，加了很多人微信，认识了很多点头之交，发现生活还是很糟糕，依然没有赚到钱。于是换一种说法：要放弃无效的人脉。又删了很多人微信，拒绝与很多人来往。之后发现生活仍然很糟糕，依然没有赚到钱。

其实，重要之处在于，是以清净的因缘去聚集人和事，还是以染污的因缘去聚集。如果以染污的发心去聚集，只会聚集来染污的东西，只会彼此助长不善。如果以清净的发心去聚集，染污的东西慢慢就远离了。

有读者看了我的文章，骂几句，说果断取关。我并不生气。他们都走了，留下来的读者，尽管也往往与我有分歧，但仍然可以心平气和，彼此尊重地探讨。

知乎就不一样。很多人说知乎戾气重。知乎是有点这个特质。因为知乎的设定，注定它是要靠彼此攻击、互怼营造出来的社区。你要想体现自己的价值，就要在赞数上碾压别人，所以知乎上流行“怒答”、“实名反对”——答个题干嘛要怒呢？笑眯眯地答不行吗？说白了，很多时候，答题不是为了帮助别人，是为了秀自己的优越感。于是很多人被气走，隔了一段时间回来，又气走。有人在现实中很和蔼，很客气，跑到知乎，就变得摩拳擦掌，拔刀相见了。这正是因为，不同的地方，聚集人的因缘不同。

说回最早的话题，如果你和一个人分手后，能衷心祝福她过得更好，能忘掉她的不好，常常念着她的好，但又不贪求这种好属于自己的时候，她能不能过得更好不知道，但你的这种发心，一定会让自己过得更好。当你愿意别人的生活比自己好，不嫉妒别人，乐于见到别人比自己有才华，有能力，更成功的时候，你的生活是很幸福的。
