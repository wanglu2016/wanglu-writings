# 端午快乐不是事儿

2016年的端午和中秋，对我来说，和别的年份不一样。

那年端午，我收到了一堆粽子；中秋，我收到了一大堆月饼。关键是，送月饼和粽子的人，大部分我连见都没见过。其实不是个人送的，是机构送的。那是我上班的最后一年——假如这辈子不再上班的话（相当有可能）。

这说明两点：1、2016年经济还是比较景气的，不少单位还都喜欢往外送东西；2、离开了单位，我真的啥都不是了（但不后悔，不仅不后悔，还开心坏了；我上班是图那些粽子月饼吗？）——现在，碰到朋友向陌生人介绍我，还会说，王路以前在什么什么单位。别人要问我现在搞什么，我只能说，瞎搞。

“瞎搞”虽然不好听，其实还是比较好的说法——会让别人觉得你有点谦虚，而且摸不清你的底儿。但你不能说“胡搞”，虽然“瞎”和“胡”是近义词，但“瞎搞”和“胡搞”感情色彩还是不一样的。更不能说“乱搞”。“随便搞搞”倒是可以，“啥都没搞”也不赖。

扯这些没用。2016年的时候，我还经常见陌生人，一会儿被拉到这个群，一会儿被拉到那个群。现在，群差不多都退了。一年也认识不了几个陌生人。一方面说明我年纪大了，一方面说明经济不景气了。经济景气的时候，大家都像热锅上的蚂蚁，尤其在北京这种地方，三天两头认识人。经济不景气的时候，很清爽，就固定的几个朋友，定期见见。

陶渊明有句话我很喜欢，“请息交以绝游”，可惜我不喜欢搞斋号——就是给自己住的地方起个名字，说是给住的地方起名字，实际上是给自己起名字，因为你起的斋号也不会到不动产中心去登记。比如叫个“息交斋”，你就是“息交翁”了——止息了交游，像商山四皓那样的世外高人。唉，这个搜狗输入法太低俗了，我打“息交斋”，它给我出来个“洗脚斋”，“洗脚翁”这名字可不行。真想叫“洗脚斋”，那也不能叫“洗脚斋”，要叫“濯缨馆”。——谐音梗确实该扣钱。还是叫“绝游堂”好点，你就是“绝游堂主人”了。

所以说，给住的地方起名字其实不是给住的地方起名字，是给自己起。我别说给自己起，连俩猫都不叫名字了现在，直接叫“俩猫”。开门回来，俩猫喵喵叫，我就说：饿了？俩猫。——一下子把俩猫都叫住，一碗水端平。

虽然我这些年越来越收不到粽子，但端午节祝福还是不绝如缕，今年也收到一两条。这一两条里，就有祝“端午安康”的。朋友圈里也是刷屏的“端午安康”。

安康不安康的，都成月经帖了。“月经帖”好像不太准确——如果一个话题，每隔一段就被拿来讨论，就会叫月帖贴。问题是没有年经，端午安不安康，是每年才讨论一下子的。别人给我发安康，我也回别人安康——无所谓嘛，安康就安康，你能祝我安康，我还不能祝你安康吗？少管闲事养精神。

我倒觉得，我知道为什么“端午安康”会占上风。——因为很多人害怕自己没文化。说“端午快乐”是啥事没有的，正常不得了，但有人看别人都安康安康的，他不敢了，还有些人是怕麻烦，像我这样的，爱安康就安康吧，又不是端午安息，怕啥。但有些人，他怕，他怕一说“端午快乐”，人家嫌他没文化，人家要教育他。关键是，他可能觉得人家的教育是有道理的，慢慢地，他就觉得，一说“端午快乐”，搞不好自己就真的没文化。他就不敢说了。

其实不是事儿。你就是说“中元节快乐”，也挺好，中元节就不能快乐吗？中元节是佛欢喜日，佛还快乐呢，我快乐一下咋了？
