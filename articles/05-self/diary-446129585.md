# 拼酒能在多大程度上体现魄力和逼格？（文/王路）

好友在通信公司干项目，昨晚打电话时说，他们头儿请某设备商的项目经理吃饭，每次一万块钱都下不来，而且不是大城市，是东北一个偏僻的三四线城市。先请吃喝，再请唱歌，然后洗浴。
甲方喝酒很有意思，找服务员要一只大海碗，两瓶啤酒倒进去，别人不动，先自己喝，让人掐秒表，15秒喝完。表走到18秒，还没喝完，这边的头儿急了，踢掐表的，掐表的不睬。等喝完，掐表的说：“真厉害！14.5秒！”满座轰然鼓掌。然后每人一只大海碗，两瓶啤酒，一气儿喝完。大多数人没这个本事，喝得领子上、前襟上、裤裆上，全是啤酒。
好友说，那帮人连古代的土匪都不如。土匪至少还讲义气，还有打家劫舍的本事，那帮人纯粹是一群乌合之众，业务上一塌糊涂，每天的生活就是上班混钱，下班喝酒。他们都是外地人，跑到三四线城市干项目，每天晚上都喝酒。先在饭店喝，饭店喝完到路边摊吃着串喝，吃完串再换个摊儿就着青菜花生米喝。酒喝多了，第二天就不想吃饭。有个人每天拎一瓶雪碧去上班，白天从来不吃东西，到了晚上，去喝酒。
喝酒于他们而言，是展现魄力的手段。你能15秒干两瓶酒，你就有魄力。干不了，你就怂。我有一回跟人吃饭，有认识的，有不认识的，桌上一人直男癌犯了，端起杯说：“大家都干了，不干不是男人！”我抿了一口，没干。“你是不是男人？”我没鸟他。他走到我前边，抓起杯子端到我面前：“是男人就干了！”我还是没鸟他。他只好悻悻回去了。
有句话叫烟酒不分家，不是说边喝边抽，是说喝酒的时候旁边放一盒烟。白酒第一杯，和烟盒躺着平齐；第二杯，和烟盒侧着平齐；第三杯，和烟盒立着平齐。三杯下去，才算开席。口数也有讲究：一口喝干叫龙饮，两口喝干叫虎闷（第一声），三口喝干叫狗舔，四口喝干叫鳖吸。
我年轻的时候，也好喝酒。年轻说的是五岁以前，听武松打虎，三碗不过岗，心潮澎湃。打老虎的本事没有，喝酒的本事还没有吗。于是喝。听我爸说，小时候我不爱喝药，每次喝药都得就着啤酒。药片往嘴里一扔，皱紧眉头，啤酒一灌，下去了。《水浒传》上，武松到快活林闹事，只有五六分醉意，却装成十分。想来我那时候紧皱眉头，也有七八分是装的。没办法，小孩都天生自带装逼气质，只是越长大，越能装得隐晦一点，不会再“我爸给我买的变形金刚比你这还大”那么直白。
但通过喝酒来体现魄力，不也是同样的逼格吗？一个人没有别的魅力来征服人，只好靠喝酒。曾问某人白酒量多少，答曰：一斤二斤漱漱口，三斤四斤还能走。
我年轻的时候，也羡慕李白、陶渊明，喝得一壶好酒，写得一手好诗。后来明白，他们诗能写那么好，跟喝酒一毛钱关系都没有。论酒量，李白在他的时代连一万名都排不到。人们之所以记住他，是因为他的诗好。
《饮中八仙歌》里赞叹八个人，有人凭诗冠绝古今，有人凭书法名动天下，有人是丞相，有人是皇侄，有没有单凭喝酒名列其中的呢？有。这个人可能是当时酒量最大的，但今天几乎没人知道他，他叫焦遂，排在最末。为什么要排他一个呢？因为“饮中七仙”不好听，要拉他垫背，拉他就是为了衬托前边七人也能喝。虽然他们酒量加起来可能都敌不过焦遂，但七人是内定的，焦遂是走运入选的。
这就是真实的生态。所以我不理解，有些人宁愿损伤自己的身体，来换取这样一种逼格有何意义。你喝趴下了，甚至喝挂了，别人也不会在乎，只有你妈你老婆心疼。
可以明了的事实是，往往一个人在别的方面很怂，才要靠拼身体来证明自己不怂，证明自己还能雄起，想通过这展现自己的自负。但这种证明是何等孱弱无力，而这种自负又何等愚蠢浅薄。
不过，类似的事不止拼酒一桩，大大小小的事上都有反映。比如我这篇文章说了两遍“我年轻的时候”，就带着点儿要隐隐约约透露“老子也曾经屌过”的意思，而身经百战的长者看到这里早就嘴角露出一丝微笑了：太嫩，太简单。
