# 异性的漂亮为什么是苦？

如果学心理学就能解决心理问题，那么大家都学心理学了；如果学佛就能解决烦恼问题，那么大家都学佛了。实际上，对绝大多数人来说，解决不了。只是在学习之前，并不清楚这一点，于是会抱着憧憬，或者幻想，寄希望于学了就能解决问题。在学的过程中，发现并不能很好地解决问题，不同的人在不同阶段，会给自己不同的解释。

比如：没能解决，是因为学得还不够好，我如果有朝一日学得像某某那样好，应该就能解决了（偶像崇拜就是这样产生的，当你没有涉足一个领域的时候，对这个领域的权威是一点儿也不感冒的，但当你涉足得越深，就越感冒）；或者干脆认为，看来学这个东西是没什么用的，于是放弃了。——这对应两种不同的性格，一种人认死了先前的幻想，无论如何不肯放弃，要找各种理由，企图让自己相信先前的判断不错；另一种人是浅尝辄止的，刚了解皮毛，就觉得自己把一个学科一眼望到头了。

对于后者，不用说，他是不可能了解到一个有东西的领域货真价实的东西的。对于前者，他可以了解到一些，甚至，方法对头的话，可能了解到很多，但这“很多”相比解决自己先前设想的问题来说，仍然是杯水车薪。就像一个人在接触物理之前，可能幻想学了物理就能洞晓自然界的种种规律，而事实是，一个物理学博士，恐怕也很难根据乒乓球发球的一刹那，计算出随后每个时刻的角动量和速度，并精确地画出乒乓球的运动轨迹。

学习心理学和佛教，对90%的人来说，恐怕不能解决心理问题。这里说的“解决”，介于“彻底解决”和“有效缓解”之间。如果说“彻底解决”，恐怕100%的人，都不能单纯通过学习某个学科来解决。如果说“有效缓解”，一定会有很多人认定自己是有效缓解了的；这一方面是因为，人们对自己下过功夫花过时间和金钱的事情，是不甘心承认它于事无补的；另一方面，真正有效缓解的人，假使压根儿没有接触过那些学科，他们大概率也会通过别的方式让问题得到有效的缓解。

现在，来思考一个问题：解决问题重要？还是了解自己重要？

有人会给自己一个退而求其次的解释：我学习一种学问，寄希望于解决问题，最终发现，虽然问题没有解决，至少我通过学习更加了解自己了。甚至会感觉：了解自己比解决问题更重要。

对此，我想说说佛教是怎么看的。佛教认为，了解自己和解决问题，是一码事，但是有次序上的差别。自己的烦恼问题，只有通过了解自己，才能得到解决，而且，一旦了解自己，就必将得到解决。说“必将”，是因为，解决是表现在了解之后的，中间会有一段时滞。这种时滞甚至可以超过一辈子的时间。佛教把这比喻成砍树。如果你想让叶子枯萎，重要的不是对叶子做什么，而是斩断树根。树根被斩断的一刻，叶子的颜色不会发生变化；第二天，叶子仍然是绿色。但是到了第七天，不会存在任何一片尚未枯萎的叶子。

佛教把烦恼分为两类：见所断、修所断。用通俗的表达是：认知问题，具体事情的问题。如果我们着眼于先解决具体事情的问题，问题是不能根除的，因为有无穷无尽的事情。所以，首先应该解决的是认知问题。

认知问题如何解决？需要有抽象的能力。一个糖尿病医生，无法通过仅仅对一个患者的钻研，就精通糖尿病。不管这个患者的症状多么典型。任何一个人，都无法仅仅通过对自己的反思，就了解自己。不管他自认为反思有多深刻。糖尿病医生一定是通过成百上千、成千上万个病例来理解糖尿病的。一个人也必须通过无数人来理解自身。因为自身没有一个地方是特殊的。

具体事情的烦恼可以有种种不同的表现，比如看到商场橱窗里的包，觉得好喜欢，这就是烦恼；漂亮异性从身边经过，忍不住多看一眼，也是烦恼；闻到不知哪里传来的炖排骨香，有点咽口水，这也是烦恼。如果去琢磨这些无穷无尽的细节，就永远无法真正理解烦恼，也无法理解自己——因为认知没有得到很好的抽象。我们不是通过小学三年级的计算掌握一切数学的。我们会渐渐学会用a，b，c，x，y，z来表示数学问题。只有通过正确的抽象，才能更好地理解事物本质。

上述种种烦恼，其实只是一种：欲界修所断贪。欲界修所断贪的彻底解决，要以三界见所断贪的解决为前提。具体又进而分为四个层次：理解苦、理解集、理解灭、理解道。四个层次还可以细分，但这里就不细分了，我们只说最要紧的，就是理解苦。

漂亮的异性也是苦——严格地说，如果漂亮的异性是圣者，要把此人身上的圣道除掉，那些不是苦，不过我们不需要总是表述得很严谨，而且，世界上的圣者也很好，几乎不会是你恰好撞见的人。不过，可以换一种更贴切的表达：异性的漂亮也是苦，这种漂亮，就是好看的容貌与轮廓。——这比“病痛是苦”难以理解得多。因为病痛会给身体带来不舒服的感受，而漂亮的容颜和身姿会给你的身心带来舒服的感受。为什么带来舒服感受的东西也是苦？

因为它实际上带来的，是舒服感受的破坏，或者说毁灭。就像亲人的离去，花朵的枯萎，恋情的终结。所有一切美好事物的凋亡，都不是偶然的，而是必然。也不是要隔上一段时间才发生的，或者说能有任何机会暂住的；事实上，那些毁灭发生于此时此刻。任何愉悦的感受，无论是身体，还是精神，都一并在当下粉碎了。——这就是“当下”的意义。什么叫把握当下、专注当下？就是专注一切愉悦的感受都在毁灭，现在进行时的毁灭。那么，引起愉悦感受的事物，如果可以成为渴望的对象，它就是苦。
