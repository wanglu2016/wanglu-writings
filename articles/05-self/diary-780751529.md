# 渴望焦虑与惧怕涅槃

上周备课，遇到些问题，有点焦虑。我是排斥焦虑的，心想何必要这样呢，甚至掠过一丝念头：趁这月还没开课，干脆把学费退了，班不开了。当然，不会真的那么做，那会带来更大的焦虑，会让以后每次想起都感到挫败和懊丧。

那天邻近中午，有个老学员问10月班还开不开，想续报，说课程很棒，希望明年接着开，最好能包年。这让我有点高兴，但并不太能缓解焦虑。因为焦虑的缓解，不取决于别人对过往工作的评价，主要取决于眼下的困难能否解决。

我歇了会儿，中午吃过饭，下楼溜达一圈。重新把思路捋了捋，渐渐捋清楚了些，问题差不多解决了。回想以前，类似的焦虑不止一次出现，每次出现，我都有“以后写作班停掉算了”的想法。其实，焦虑并不大，也基本上都能解决，加上还有一些支撑我继续开下去的动力，所以到现在都还没停。经过这些事情，我问自己：不想承受一丁点儿焦虑，这样好吗？人到底是应该尽可能远离一切焦虑，还是应该保留适度的焦虑呢？假如生活中一丁点儿焦虑都没有，是不是太乏味了？

是的。所以每到暂时没有焦虑的时候，我都会给自己制造一些焦虑。这是很愚痴的。可是总情不自禁这么做。而且我还发现，不仅我，我父母，我周围所有人，都是这样，还没有见过谁不是这样的。

三年多前，有朋友转来知乎上一个问题。提问者去斯里兰卡禅修了两个月，心情很平和，回国时感觉特别好，回来后，变得容易发怒，问是怎么回事，该如何调节。我当时写了回答，说如果是正确的禅修，发现自己变得易怒不一定是坏事，有两种可能，一种表示觉知变敏锐了，就像去体检，检查出问题不是坏事，问题本来就存在，只是从前没有察觉，经过禅修，能更清晰地看见情绪的变化，不是变得易怒，而是变得更容易发现易怒了；另一种是，水平并没有进步，是环境的改换让情绪更明显，如果始终在嘈杂的环境里，听到嘈杂的声音也习惯了，如果是从很安静的环境里突然转到嘈杂的环境，自然非常难受。

现在回头看当时的解释，总觉得没有“搔到痒处”，没有揭出更深层次的事实。回答里说“不一定是坏事”，这是很滑头的表述，像很多学者写论文、医生开诊断，说得不错，但空洞没有意义。“不一定是坏事”，也未必见得是好事，很多不必要的事，说不上坏，但确实没啥必要。一个人向往和平安宁的生活而去禅修，是值得随喜的，而禅修后，由于种种原因依旧故我，就像一边吃着降压药一边饮食没有忌口，又有什么意义呢？有时候，看似巧妙的解释只是在企图绕开问题的关键。

问题的要害是：一个人是不是应该主动减少一切焦虑？还是保持适度的焦虑“积极面对”？

“面对”是个很蛊惑人的词。很多不算好的事情，一旦用“面对”，就显得态度积极了。固然，有些事情是需要面对的，因为你逃不开。比如工作会带来焦虑，可如果辞职，失业没钱会带来更大的焦虑，这时候，“面对焦虑”并不是因为要“勇于面对问题”，只是因为逃不开——逃开这个问题，更大的问题会找上门。这是理智的结果，不是勇敢的结果。就像有摩托撞过来，你不要躲，面对它，为什么？因为两边都是大卡车，如果躲摩托，就被大卡车撞了，干脆还是面对摩托好了。

但是，如果没有大卡车呢？凭什么就要面对摩托，不能逃避？有些问题是完全可以逃避的，你一逃避，它就不存在了，没有了，再也不会找你。那为什么还要面对？不是傻吗？而且，很多问题是连串的，面对了第一个，就不得不面对第二个，第三个，第四个……后来的问题，是先前绝没有料想到的，骑虎难下，骑老虎的问题是面对了，解决了，但下老虎的问题没解决，下来的时候被咬了。那为什么一开始要骑上老虎呢？

由此想思考的是：某种焦虑虽然小，但完全可以避开，你是应该避开它，还是迎接它？

这个问题，在实践中往往无足轻重。正因此，它才难以解答。就像摩托车撞过来，能躲自然要躲，但如果是蹒跚学步的小孩撞过来呢？躲了，他也不会倒，你会不会躲？还是说，都无所谓？

生活中有重大的焦虑。无常的侵袭会带来焦虑。人总要生老病死，生老病死会发生在父母身上，自己身上，眷属和孩子身上，这是必然的、注定的，不可避免的。普通人不可能不因此焦虑，那么，既然有这样重大的焦虑当头，再去琢磨是否应该避开微小的焦虑，有必要吗？大力士的铁拳吃定了，还考虑要不要躲开幼儿的小拳头，有意义吗？

然而，真正的解脱，是要避开一切焦虑的。像刘备说的，“勿以恶小而为之，勿以善小而不为”，不应该因为焦虑的微小，干脆就不管了。那是稀里糊涂的。而且，细微的事情搞不明白，大的事情往往也不容易搞明白。细微之处能看明白，显著之处就能看得更清楚。

断烦恼，也是先从大的断起。大的不断，先断细的，是不可能断掉的。但我们生活中，确实很多时候存在大的问题没有解决，却转手去解决小问题的时刻，那就往往徒劳了。比如有人努力减肥，又忍不住馋，去吃火锅、烤肉，为了不让减肥大计付诸东流，每次吃火锅、烤肉时喝的可乐一定是零度的。

假如禅修回来，有选择和改换环境的可能，可以避开焦虑的诱发因素，却依然让自己停留在容易焦虑的环境里，并且激起了自己的焦虑，那么，禅修的必要性，也就值得考虑了。“禅修后变得易怒”，也许它的积极意义在于，对自己是一种提醒，告诫自己应该告别某些环境和生活行为方式了。

就像去医院体检，检查出来问题，总是有原因的，要么是遗传的基因问题，难以改变；要么是后天原因，是不良环境和生活习惯的诱发。慢性病不是一天出来的，是日积月累的，只是在积累的过程中，毫厘间的变化难以察觉。体检的结果，可以警醒自己，在有可能的情况下，做出选择，改换环境和生活习惯。假如不这样，体检又有什么意义呢。

焦虑不一定都需要面对。哪怕是小的焦虑。不过，有些焦虑并非全无积极的意义，它是为了让总体焦虑变得更小而存在的。就像早上的闹钟虽然刺耳，带来不舒服的感受，但它是必要的提醒，否则迟到扣工资会让自己更难受。然而，在解除了迟到的风险，以及其他一切晚起的过患后，闹钟的刺耳就不必要了。

焦虑的复杂，事物与事物之间错综的联系，让我们不能不去仔细考虑每一桩焦虑的存在是否有必要，而不能盲从世俗的说法和外在的显现。从外在显现上看，深圳三和大神的生活，似乎和孔子门下的颜回差不多，都是“箪食瓢饮在陋巷”，都没有激进的事业心和凌厉的拼搏劲儿，可他们实在很不一样——三和大神会比一般人更频繁地陷入焦虑，会在突如其来的打击下变得非常焦虑不可逆转，颜回却能在“人不堪其忧”的环境里始终“不改其乐”。三和大神对焦虑的躲避，一定会造成未来甚至是很近的未来的大焦虑；但颜回不会，颜回只是不去主动拥抱焦虑，也不必接受未来焦虑的侵袭。

而我们往往会去主动拥抱焦虑。一旦我们暂时缺乏焦虑，在享受片刻的宁静后，就会陷入空虚和无聊，于是不得不去拥抱焦虑来打破空虚和无聊。就像生活本来美满顺当的人，突然觉得没什么意思，要做些冒险的事情，折腾掉一层皮，给他带来很大焦虑和压力，背上巨额债务。但如果重来一次，他还会这样。就像有些人手里放不住钱，没钱的时候只好算了，稍微有点钱，捏在手里不花掉，心里会非常难受。缺乏焦虑的生活，也会让很多人非常难受。因为他长久以来，已经非常习惯焦虑的相伴了。有人一直生活在嘈杂的环境里，一旦到了寂静的地方，就受不了，心里发慌。

那些被感情折磨得伤痕累累，又死活不愿意分手的人，一旦分手，只要有可能，就会迅速投入下一场类似的折磨中。这绝不是什么勇敢、奋不顾身。恰恰是因为，只有在被折磨和虐待中，才更容易感受到“身”的存在。在平淡的生活中，难以捕捉到自身存在的证据，就会发慌，会可劲儿造作。

佛教说“涅槃寂静”。实际上，绝大多数人是恐惧涅槃的。包括口口声声要学佛修行的人，一旦接近通向涅槃的道路，他很可能扭头就跑。

涅槃是烦恼的熄灭。三界九地的烦恼，一并熄灭了，永远熄灭了。这令人恐惧。涅槃里什么都没有。很多人觉得，断掉一只胳膊一条腿都会生起极大的忧恼，更何况什么都断掉，什么都没有。因此，人们对涅槃大都是排斥的，是叶公好龙。不要说色无色界的烦恼熄灭，就是欲界最粗重的烦恼熄灭，也会让人生起极大的恐惧和误解。误解是，真修行到了离欲染的时候，会以为梵天的清净就是涅槃的寂静。恐惧是，在生活刚刚有些平和的时候，仅仅是烦恼现起少了一点，就已经浑身不自在，觉得空虚无聊，虚度光阴，没有意思，一定要去搞点“有意义”的事情出来，才不“枉过此生”。

这是“萨迦耶见”对涅槃的恐惧。在通往涅槃的道路上，先要斩断萨迦耶见，也就是“我见”和“我所见”。萨迦耶见当然不希望自己的头颅被八正道砍掉，于是要奴役有情起来反抗。别说通向涅槃的道路，仅仅是听到涅槃这个词，就让人厌恶恐惧。因为害怕“自我”的彻底消失。

善法，是让心趋于寂静安定的法；染污法，与之相反，是让心躁动不安的法。染污法生起的时候，更容易感受到心的存在，“我”的存在，躁动得越剧烈，感受越明显。而一旦心安静下来，就会有恐惧，怕它消失。害怕空虚，是我们受萨迦耶见奴役的明证。

因为害怕空虚，会主动拥抱焦虑，不要说生活本身已经为无边的焦虑营造好种种坑堑，即便是一时没有踏入坑堑的人，也喜欢主动开凿坑堑，制造焦虑去拥抱。由于过去的拥抱，现在面临痛苦；由于过去和现在的拥抱，将来继续面临痛苦。但还是忍不住拥抱，因为并不清楚拥抱的是什么。佛陀说，那是苦，是集。
