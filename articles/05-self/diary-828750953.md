# 坏情绪才是动力，好情绪不是动力，而是负载力

主题：自我、情绪与人际关系

人们说“好情绪”的时候，往往说的是“舒服的感受”。比如：开心、快乐、高兴、欢喜、灿烂…… 不管是描述，还是形容，或者比喻，所指都不会超出两样感受：心理上的舒服、生理上的舒服。

那么，假如我们抛开感受，来重新定义“好情绪”，还有什么能被定义为“好情绪”？

在谈这个问题之前，很有必要先解释一下，为什么要把情绪和感受区分开。——如果把情绪和感受混同，人们就会认为，感受是行为的动力。比如，有人骂我一句，我一定要打回去，至少骂回去。他骂我，让我产生不舒服的感受，这种感受是行为的动力，在动力的迫使下，我自然要做出行为。换言之，我打他不是主动的，因为他骂我了，我是被动的，别无选择——他不骂，我就不会打，他骂了，我就不能不打。

而现实中，你会发现，有些人挨了骂并不打回去，甚至唾面自干都行。这表示，感受本身并不是行为的动力。感受只是一种状态，被动领纳的状态。而由感受引起的情绪，才是行为的动力。

如果把感受和情绪混在一起，就难以搞清楚在“产生感受”和“做出行为”之间到底存在着什么。混同的人，会致力于改变感受，却无法左右行为。而实际上，感受的改变取决于置身的环境、感官接触的对象，而这些是受行为影响的。关注感受而不能改变行为，就是扬汤止沸。

因此，要抛开感受来理解情绪——好情绪和坏情绪。

坏情绪，是比较容易理解的。很容易想到的就是愤怒，愤怒会促使我们做一些事情。即便你察觉不到自己“做了什么事情”，只要随身佩戴监测生理指标的仪器，也会发现自己血压升高了。说“升高”，指的是和愤怒之前相比，离开比较就没有办法说“升高”。由此可见，坏情绪是一种动力，推动某些事情变化。

问题是，好情绪是什么？抛开感受，去寻找一个可以称得上“好情绪”的东西，你会认为那是什么？不妨现在停下来，想一想，看看能否找到可以称为“好情绪”的东西。

类比“坏情绪”，能够知道好情绪也是一种力量。难以理解之处在于，好情绪并不是一种动力，而是一种负载力。比如说“好扁担”：有两根扁担，一根竹子做的，一根铁做的，担重东西，竹扁担压折了，铁扁担没事，我们就说铁扁担更好。

用同一句话，在同样情境里骂人，有人听了马上暴跳，有人听了只是笑笑。笑笑的人未必没有愤怒。但我们如果监测他们的血压上升程度或者其他生理指标，会发现，面对同样的感受，不同人产生的情绪确实存在差别。这是非常简单的事实。重要的不是事实本身，而是这种事实让我们可以抛开感受来定义什么是“好情绪”。

现在设定：“坏情绪”的最大强度为9，最小强度为1。如果一种负面情绪的力量很微弱，还达不到1，不叫它“坏情绪”，叫它“负面情绪”。

我们会发现，有些人，坏情绪永远达不到9，甚至达不到6。那么，我们就把一个人坏情绪所能达到的数值上限和9之间的差距，作为这个人的“好情绪”数值。如果一个人的好情绪数值为3，就意味着，无论碰到什么事情，天塌下来，他的坏情绪强度也只能达到6。

需要强调两点：第一，好情绪并不是拿9减去此刻坏情绪的强度值，而是减去此人坏情绪上限的数值，就好比一辆车载重是2吨，不管现在拉了多少货，载重都是2吨；一个人肺活量是5000，不管现在怎样呼吸，肺活量都是5000；这就是为什么说好情绪不是“动力”，而是“负载力”。第二，好情绪作为一种能力，是会变化的；就像人的肺活量，短期看是稳定的，但长期看，也会变化，也可以训练；一个人现在的好情绪是3，不意味着永远都是3。

接下来，我们把“好情绪”分为两种，一种是值为0的好情绪，一种是值为正的好情绪。值为0的好情绪是什么意思呢？就是说，哪怕一个人的负面情绪最高能飙到9，他也不是在任何时候都有负面情绪——碰到和缓的环境，碰到好事，他的负面情绪也会降下来，甚至降到0。负面情绪一旦下降到0，就不能称为“负面”了。这时候，他的情绪或者是中性的，或者是好的——无论生起的是中性情绪，还是好情绪，此时负面情绪的强度都是0。这一点特别重要，千万不要认为，生起好情绪的时候，负面情绪的强度为负值。好情绪类似一种“冗余设计”，是在负面情绪出现时才发挥作用的；负面情绪不出现时，它只是存在，并不发挥作用。就像一个人能扛200斤的包，但他不需要任何时候都举着200斤重量，当他空手的时候，不能说他举了负的重量。

很容易产生的曲解是，认为好情绪类似负面情绪，也是一种动力，会推动你做某些事情，心潮澎湃、斗志昂扬——当一个人想发财想疯了的时候，他可能觉得此刻情绪很好。实际上，那是负面情绪伴随着“舒服感受”出现。它还是负面情绪，只是“舒服的感受”让他迷惑了，误以为情绪是正面。一个人满怀激情地要砍死敌人的时候，他可能觉得自己是英勇的、道德的、正义的——他内心中涌现的绝不是对他行将伤害之人的同情与悲悯。假如他当时没有负面情绪，哪怕是对十恶不赦的人，也不会有愤怒、仇恨、伤害的心，只有同情和悲悯。

负面情绪可以达到9的人，也有生起同情、悲悯、不伤害、恭敬等好情绪的时候——前面说过，这样的人，好情绪的负载力数值是0。数值为0并不代表没有好情绪，就像一辆车，不能负载任何货物跑，但是，空载的时候，它可以跑。我们把这种好情绪叫做“天生的好情绪”。人人生下来，都拥有这种好情绪。而负载力不为0的好情绪，我们称为“习得的好情绪”，它是可以后天训练并改变的。

那么，“天生的好情绪”能改变吗？也能。既可以在它的基础上，通过训练成就“习得的好情绪”，也可以把它破坏掉。什么时候它会被破坏？在一个人根深蒂固地接受某些错误认知的时候。是什么错误认知有这样的威力？认为作恶并不会导致受苦。

这种认知，会毁坏“天生的好情绪”，从此往后，他虽然也有负面情绪不生起的时候，但那时也只能生起中性的情绪，绝不会生起好的情绪。这和一般人不一样，一般人负面情绪不生起的时候，有时是中性的情绪，有时是好情绪。而持有上述错误认知的人，任何时候都不会有好情绪，直到他开始怀疑所持的错误认知。
