# 幻想是真实的一部分

我们常说“无谓的焦虑”。假如焦虑真的无谓，我们就可以不用管它了。假如幻想真的是幻想，和真实完全无涉，一个人常常抱有幻想也没什么，毕竟不影响真实。

可事实上，并不如此。

这里姑且还举一个前几篇说过的小话头：有没有来世。

一个人对来世的理解，显然会影响到他此世的作为。哪怕他的理解是错误的。照佛教的说法，理解去、来二世，都有两种办法，一种是通过“见”，一种是通过推理。推理有时候不那么准确，因为毕竟不是“现量”，而见是更准确的。所谓推理，就是“欲知前世因，今生受者是；欲知来世果，今生作者是”。这种推理常常太宽泛。就像别人问389乘以498等于多少，你说，等于一个正数。你真是够聪明噢，说得一点都没错。

“前世”涉及的范围很广，从前一世到前无数世，到底今生受者是前面哪一世的报呢？对来世果来说，也并不一定是受今生所作的报，也可以受前世所作的报，还可以受来世所作的报。这样一来，就给了一些爱忽悠的人发挥的空间，今天看到谁个倒霉，就说他前世造恶了，明天见他因祸得福，又解释成他前世还行善了——反正每个人都有无穷无尽的前世，谁的前世没有造过各种各样的恶并行过各种各样的善呢。

“见”是比较准确的。见前世，通过宿住通，像翻账本一样一页页往前查就可以了。那么，见后世呢，靠什么通？

任何神通——如果单是神通的话，都见不到后世。

很简单，未来的事情还没发生，你怎么见？就像有人去找算命的：算算我什么时候结婚？算命的说，再过三年，结果你明天就去领证，不是把算命的结论推翻了吗？前两年看过一条新闻，有人去算命，算命的说，他不去当和尚就要在几年内死掉，他信了，当了和尚，过了几年没死，越想越生气，觉得受骗，把算命的杀了。

别说算命的没有神通。就是有神通，后面的事也看不准。就是有神通，熟鸡蛋也不能返生。六种神通里，没有一样是能让熟鸡蛋返生的。

不过，照理论来说，确实有一种本质上是神通的东西，可以看到来世。不是宿命通，因为宿命通只看过去，只能翻过去的账。而是天眼明。天眼明的本质是天眼通，天眼通的本质是解脱道所摄的慧。天眼明只有阿罗汉才有——不像天眼通是随便哪个得禅定的就有。天眼明之所以能看准来世，因为所有天眼明看见的来世只有一种：

没有来世。

就像高考估分，怎么估都不会太准。但你交白卷，估零分，肯定估得准。

也就是说：当一个人搞不清楚、不确定有没有来世的时候，他就是有来世的；而当一个人彻底看清楚来世的问题时，他一定没有来世。

这篇文章不想过多讨论佛教理论。倒想由此引申开聊聊：

唯有在彻底认清幻想的时候，幻想才不会对真实起作用——换句话说，幻想才真正成为“幻想”；只要还没彻底认清幻想，幻想其实就不全是幻想，幻想就会成为真实的一部分，或者说，引生真实的一部分（假如我们要在“幻想”之外另立“真实”的话）。

举例来说，谣言是不是假的？

谣言是假的。但相信谣言的人，所起的种种行为是真的还是假的？

假如大人对闹着出去玩的小孩说，今天不能出门，星期一，外面有老虎，出去老虎就会把你吃掉。——这当然是假的。但小孩相信了，或者将信将疑，他即便出门了，也会时刻担心从哪里突然跳出一只老虎把他吃掉。这担心不是假的。尽管担心是由幻想所引生。

只有当一个人彻底明了幻想是幻想的时候，对他来说，幻想才真的是幻想。否则，幻想就要以缘起的方式，牵动并改变他所认为的真实。

有来世的根源，是因为没看清是不是有来世，换句话说，是因为怀疑有来世——由于怀疑有来世，就真的有来世了。而当真正看清楚、看得完全明了的时候，就没有来世了。谁看得完全明了呢？阿罗汉。谁不能完全明了呢？有学圣者与外道。谁完全不明了呢？具缚凡夫。用阿毗达磨的话说，“无明诸有本”。一旦看清楚，消除了无明，得到了“明”，对治了“后际愚”，必将“不受后有”。

然而，事情还不是这么简单。

纵然一个人能认清幻想，我们可以“有条件地”说，幻想对他不起作用了。为什么是“有条件地”？因为他周围的人并不一定能认清幻想。

孩子的爸爸对孩子说，放心出门吧，外面没老虎，可小孩还是瘪着嘴说，妈妈说，外面有老虎。

假如孤立地看，对认清幻想的人来说，幻想固然对他不再起作用，然而，假如在他和其他人的交互中看，但凡其他人还没彻底认清幻想，幻想就会在彼此的交互中发挥作用。那么，也就依然不能与“真实”独立。

一个认清幻想和没认清幻想的人，假如在一块生活，吃喝拉撒，就很容易就一件事情到底是不是幻想吵起来，甚至干架。难道由幻想引起的吵架和干架也是幻想吗？

所以说，在家人一旦证了阿罗汉，就要赶紧出家，或者涅槃。因为不想跟人抬杠。在阿罗汉中，有一种不动阿罗汉，有“无诤智”。这是一种世俗智，就是防止别人杠他的智。他当然不去杠别人，但当他入了第四边际静虑，观察到有些人可能要杠他的时候，有些话就不说了。因为缘阿罗汉起瞋是要受很大苦果的。

话重新说回来：只有所有人都认为是幻想、是假的东西，才真正是假的，才不会起作用。然而，一样幻想只要存在，多少总会有人怀疑它有没有可能是真的，那也就意味着，幻想总在某种程度上影响着真实。

焦虑真的无谓吗？焦虑真的对事情没有帮助吗？焦虑对事情有帮助。大多时候有负的帮助，也有一些时候有正的帮助。焦虑从很多不同层面对事情起影响。不仅你的焦虑对自己来说不是无谓，别人的焦虑对你来说，也不完全是无谓。这就是缘起的深义了。

同样，幻想不仅是幻想，幻想当中有真实，而且始终影响着真实。包含了真实与幻想、承认幻想对真实的牵动与影响的，或可叫做更深的真实。
