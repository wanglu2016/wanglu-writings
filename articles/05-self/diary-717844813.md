# 马云的荤段子

马云讲的669的段子，佛教叫“绮语”，“绮语”也叫“杂秽语”，是对解脱没有什么帮助的话。不仅没帮助，还有坏处。


我们平时开玩笑，朋友之间调侃，很多时候是杂秽语。杂秽语不好，但我们经常说。很惭愧，我自己也说得不少。不一定是荤段子才叫杂秽语，讲个笑话，很多时候就是杂秽语，属于“身三口四”的口业之一。知道它不好，一时半会儿又改不掉，也是凡夫的习气。

马云讲荤段子，而且是公开场合讲，是杂秽语中的杂秽语。但这也不全是马云的问题。一个时代有一个时代的习气。时代的习气，会在众生身上体现。

荤段子，不仅是荤段子。荤段子有几重含义。

第一重含义，是幽默感。幽默感是中性的东西，但我们倾向把幽默感看作好的品质。幽默感只有在能起到抚慰他人的作用，让他人在冰冷的尘世中得到温暖，在痛苦中得到安慰时，才是好的品质。但这种幽默感，要求很高。我们讲十个笑话，有一个能达到这种水平，就不错了。

什么笑话最好讲呢？一种是调侃自己或他人的笑话。以贬抑嘲讽他人或自己，达到引起大家发笑的目的。我就听过有居士在讲佛法的时候，骂一些人蠢，没脑子，骂的都是不在座的，在座的人一听，都乐了，哗哗哗鼓掌，很起劲儿。说不在座的人蠢，就暗示在座儿的聪明。大家的虚荣心和自我，就在笑话和调侃中膨胀起来了。

另一种，就是和性有关的，荤一点的笑话。这种笑话基本不可能达到抚慰他人的效果，只是靠迎合众生习气，来彰显自己的幽默。

笑话不全是绮语，也有爱语。爱语是好的，是“四摄”之一。菩萨就是靠爱语，把众生摄受在自己周围，然后去度化他们。同样是笑话，爱语和绮语如何分别呢？

以抚慰他人，令他人得到积极的快乐为目的的笑话，就是爱语。以彰显自己为目的的笑话，就是绮语。

其实，快乐都是积极的，没有消极的快乐。那为什么前面说“积极的快乐”呢？因为有些时候，看似快乐，实际上并不快乐。比如，讲和性有关的段子，对那些性方面有障碍的人，或者失恋分手的人来讲，表面上跟着别人哈哈大笑，内心是挺难过的。马云讲669，大家跟着哈哈大笑，哈哈大笑背后，恐怕绝大多数人很清楚，669就是个笑话。真要以669为指标考核，恐怕彼此都笑不起来。

那么，这种笑话给别人带来的快乐，并不是真实的快乐，是绸缎底下爬满了虱子，是对内里挫败的虚假掩饰。除了彰显演讲者的幽默机智，对听众恐怕没有真实利益。

第二重含义，是权力欲。

讲段子，是想展现幽默。讲荤段子，除了想展现幽默之外，还附带一重隐晦的功能——展现权力。

一个再喜欢讲荤段子的人，假如跟领导坐一个桌，自己坐下席，领导不开口，恐怕他没有胆量先讲荤段子。

否则，他就把风头抢走了。

上级在下级面前讲荤段子，是一种威慑。越是等级森严的体制中，荤段子越流行。但这种流行，有严格的秩序。平级之间可以讲，关系熟了可以讲。上级已经开了口，不拘小节了，下级才可以勉强陪讲一两个，还不能比上级讲得出彩。

但是，上级可以随时随地对下级讲。所谓随时随地，也不是绝对的随时随地。权力越大，级别越高，越敢在相对公开的场合讲，越敢面对相对不熟悉的听众讲。

因为，一个人讲荤段子时，隐晦地体现另一重作用：我在划定我的势力范围：

你听我的荤段子，而且不得不听，这就意味着你在某种程度上，屈服于我的威慑。

你要敢与我抗衡，就站出来指着我的鼻子，让我把荤段子收回去，或者要求我道歉——否则，你在气势上，就输给我了。

很多酒桌上，流行讲荤段子。这未必代表每一个酒桌上讲荤段子的人都是低级趣味，更可能是很多人屈从于这么个游戏规则：想和别人抗衡，要用一种隐晦的方式，表露自己不甘屈居别人之下。

男性在有女性的酒桌上讲荤段子，可以说是隐晦的性骚扰。但这种性骚扰，让人很难反击，即便介意，可能也只有尴尬地陪笑，或者借故躲开，甚至干脆跟他对着讲，表示我不屈服于你。

这样，荤段子就不仅仅是荤段子，荤段子背后隐藏着权力欲，代表一个人在当众宣告他对局面的掌控。

无论是彰显自我的幽默感，还是掌控局面的权力欲，在迁善改过、利乐他人的目标下看，都是弃之如粪便的杂秽，是羞于向人炫耀的。

面对自己尊重的人，敬畏的人，这种话，讲不出口。

而真正交心的朋友，聚在一起时，第一不必靠豪奢的吃喝展示排场，第二不必靠荤段子联络感情——那些都是不够熟、不够真诚的表现——真实的自我既已隐藏，又要向对方表演亲昵，才去展示这些虚伪套路。
