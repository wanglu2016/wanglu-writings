# 《情绪觉知100讲》发刊词：探索大脑的内在开关

下面是我在得到APP的新课《情绪觉知100讲》的发刊词：

你好，我是王路，欢迎来到《情绪觉知》课。

“情绪”的重要性，我想不需要多说。要说的是，那么多人讲情绪，这门课有什么不同？讲情绪就能解决情绪问题吗？为什么我听了很多门情绪的课，还是对自己的情绪不满意？这门课到底能带给我什么？

咱们直接上例子，聊三个具体的问题：

第一个：你觉得健康的状态，应该是早上压力大，还是晚上压力大？还是早上晚上压力都不大？

如果你觉得，早上睡了一觉刚醒，自然压力小，白天干了一天活，晚上自然压力大。那么，这门课应该能带给你一些不一样的思考。它会让你从皮质醇的视角，来重新审视这个问题。听完你也许会接受一种截然相反的观点：健康的状态是早上压力最大，一天中渐渐变小，晚上压力最小。

第二个：假如你的工作是写东西、做设计、写代码等等，偶尔你会进入心流状态。那么你觉得，让你进入心流的，是多巴胺，还是内啡肽呢？还是都是呢？

如果你觉得是内啡肽，你可能上了网上流行帖子的当了。一般我们伏案工作，对着电脑，不会产生内啡肽。万一内啡肽水平显著增加，不管你是心流还是什么流，赶紧起来活动活动颈椎和腰椎吧，不然可能哪天就发现自己起不来床了。

真正让我们进入心流的主要是多巴胺。还有去甲肾上腺素和乙酰胆碱。内啡肽是镇痛的。如果办公室上班上到大量分泌内啡肽，可能问题有点严重。所以不要相信那种“不要多巴胺，要内啡肽”之类的说法，太粗糙了。

第三个：产妇在生完小孩之后，更容易抑郁还是焦虑？

有人会立马想到一个词：产后抑郁。产后抑郁，可见产后的主要情绪问题就是抑郁嘛！其实不是。虽然流行的说法是“产后抑郁”，但产后的主要情绪问题是焦虑。为什么这么说呢？因为产后抑郁最主要也是最直接的原因，是异孕酮的断崖式下跌。你如果了解异孕酮在大脑里怎么起作用的，就会知道它其实有点像治疗焦虑症的苯二氮卓，还有点像酒精——相似之处在于，它们都会增加大脑的刹车功能，而不是油门功能。如果你周围有产后抑郁的人，你让她回忆一下症状，主要不是提不起来精神、没有动力，而是心烦意乱、躁动不安。你还会知道，为什么有人吃了抗抑郁的药，抑郁没有好转，但是更加焦躁了。这不见得是医生开错药了。不要因为通俗的说法叫“产后抑郁”，就把抑郁当成主导。要能够精准识别每一种情绪，搞清楚它的来龙去脉，才有可能更好地应对。

举了上面三个例子，你可能也就差不多知道这门课讲情绪的特点了。这门课更加关注微观而不是宏观，更加侧重战术而不是战略。更加关注大脑里发生的事情，而不是社会上发生的事情。不是说不关心社会和生活，而是说，要把社会和生活里的东西，映射到大脑里。

大脑里隐藏着很多开关，指向各种各样的情绪。它可以通过感受来开启，比如假期旅游，看到辽阔的大漠，和堵在早高峰的路上，情绪显然不一样。情绪也可以通过语言来开启，开车的时候别的司机摇下车窗骂你一句，会让你瞬间生气。我为什么会突然生气？我大脑里哪个开关被他拨动了呢？——有人会从社会学、心理学、伦理学方面探讨；而这门课更加侧重从大脑里面去探索。除了外在的感受、语言和行为触发的情绪开关，这门课更想探索内在想法触发的开关。

很多时候，仅仅是一个想法闯入脑子，你的情绪就变了。是哪些想法触碰到情绪的哪些开关呢？我们怎样才能做到，让自己去想该想的事情，而不要去想不该想的呢？——佛教把这叫“如理作意”，说起来很简单，但做起来很难。晚上因为想事情睡不着觉的时候，能不能像关灯一样把脑子里的想法关闭掉，告诉自己一句：该睡了，别胡思乱想了，然后你就能不想了呢？99%的人做不到。如果抑郁症的人能做到让自己不要想不该想的，他就可以随时从抑郁的深谷里跳出来，但是他做不到。重要的是，他并不知道自己是怎样一步一步从健康状态滑向抑郁情绪，最终又滑向抑郁症的。这门课就要来探索，中间到底发生了什么。大脑里哪些东西在你不知不觉中发生变化，又是什么原因引起了那些变化？

不过，我们只能说是探索，并不能给出明确的答案。整个人类在现阶段，对情绪的了解，还远远不足以搞清情绪的真相。如果已经有明确结论，神经科学的权威教材就不会每隔几年修订那么多细节了。那些就是科学家曾经尝试对某些现象做出解释，后来发现错了。心理学顶刊的论文，有些让人眼睛一亮，觉得真有意思。过了几年，出来不同的研究，把之前的看法推翻了。——人类就是在不断的质疑和修正中，对自身和世界有越来越深的思考和理解。

虽然做不到知晓答案，但是去尝试了解，就足够有价值。把没有定论的思考、探索和启发分享出来，也许比分享早已有定论的东西重要得多。有定论的知识，在今天的技术条件下，太容易获得了。

所以，这门课主要分享的不是知识，而是思考；不是经验，而是探索；不是智慧，而是偏见。正因为还不够了解，才存在偏见，才需要思考和探索。

这门课侧重微观，也不忽略宏观；侧重战术，也不忽视战略；会从微观宏观两个尺度展开。微观尺度的主要工具是神经科学，宏观尺度是心理学、动态系统理论，偶尔可能也会有社会学和哲学。说白了，不是要介绍一门学科，而是要讨论一些问题。要探索和情绪有关的问题，哪个学科有趁手的工具，就拿来用，不追求建立某个学科的知识体系。是产业界的逻辑，不是学术界的逻辑。

这样讲，有一个坏处——看起来不专业。专业的人什么样？一套理论包打天下。比如搞精神分析的，什么情绪、关系，都用精神分析来解释。那样更容易有鲜明的标签，更具备辨识度。我不是那种风格。其实这门课，得到最早是非常希望我从佛学角度来讲情绪。因为我是研究佛学的，很多人觉得佛学可以解释情绪问题。我坦白告诉你，解释不了。

佛学可以提供开阔的认知，也可以给人很好的体验和慰藉。但解释不了情绪的细节和机制。很多人是因为不熟悉才觉得神秘。佛学的确有讲情绪的，像阿毗达磨里的随眠品，但那些更多的是庞大的理论大厦，和日常的情绪对不上。要照那个讲，就难免牵强附会，挂羊头卖狗肉了。我不能因为自己擅长阿毗达磨，就企图用阿毗达磨解释一切。我也见过好多人企图用五行解释一些，八卦解释一切，甚至阴阳解释一切。我不想阴阳他们，但我要告诫自己：每一门学科都有它的边界。我们的目的是尝试搞清楚各种情绪到底是怎么回事，一门学科如果有有价值有帮助的线索，就把它拎出来；如果没有，不要硬套，不要勉强。

我想探索的话题其实要比狭义的情绪更复杂，它会由个人的情绪蔓延到日常的生活。比如会思考：为什么我在八线小城上中学时那种糟糕的教育到今天都还没改变？一个了解学习是怎么回事的老师和家长，难道不认为让孩子少上晚自习多睡觉才是正事吗？白天学到的东西如果不经过睡觉去巩固，你是记不住它的。乃至，为什么有些女孩总会遇见渣男，为什么不渣的人吸引不了她？婚姻中的七年之痒真的意味着道德败坏吗？应该用羞耻感去遏制自己不要做某些事情吗？为什么有些人会活在反刍和内耗里而另一些人不会？

这些看起来好像有些不算是情绪，但是它和情绪有关，和大脑的运作机制有关。想寻找大脑里隐藏的开关，也就是这个意思。有些翼装飞行的人，风险巨大，收益很小，但他为什么还乐此不疲地去尝试？这门课是想探索这些问题的答案。

我们的课程是问题驱动的，不属于固定的学科。不是给你现成学科的既定知识。是从问题出发去探索。你不知道问题会把你带向哪里，不知道什么时候会从原有的世界中裂开一道缝隙，陌生世界在其中展开。

这门课没有导论，也没有地图。上来就从症状开始，聊戒瘾、渴求和奖赏。从这些出发去思考：为什么我们想要的可能是对自己有害的？为什么有时候安慰朋友其实是在伤害他？

提出问题可能比解决问题更重要。很多时候，一个人会拎出假问题横亘在眼前，好遮住那些不敢直视的东西。在这门课里，我想把探索呈现给你，包括探索中的偏见。就我的体验来说，从偏见中得到的洞察比从知识中更多，从烦恼中领受的教益比从清净中更多。

邀请你加入这门课，和我一起探索我们最熟悉又陌生的情绪世界。
