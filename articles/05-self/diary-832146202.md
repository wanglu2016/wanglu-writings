# 朋友圈里岁月静好的人

[文集首页](../../README.md) · [本类目录](../../catalog/05-self.md)

作者／署名：王路  
主题：自我、情绪与人际关系  
页面时间：2022-05-29 15:37:07  
来源：[https://www.douban.com/note/832146202/](https://www.douban.com/note/832146202/)

加过一些房产中介的微信。大部分是爱刷屏的，早屏蔽了。还有些留着没屏蔽，是想看看他们每天关注些什么、发些什么。疫情以来，他们的朋友圈有个显著特点——好像除了楼市，疫情对生活没有任何影响。他们常让我想起杜牧的两句诗。看他们的朋友圈，仿佛生活永远红红火火，楼市永远大涨在即，除了吃火锅、撸串、店家促销之外，看不到任何悲欢离合。

去年看房时见过一个销售顾问，感觉人挺不错的，说话得体、有分寸，很为客户着想的样子。加微信后，一看朋友圈，大失所望。她很爱在朋友圈挖苦客户。曾经发过一张漫画：矮个子扬起手扇了高个子一巴掌，高个子捂着脸。高个子头上标着“我”，矮个子头上标着“客户”，“客户”一边抽“我”耳光一边骂：怎么不早点催我买房！矮个子表情狰狞，面目猥琐，高个子虽然挨了一巴掌，身姿倒有点潇洒倜傥的意思。

最近又见一个销售顾问发朋友圈，说有人跑到售楼处问：听说房价降了？售楼处：您在哪儿听说的？客户：抖音上。售楼处：那您去抖音上买吧！

这倒还不是让我想聊聊的主要缘故。主要还是，最近看他们的朋友圈，分明觉得，有些人似乎对我们正经历的一切毫无感觉——不管他是不是真的毫无感觉，但给你留下的印象绝对是这样。上海这两个月发生了那么多事情，而他们的朋友圈，始终岁月静好。除了“疫情之后楼市必将迎来报复性反弹”之类观点以外，再看不到疫情对他们的生活有任何影响。

他们也都生活在北京，很容易想到恒大融创相继暴雷之后，他们的日子恐怕不会太好过，但要是只看朋友圈，还会给你一种楼市越来越好了的错觉：“年中冲刺，好房价到”，“不可思议，瓜分6亿”，“涨价，我们是认真的！每个月都超额完成业绩的底气是……”

有人也许觉得，只有通过现实，才能了解到他们真实的一面，而朋友圈了解的都是虚假。但我想：也许有时候恰恰是反过来的。我在现实中接触这些人，还真判断不了他们说的哪句是真话哪句是假话，到底是真殷勤还是装殷勤，但是，观察过他们朋友圈一段时间，也就慢慢明了了。就像假如你不看朋友圈，在一个小县城生活，每天上街逛逛菜市场下下馆子，你不会知道上海的人以及滞留在上海打工的人他们正过着一种什么样的生活。

不久前网上看过几段大卡车司机在公路旁边搭火煮面条的视频，我们能够多少知道他们过着这样的生活，但他们在老家的亲戚、家人，恐怕都不一定知道他们这两个月是怎样过来的。所以，并不一定亲眼看到的才是现实。你没有办法根据今天亲眼看到的景象，想象明天菜市场突然一抢而空。也没有办法根据自己今天的生活，想象明天可能的遭遇。

眼见，不一定为实；文，也不一定如其人。尽管如此，看社会有经验的人，总还是可以通过种种迹象去判断，真实的变化正在如何发生。看文章有经验的人，有可能更多地留意到一个人该说而没说的地方，而不是他说了的地方。

最近看了不少刷屏的帖子，有些在朋友圈里，好像所有人都在转。但仔细留意，就会发现，转那些帖子的，永远都是相同的一批人，而有些人是从来不转的。对那些任何帖子都不转的人，我们是没有办法判断他的。但经常发朋友圈、经常转帖，却又从来不转一类你敢打赌他会看到、而且任何一个正常人看了都不至于无动于衷的帖子，对这种人，其实是可以稍作归类的。

据我简单的印象，至少有三种：一种是类似房产中介、汽车销售这些，他们的朋友圈就是用来搞营销的，除了发自己单位的宣传、公司的产品，别的什么都不发。

另一种，是小县城的人。朋友圈能看到他们的生活，但很少看到他们对陌生人的关心，哪怕他们当中有些人也会关注大国交锋、贸易战、俄乌战争，但很少看到他们会关心陌生人的遭遇。只要不是自己认识的人，不管多么不幸，好像都离自己很遥远。我每天至少下楼散步两次。常常在电梯里碰见保洁阿姨。几乎从来不说话，顶多是问问到几层。她今天早晨突然问我是不是在北京上班——她知道这一点毫不奇怪，我们这栋楼住的都是以前在一个家属院的人。但这个保洁阿姨为什么突然今天问我了呢？因为她侄子最近从北京回来，被隔离了。

第三种，是大部分体制内的人。像我最早工作的单位同事就是。在那么多加过微信的前同事朋友圈里，我几乎看不到谁转过上海隔离期间的不幸。唯一的例外是，有个养狗的前同事，因为柯基事件非常愤怒，转过帖子表达态度和心情。

上周写作课讲了《四世同堂》。讲到晓荷和瑞丰这两个人。日本人从天津请来专家给他们做测试，晓荷得了98分，瑞丰得了92分。按照标准，达到80分就是一等顺民。老舍说，根据得分，他们算是超等顺民了。但这两个人的结局怎么样，大家去看看就知道了。

去年年底，我被拉到酒店隔离了三天。那是从北京回到老家后。前三天，一点儿事儿都没有，提前在居委会报备了，回来进小区根本没人问，每天正常逛街遛弯儿。到了第四天，市里突然出来个通知，北京返乡的一律集中隔离，不管你来自高风险地区还是低风险。那会儿国务院发了文件不允许层层加码，我也打电话问了一圈朋友，但没有任何办法。

我当时搞到一张集中隔离的名单，加上我，七八个人。我就想拉个群，有什么消息，大家在里面沟通——因为真害怕三天后还会继续隔离。没想到的是，申请加一同隔离者的微信，大部分人根本不理我。只有两个人通过了请求。我问第一个人：您是不是也在这儿隔离？他不回。这让我都有点怀疑，他是不是没来隔离。

后来加下去才明白，很可能是他们觉得我这样做毫无必要。最终，我只建了个三人的小群，又重复问一遍“你们是不是也都在某某酒店隔离”，说有情况可以在群里沟通。后加的那人简单回答了“是”。直到解除隔离，群里再也没有说过话。

第二天，正是小年，我从隔离酒店的窗户上往外望，天空飘着雪花，酒店孤零零伫在郊野里。每过一两个小时，来一辆救护车，拉着不同的打工返乡者，看起来却像同一批人：都是铺单卷着棉被，拖着蛇皮编织袋。救护车一点点倒进酒店后门，人下车，消毒液朝身上喷几下，隔离的人消失在后门，救护车缓缓驶开，寂静无声。
