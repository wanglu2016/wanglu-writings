# 婚姻关系里中年危机的动力学

我们今天要谈的这件事，如果一开始就从年龄差、经济差距、社会地位差距这些看得见的特征切入，几乎一定会谈错。原因不是这些特征不重要，而是它们是表型，是一种结构在外部世界呈现出来的形状。同样的形状可以由非常不同的内部结构产生，而我们要谈的那种内部结构，也并不总是产生这些形状。所以从外部特征切入，你会同时把不属于这种结构的关系误判进来，又把属于这种结构但表型不典型的关系漏掉。要看清楚，得从底层动力学开始。

我先把底层结构讲清楚，然后我们再回到那些可见的形态。

每个人的认知系统里都有一组核心先验，这些先验是关于"我是谁"的最深一层判断。它们不是有意识持有的信念，是认知系统在进行预测时默认调用的参数。"我有价值"是一条先验、"我作为一个伴侣是有效的"是一条先验、"我是被需要的"是一条先验、"我是一个能保护和提供的人"是一条先验。这些先验的状态可以用一个变量来描述，叫精度——它们被这个系统持有得有多稳。

精度高意味着什么？意味着这条先验不依赖每一次具体的外部事件来维持，你做错了一件事不会让"我是有价值的"这条先验崩塌，你被人误解了一次也不会让"我是有效的"这条先验需要紧急修复。一个高精度的核心先验，它的支撑来自一段长期的、被真实校准过的历史——这个人曾经在一段关系里、在一份工作里、在某些时刻里，真实地暴露过自己的不知道、不能、错误、脆弱，然后这个先验在那种暴露中没有崩塌，反而被重新整合、被压实、被打磨成一个能承受现实的形态。这是先验被微分反馈过的状态。

但有另一种状态。一条先验从来没有被真正校准过——这个人的历史里没有过那种暴露——它只是被持续地、用大量低信息量的外部反馈维持在一个表面看起来稳定的位置上。它的精度不是源自内在校准，是源自外部环境持续的供给。这种先验是扁平的。它看起来在那里，但只要外部的供给一中断，只要它真正暴露在一个会挑战它的输入面前，它就会暴露出自己其实没有被压实过这件事。

一个人如果在自己的核心先验里有几条处于这种扁平状态——不是全部，通常是一两条特别脆弱的——他在选择伴侣的时候，某些事情就会发生。但要注意，他不是在做有意识的选择。他不会想"我要找一个崇拜我的人"，甚至他可能真心相信自己想找一个能挑战他、和他对等的伴侣。这件事发生在 routing 层级，在意识之下。他的预测系统在评估每一个潜在伴侣的时候，会评估这个人会让他的认知系统进入什么样的运行状态。某些人让他感觉对劲、感觉舒服、感觉"就是这个人"——这些感觉的本质是低自由能，是预测系统判断和这个人在一起，他的核心先验会被稳定运行而不会被挑战。某些人让他感觉别扭、感觉这个人太难、感觉和这个人在一起累——这些感觉的本质是高自由能，是预测系统判断和这个人在一起，他的某条扁平先验会被持续暴露在挑战之下。

他会朝低自由能的方向走。这不是道德缺陷，这是认知系统的标准行为——系统倾向于让自己稳定运行。但代价是，被选中的伴侣往往是那些不能给他做微分反馈的人。

我们现在可以回到那些可见的特征了，但是用新的眼光看它们。

为什么这种动力学常常表现为伴侣比他年轻很多？因为足够大的年龄差，会让对方在很多领域天然没有他的经验和资源。他可以稳定占据"那个知道更多的人"的位置。他不需要面对一个在所有维度上都和他对等的人。为什么常常表现为对方经济上依赖他？因为这种依赖一方面持续地让"我提供"这条先验有运行机会，另一方面让对方很难轻易离开。结构上的不可离开，是一种隐性的过滤——它过滤掉对方做某些反馈的能力。一个会因为给出反馈而面临关系破裂、经济崩溃、生活无着的人，在结构上是没有能力给出那种反馈的，即使她想给。为什么常常表现为文化资本或社会经验上的差距？因为这种差距让他在关系内部持续是"那个引导的人"，对方需要他的解释、他的判断、他的视角。为什么常常表现为对方有某种深层的依附需要？因为这种需要让她在情感上无法承受让他不满意，她的整个心理结构是围绕着不失去他来组织的。

但请注意，这些条件单独存在时不一定构成这种结构。年龄差很大但两个人在情感和心智上对等的关系是真实存在的；一方经济依赖但另一方仍然敢于真实表达和挑战的关系也是真实存在的。问题不在这些条件本身，问题在于这些条件加在一起，是不是结构性地排除了对方做微分反馈的能力。

什么叫微分反馈？让我具体讲。

一个真正能给他做微分反馈的伴侣会做什么。她会在他做错的时候具体地告诉他，而不是让过去。她会在他自我欺骗的时候穿透他的解释，不接受他给自己的那套合理化叙事。她会在他扮演某个角色的时候不接受这个角色，坚持要看到角色背后那个具体的人。她会在他的某些行为伤害到她的时候，让他真实地面对那种伤害，而不是替他把这件事消化掉。她会在自己有不同需要的时候坚持这些需要，即使这意味着关系里出现张力。她会在对他失望的时候让他知道，而不是把这种失望藏起来，以免动摇关系。

这些行为要求她有结构上的位置去做。如果她做这些会让她付出不对等的代价——她可能失去这段关系而他不会、她可能失去经济保障而他不会、她可能失去社会支持而他不会——她在结构上就没有能力做这些。她可能想做、她可能在某些时刻试着去做、但结构性的不对等会持续地把她拉回不做的位置。

而被选中进入这种关系的伴侣，她能做的反馈会被压缩到不威胁结构的范围内。她可以撒娇式地表达需要——这继续维持着依赖结构。她可以表达感激——这继续验证着他的提供。她可以表达想念、表达脆弱、表达对他的依靠——这些都不威胁结构。但她不能以平等的位置挑战他的判断、坚持和他不同的人生方向、表达对他作为一个人的某些方面的真实失望——这些会威胁结构，而结构是她生活的支撑。

于是关系内部不会出现强失配。注意，这不是因为他们配合得好，是因为任何会产生强失配的输入都被结构性地预过滤掉了——它们没有进入他的认知系统，所以他从来不需要处理它们。他的核心先验在这段关系里运行了多年，每年都在收到反馈，但收到的全部是非微分的反馈——大量的、高强度的、低信息量的反馈，只验证他的先验，不修正它们。

这种关系往往非常稳定。它可能持续数年、十几年、几十年。从外部看，它符合很多关于"成功关系"的标准——长期的、有家庭的、有共同生活的、双方都没有抱怨的。问题不会以关系崩溃的形式出现。问题会以另一些形态出现，而这些形态常常被归因到别的原因上。

他可能在某个时刻开始有持续的、说不清楚的不满足感——一种底层的虚无，一种"这一切看起来都对但好像哪里不对"的感觉。这种感觉的底层结构是，他的核心先验在多年的非微分反馈中已经变得越来越扁平，越来越不能处理任何稍微复杂的情境，而他的生活总会在某些时刻给他这样的情境。他可能在某个时刻产生强烈的逃离冲动——这常常被理解为中年危机，但中年危机这个词描述的是现象，不是机制。机制是，某些核心先验在长期失校准下达到了一个临界点，系统开始发出崩盘信号。他可能转向另一段关系或另一条路径——但仔细看，常常是在寻找一个新的非微分反馈源，因为旧的源已经维持不住先验了。

或者，对方在某个时刻发生改变。她经历了某些事——可能是某个人、某段经历、某次觉醒——她突破了原有的结构，开始能够做微分反馈。这时候关系会经历剧烈的震荡。因为对他来说，他的认知系统第一次在这段关系里遭遇真正的挑战。他面前有两条路：开始接受微分反馈，经历核心先验的深层重组——这是真正的成长，但也是真正的痛苦——或者离开这段关系，寻找另一个能恢复非微分反馈结构的伴侣。哪一条路被选，取决于他的整个认知系统在那个时刻有没有承受重组的能力。

这里我要讲最隐蔽的一层。

这种结构里有一种对称性，常常被忽略。我们一直在讲他的核心先验如何通过这种结构被维持，但她的核心先验也在通过同样的结构被维持。她的"我被需要"先验、"我被保护"先验、"我有一个稳定依靠"先验——这些先验同样可能是扁平的，同样需要外部的非微分反馈来维持精度，而这段关系恰好持续地提供这种反馈。两个人各自的核心先验都依赖这同一个结构，所以这个结构有非常强的内部稳定性。任何威胁结构的外部输入，会被双方共同抵抗。这是为什么从外部去劝这种关系里的任何一方"看清楚"，几乎从来不成功——你不是在让一个人重新评估，你是在要求一个双稳态系统同时让两个稳定态崩塌，这对系统是不可承受的。

那么怎么判断一段关系是不是这种结构？表型是不可靠的。年龄差不可靠，经济差距不可靠，社会地位不可靠。这些条件在很多正常关系里也存在。

可靠的判断标准在动力学层。具体而言，你看一个东西：在过去几年里，有没有任何核心先验在这段关系里被实质性地更新过。一个人对自己的某种自我理解——某种他原本认为是"他就是这样"的特质——是不是因为这段关系的运行被推动着重组过。如果答案是没有，如果两个人都很稳定、关系也很稳定、双方都各自停在自己的位置上多年没有动过——这种没有动，本身就是一个信号。真实的关系会推动核心先验的更新，因为真实的关系会持续地把核心先验暴露在微分反馈之下。如果一段关系运行了多年而双方的核心先验都没有动过，这段关系大概率没有在做现实校准。它可能在做很多其他事——提供陪伴、提供支持、提供共同生活——但它没有在做现实校准。

我想用一句话作为结束。

人在选择伴侣的时候，认知系统会让他朝低自由能的方向走。这是它的本性。但低自由能不等于真实——它只意味着这个伴侣会让他的现有先验稳定运行。一段做现实校准的关系，在很多时刻是高自由能的——它让你不舒服、它让你被看穿、它让你发现自己原来不是你以为的那样。能不能在某些时刻选择那个高自由能的方向，而不是被低自由能拉着走，这是判断一个人是不是在过一段真实关系的根本问题。这个问题和年龄、和钱、和社会地位都没有关系。这个问题和你愿不愿意，在那些感觉对劲的人和那些让你被看穿的人之间，选择后者，有关系。
