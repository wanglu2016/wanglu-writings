# 加微信和写邮件的基本礼貌

先说加微信。网上认识个新朋友，或者想找人聊点事儿，第一步通常是加好友。但你总不能直接丢个验证申请，啥也不写吧？微信那小框框虽然字数有限，可也不是让你留白的。上来至少得有个自我介绍，比如“我是小张，在XX群里看到你分享挺有意思，想跟你聊聊”。简单一句，名字、来历、目的全有了，对方一看就知道你是谁，不至于一脸懵。别小看这几秒钟的打字工夫，它能让对方觉得你不是随便加人的“伸手党”。要是再加点具体背景，比如“昨天你在群里提了阿毗达磨，我特别感兴趣”，那就更好了，既显得你有备而来，也给对方一个回应的切入点。反过来，如果验证消息里只有“您好”或者“加一下”，对方很可能懒得通过——不是人家高冷，是你没给人家理由。

再说发邮件。邮件比微信正式点，但道理差不多，最忌讳的就是“无主题”或者正文空荡荡。我见过有人发邮件，主题栏空白，正文就一句“附件里是我的资料”，连个称呼和签名都没有。这种邮件，收件人第一反应可能是“这是谁啊？发错了？”结果直接扔垃圾箱。要避免这种尴尬，其实很简单。首先，主题要写清楚，比如“关于加入阿毗达磨项目群的申请”——几个字就让对方明白你想干嘛，别让人猜。其次，正文得有头有尾。开头加个称呼，比如“尊敬的李老师”或者“张先生您好”，别直接硬邦邦地开讲，显得没礼貌。然后简单介绍自己，比如“我是小王，在XX平台看到您的文章”，让对方知道你不是天上掉下来的。接下来再说目的，比如“对您提到的AI项目很感兴趣，想加入讨论”，最好再加两句理由，比如“自己调过模型，也想学点古典文献的知识”。最后别忘了落款，写上名字和联系方式，比如“小王，邮箱xiaowang@123.com”，这样对方想回你也方便。整个邮件不用长篇大论，三五句话足够，但该有的信息一个不能少。

还有个共通的点，不管是微信还是邮件，别一上来就急吼吼地提要求。比如加了微信就问“你能帮我改代码吗”，或者邮件里直接说“请尽快回复我”，这种语气容易让人觉得你只想着自己，没考虑对方的感受。稍微缓和点，比如“我有个问题想请教，不知道您方便时能不能聊聊”，既表达了需求，也给了对方空间，谁都不会反感。毕竟，主动联系别人，本质上是请求一份信任，态度上得有点“求”的姿态，而不是“等着被伺候”。

当然，也别太拘谨，弄得像写八股文似的。礼仪不是让你端着，而是让沟通顺畅起来。微信可以轻松点，邮件可以正式点，但核心都是真诚和尊重。比如我在微信上加人，可能就说“我是老李，昨晚看你发的帖子笑喷了，想认识一下”，带点人情味儿，对方看了也舒服。邮件里可能会写“李先生您好，我是老李，读了您关于AI的文章很受启发，希望能聊聊合作可能”，稍微正经但不死板。总之，语气因人而异，但让对方觉得“你在乎他们”是底线。

最后提醒一句，礼仪不是讨好，而是给自己加分。你多花一分钟写清楚，对方就能少花一分钟去猜你是谁、想要啥。时间长了，这种习惯不仅让人愿意跟你打交道，还能让你在人群里多几分“靠谱”的口碑。反过来，那些上来就“在吗”“加一下”的人，可能压根儿没意识到，自己已经在第一步把机会丢了。学学怎么好好说话吧，别等AI都比你会写邮件了，才后悔没早点讲究起来。
