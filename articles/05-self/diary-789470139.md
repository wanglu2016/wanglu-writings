# 忏悔与庄严

看帖子，说有个修行人，称自己离明心见性还很远，不过，生从哪来、死到哪去早就明白了，还说要趁临死之前多忏悔，忏悔以前造下的罪业，尤其是因为一知半解给人讲经说法造下的口业，本来寿命到了尽头，为了把业障忏悔干净，“轻装上路”，决定多活几个月。

这是不动声色的修辞呀。诚恳谦卑地透露了自己有宿命通，还有续命法。要照书上阿毗达磨的说法，多少阿罗汉还做不到想多活俩月就能多活俩月呢。谦卑地表示自己离明心见性差得远，又诚恳地忏悔口业，就让人不由觉得他所说有据了。

这让我想起多年前，有朋友失恋后说，花了一整个下午，去梳理、复盘，把自己从恋爱到分手的经历仔细反思了一遍，想通了，终于轻松了。——这和那位知道自己从哪儿来到哪儿去的大德，是有异曲同工之处的。真以为可以靠这样复盘反思，把过去的恋爱经历想通、整明白，就像把从前造作的所有恶业忏悔干净。然而，依佛教看，至少从理论上说，大约不是这样子的。

我们下一盘棋，可以复盘，做一件事情，也可以复盘，但谈一场恋爱，去复盘，恐怕是难以复出什么结果的，更多的时候，不过是再咀嚼一遍往昔所尝欲贪的滋味，它以回忆的名义，让自己一次又一次浸润在那种氛围里、想象里，欲罢不能。

就像对事物理解根本不在同一层面、并不具备交流基础的两个人，产生了分歧，非要拉着对方：别走！咱们今天必须把这事儿掰扯明白不可！——能吗？恐怕挺难。干净利落的做法，是转身走了，再也不谈，对方怎么想，随他去吧。

我们每个人往昔所造的恶业，要想通过忏悔的办法，让它干净，永远都不可能。就像拿瓢舀大海里的水，想舀竭尽，是不可能的。每个人，在无量劫来，都造过五无间业，假如业有什么实体，尽虚空遍法界都不能容受，怎么可能忏悔得完呢。然而，业的本性是空的，像一切法一样，是空的，虽然是本性空的，但并不是所有的业在未来的所有时候，都失去了作用。有些业，未来还是会起作用的。什么时候起作用呢？就是在你回忆它的时候。就是在你不经意的时候——哪怕绝对没有刻意去回想它的意思，然而周遭熟悉的场景、曾经听过的歌词、熟悉的味道、一张照片、一处风景、甚至一个符号，都把你过去的业给勾起来了。

虽然过去的业过去了，但因为总会这样有意无意主动被动地勾起，会有新的作用产生，就仿佛过去的业还在那样。罪魁祸首，要讲到真正的根源上，也并不是过去的业，而是一遍又一遍地被重新提起。一个曾经的小偷，已经洗心革面了，如果你还是不停地揪出他批斗、写检讨，这是不给他重新做人的机会了。

业过去了，没有了，但它所造成的势力，像种子一样潜藏在有情的识海里，伺机待发，如果你有本事让那些不善的种子永远都不成熟的话，我们就说“业尽”了、“情空”了，用法相的说法，是“对治道”生起了。所以说，当法制完善，一切井然有条的时候，我们可以说“盗贼不起”了，我们并不是根据过去的事件给人打上“盗贼”的标签，通过枪毙所有的盗贼让世界安宁。一个世界只要没有盗窃的行为发生，我们就说它没有盗贼。被业熏过的识海，产生种子，也是这样。只要不善的种子不起，我们就完全不用怕它，它的存在甚至还是对我们有利益的，我们甚至要“留惑润生”，来圆满我们的菩提道。只是，让不善业的种子不起，并不容易，它长满了种种抓手，但凡有了适合的因缘，它就探出头了。就像田地里种子遍布，过了冬天，气温上升，有了雨水灌溉，它们就纷纷发芽了。

要提防它发芽，并不能用把种子全刨出来扔掉的办法，一是因为你刨也刨不完，再一个是因为，无论你扔到哪里，它都会在那里吐出根须，继续生长；也不能用灌水的方法把种子淹死。因为水量是远远不够把它淹死的程度的。“以欲离欲”，不是一般人可以做好的。因此，企图把它刨出来或者淹死，反倒会变成去给它松土、灌溉。

谈一场恋爱，过去了，就不宜再老想着如何处理和过去的关系；恋爱了，结婚了，就不宜再老想着如何妥善处理和过去的恋人还有异性朋友的关系。如果觉得很有必要处理又很用心用力，恐怕是越处理越麻烦的。就像在刀头上舔蜜，不要想着研究用怎样的添法、怎样的姿势，可以既舔到蜜，舌头又不被刀割破，最好的办法，是别再舔了。不要管它，该干嘛干嘛。这里的侧重点，不是“该干嘛干嘛”，而是“不要管它”。不是为了“该干嘛干嘛”才“不要管它”，而是为了“不要管它”才“该干嘛干嘛”。陕北民歌唱得好，“啊呀你不是我那哥哥呦噢，走你的那个路”，我们对待罪业诸障，也该是这么个态度——走你的那个路！不要黏黏糊糊磨磨唧唧，跟它一次又一次告别。

说要忏悔干净过去的业障，轻装上路，这多少像是借口。这不是轻装上路，而是临上路了，不断打包，生怕还有什么漏下。这不是要干干净净毫无挂碍地走，而是说到底对三界的种种滋味舍不下。我印象中，本焕老法师临终前，净慧长老去深圳看他，他已经昏迷不醒了，净慧长老走进医务室就说，老法师，该显本事了，还等什么呢。很快，本焕长老就往生了。这是干净利落、不拖泥带水的。要走就走，想来可以再来——说“走”其实也没有走，说“再来”其实也没有来。这是自在的境界了。不是决心要把业障忏悔干净的人容易理解的。

然而，绝不能因此废掉忏悔。忏悔是很好的，是一定要的。忏悔能增长有情的善根，让有情变得更好。只是，“忏悔干净”“忏悔完”，就难免包含妄想了。要忏悔，但并没有忏悔的对象。业是空的，像天空中飞过了鸟，却没有什么痕迹留下，不要以为真有鸟迹需要擦去。但忏悔本身，却是必要的，是方便，是“时时勤拂拭”的庄严。做一件事，不是为了什么结果，也不是为了过程，于是有真正的忏悔。幸好有永远忏悔不尽的业障，可以令我们生生世世永不止息地忏悔，而这忏悔，就成了庄严。
