# 昵称是随便叫的吗？

[文集首页](../../README.md) · [本类目录](../../catalog/05-self.md)

作者／署名：王路  
主题：自我、情绪与人际关系  
页面时间：2022-06-27 22:39:45  
来源：[https://www.douban.com/note/833724472/](https://www.douban.com/note/833724472/)

我曾经叫过一个朋友的昵称。不是当面叫，是把新书送给他的时候，抬头写的昵称。不是写“刘兄”“刘老师”这种。好在他是个男的。虽然是男的，现在想来，可能也不该用昵称叫他。

我跟他就见过一面，不算熟。在今天，见过一面，也许就不能说不算熟。毕竟很多朋友连一面都没见过。网络时代了嘛。有些从来没有见过面的朋友关系也不错。不过我跟他，只是简单的工作关系，所以说，叫昵称，并不合适。

他当然不至于向我泄露昵称。我是通过微博知道的。那是好多年前，我还看微博。他在微博上晒他和哥们儿同事的互动，不管男男女女，人家都那么叫他。所以我签书给他，也就跟着那么叫了。

我跟他也是朋友。但有些昵称并不是一般朋友就适合叫的。这么说吧，你看，郑板桥，自称“青藤门下走狗”，但你不能叫他“走狗”，尤其不能叫他“郑狗狗”——虽然你见他周围的男男女女都叫他“郑狗狗”，他似乎也享受，但你叫就未必合适。因为关系没到那份儿上。

关系没到，就叫，是僭越。有时候，一个小圈子里的人都那么叫，只表示他们是个团体。团体之外的人也这么叫，甚至会招来反感。我高中的时候，有些女生互相叫昵称，什么“小西瓜”“大樱桃”之类的。有个男生，也叫一个女生“小西瓜”。他不知道，虽然女生可以那么叫，甚至那女生喜欢的男生也可以叫，但他是不能随便叫人“小西瓜”的。

估计他也不是不知道，而是故意的。叫昵称，是暧昧的开始。如果人家不介意你用昵称叫她，你们的关系就会进一步，如果她反过来也给你取个昵称，用昵称叫你，你们的关系就又近一步了——“死狗”除外。但“死鬼”可以。如果能品出“死鬼”和“死狗”的差别，就算得到中文的三昧了。

昵称有正当的，有不怎么正当的。虽说关系可以无限亲密，但有些昵称是让人肉麻的。当事人可能不觉得肉麻，或者要的就是肉麻，但别人听到，耳朵是要发烧的，甚至肠胃都会有反应。

正当的昵称，比如王安石，你叫他“石仔”，这没啥，因为这个昵称是从他的名字中自然派生出来的。当然，也得有个前提：不是北宋那个王安石，否则你只能叫他“领导”或“相公”——不是白娘子叫许仙那个“相公”。对领导，是绝对不能叫昵称的。无论王安石还是蒋介石，叫他“石仔”，他就会把你宰了。

不正当的昵称，往往是情人之间才叫的。关系真的定下来，成了夫妻，反而不那么叫了。因为不正当的昵称其实包含了PUA，有时候甚至是相互PUA。通过昵称展示对另一个人的控制，或者彼此控制。控制与要挟往往是没有距离的。PUA中会体现出变态倾向，有时候轻，有时候重，轻的时候甚至不介意被人看到，重的时候，就不堪入目不堪入耳了。

网上有些情人撕破脸之后曝光的聊天记录。其中往往有肉麻的昵称。正常的关系、正当的关系，是不至于也没有必要用太肉麻的昵称的。这是典型的绮语。用太过亵渎的名字彼此称呼，不仅是对对方的不尊重，也是不自重，甚至，是对神的不尊重。

当一个人允许对方用过分亵渎的称呼来叫自己的时候，悲剧的隐患也会就此埋下。看起来的甜蜜，里面一定包含着苦果。很多时候，过于变态的昵称，会预示着不好的结局。齁甜的糖是不能多吃的，吃多了，就会从尿里出来。

有些昵称看起来正常，也不一定正常。比如“涛涛”，一个男人叫另一个男人“涛涛”，本来没什么奇怪——假如对方大名“山涛”的话，你给他写信，抬头可以写“涛涛吾兄”，最后落款，“社会你愚弟，康”。

但是，当一个男人名字里没有“涛”字，也没有任何其他人用“涛涛”叫他，只有一个男人用“涛涛”叫他——这也是有些麻烦的。因为“涛涛”显然是这个男人单独给他起的名字。在公开场合也许不叫，私下相处，他就成“涛涛”了。

尽管看起来正常，实际上仍然是控制。当一个人要单独给另一个人命名，并享有对这名字的独家使用权的时候，他是在通过名字宣示他的权利——对另一个人的独家占有权。

试想：为什么很多人喜欢用食物作为昵称？尤其是食物当中的水果？——比如大人把自家孩子叫“豆包”或“冰糖”。食物是容易唤起情感的东西。一个人用食物给另一个人命名，表面上看，似乎只是因为“可爱”，细究起来，恐怕不止是可爱，还包含了一种强烈的执著：要把对方看成“自己的”，吃定他。

“能吃的东西”和“不能吃的东西”，可以和自己发生的关系是不一样的。能吃的东西能含在口里，能放进肚子里，不能吃的东西你消化不了。很少有中产家长给孩子取名“搓板”或者“板凳腿”，因为那些不能吃。一个给小孩取名“石头”的家长，相比给小孩取名“豆沙”的，恐怕更希望孩子坚强与独立。比如刘姥姥和王狗儿给孩子取名“板儿”，可见这是贫寒的家庭，希望孩子命硬一点儿。而用食物给孩子命名，更重要的意义是“孩子是我的”“我爱他”——这种孩子你想吃定他，他将来是要反过来啃老的。

情侣之间，用食物给对方命名，或者作为自己的昵称，这一点就更凸显。男生给女生取名“樱桃”，也许因为“我最爱吃樱桃”。一个用水果作为自己昵称的人，也许潜意识里希望碰到一个能“把我吃掉”的人。尽管水果和动物都是人们最喜欢选取的昵称，但很少有人用“榴莲”，也很少有人用“刺猬”。因为榴莲带刺，而且闻起来臭。

很少有人用“煎饼果子”“鸡蛋灌饼”作为昵称，也很少有用“大列巴”。如果你去吃饭，告诉请客的人“整几个硬菜”，请客的也许一人整个大列巴——确实够硬。但这是不讨喜的：桌子腿更硬，可连老广都不吃。因此就知道，为什么情侣不用“大列巴”“桌子腿”当昵称——这样的对象，谁吃得消？
