# 国家、军队的雌雄属性略论（文/王路）

早上起床，编辑群里看到一篇稿子：《世界首个全民公投承认同性婚姻的国家居然是它》。领导问：是不是应该用“她”？这是小学语文啊。
编辑说，祖国才用“她”。领导截了一张新华社稿件，表示国家军队都用“她”。编辑说，那是我军，外军不可能。领导说，我军是母的，外军就是公的？编辑说：外军简直不是人了，只能用“它”或者“牠”。
正争着，扭头一看，值班老师已经把标题改了：《世界首个全民公投承认同性婚姻的国家居然是……》
其实，这不是个小学语文问题。这是个大问题。大到编字典和语文教材的人都未必能把这个问题搞透。因为它牵扯的不仅仅是语法。
为什么指代祖国常用“她”呢？
其实，这是一个被动的选择。是排除法的结果。不是要选择用“她”，而是用“他”和“它”都不合适，不得已，只好用“她”。
为什么用“他”不合适？某甲跟某乙见面，某甲说“贵国”如何如何，某乙也说“贵国”如何如何。其实某甲和某乙是一个国家的，而且就是在自己的国土上，为什么说“贵国”不说“我国”呢？这是一种修辞。
谈及自己的国家，说“他”，不是语法上不对，而是有跟国家对立的嫌疑。把自己的国家称为“他”，居心何在？难道已经拿到绿卡准备走了？
“他”这个字，暗含着“自他对立”的意思。不是自己一边的，才叫“他”。老太太给儿子夹肉，儿子不吃，夹给媳妇，老太太说，“你看看，给你的肉都给人家了！”媳妇恼了：“我是人家？！”
所以，官媒在提及自己国家时，能用“他”吗？不合适。“他”有两重涵义。广义的“他”，包含了“他、她、它”，表示other。在古代，就只有一个“他”字。辛弃疾“众里寻他千百度”，不要把辛弃疾当基佬。狭义的“他”，是和“她、它”并列为三的。提及“他”时，首当其冲的是广义层面的意思。
“它”为什么也不合适？其实，“它”在语法上是合适的。但是，当“它”和“他、她”并列时，首当其冲的涵义是“不是人”。要从“它、他、她”三种中选择，先问“是不是人”，再问“是公是母”。“不是人”不是骂人，可以是一种客观表述，但这种表述本身具备了骂人的功能。——你说祖国不是人？听起来好像在骂祖国。所以，“它”也不适合官媒用。
现在，只剩下“她”。有意思的是，这个经过排除法筛选出来的“她”，不仅止于能用，还能让使用体验特别好，给了使用者意外的惊喜。这种惊喜有两重。
按说，不是人的东西，应该用“它”。一座房子，我们说“它的屋顶”。但是，房子的屋顶真的属于房子吗？把屋顶拆了，房子一点都不会伤心，伤心的是房主。可见，房顶，这个机械地构成房屋一部分的东西，不属于房屋，而属于人。同样，房屋前的草坪，不是房屋所有，而是房主所有。唯有人，才可以拥有自身以外的东西。物是没有身外之物的。一物不具备拥有他物的能力，但是，人具备。
称自己的国家为“她”，就赋予了国家一层含义：她拥有某些东西。拥有什么呢？她的子民。这样，就相当于暗含着“我属于我的祖国”。这是非常有意思的——用“他”指代祖国的时候，凸出了个人和祖国的对立，用“她”指代祖国的时候，恰恰凸出了个人对祖国的归属感。
为什么会有这种情感色彩的区别？因为，“他”体现的是“父”的色彩，“她”体现的是母的色彩。父和子，对立意味很重；母和子，则包容意味更重。在“她”的身上，“自他对立”的色彩已经剥离掉了，凸显的是“女性”色彩。
在汉文化的语境下，“他”是“乾”，“她”是“坤”。乾是天，坤是地，乾是覆，坤是载。乾是高高在上的，所以才会说“子之弑父，臣之弑君”，对立的含义很明显。但坤德是“直、大、方”，是“牝马之贞”，像母马一样柔顺，构不成对立，她是承载你的。这也是为什么，说一个公司是另一个公司的“母公司”，不说是“父公司”。说“父公司”，就暗含着你和控制你的公司之间有一种对立，迟早有一天要把他干掉，摆脱他的控制。但是“母公司”不会，她是滋养你，充实你的。
这是用“她”指代祖国的第一重好处：暗示归属感。第二重好处是：体现女性的美德。也就是坤德，载物之厚德。滋养、哺育、慈爱、仁厚，这些色彩，蕴含在“她”里面。“祖国”是个庞然大物，用“她”来比拟，则“她”字暗含的“小女人气”不会显现，而“直、方、大”的一面会显现。
在这重意义上，用“她”来指代祖国，就不仅仅是一种不得已，还是一种主动选择，一种修辞手法。
既然祖国用“她”，那军队呢？
军队比较难办。之所以军队流行用“她”，是受了祖国的影响。细究起来，军队用“她”还真不一定处处都合适。
比如说，“她是人民的钢铁长城”——你家钢铁长城是母的？“她战无不胜攻无不克”——真是女汉子！
这些语境下，军队用“她”并不合适。之所以说军队难办，是因为在汉语的语境下，阴阳不是那么好分判的。有些语种里，很多名词的阴性阳性是规定好的，但是汉语，绝大多数的名词都没有规定阴阳属性。——这并不是表示汉语不重阴阳，恰恰相反，汉语太重阴阳了，以至于每个字都要分出平仄阴阳来。但是，既然音节上都规定，词性上为什么不规定呢？那是因为，汉文化对阴阳的认识太复杂，复杂到明白阴阳属性在许多情境下，是变化消长的，而非一成不变。
举个例子，一个男人在家里，夫为妻纲，他是阳，可以在老婆面前摆摆谱。到了公司，不行了，在领导面前低眉顺眼，变成阴了。但“男人”不管怎么说还有个性别属性，而对于万事万物，比如说，“宰相”一职，是阳是阴？
有人说，宰相嘛，国务院总理，那么大的官，自然是阳。错了。“相”的属性是阴。宰相是辅佐君王的，君为臣纲，君是乾，相就是坤。但是呢，“宰相”的“宰”字又有阳的意思。“宰”是“执事”的意思，引申为“宰制”，宰相对于百官而言，又有“首”、有“君”、有“乾”的意思。这就可以看出，汉文化里，许多词在不同语境下，阴阳属性不是一成不变的。
“军队”也是这样。军队的阴阳属性，《周易》解释得最明了。军队在六十四卦里是《师》。《师》，就是“众人”的意思，引申为军队。《师》卦的上下卦分别由“坤”和“坎”组成。一支军队的暴力属性，是由“坎”象来体现的。“坎”是险，是陷。说一支军队南征北战，所向披靡，这是“坎险”的属性。所以，作为国家的暴力机器，军队和法院、监狱一样，是阳性。
但如果要体现“军爱民来民拥军，军民团结一家亲”，那就不是“坎险”的属性了，而是“坤顺”的属性。体现一支军队“从群众中来，到群众中去”，是凸出《师》卦“地中有水”的“地”。
坤属阴，坎属阳。“坤上坎下”构成的《师》卦，兼含了阴阳两重属性。但从总体上看，《师》卦的主爻是九二，一阳为五阴之主。因此，单独提军队，没有具体语境时，是偏重阳性色彩的。
在英语里，提到祖国，也是用she，受祖国的影响，提到军队，也习惯用she，使用既久，就不复区分具体语境，而定于一是了。汉语受其影响，也渐渐惯于将军队称之为“她”。但“她”字不足以表现军队的温情，新兵蛋子到部队，动不动就挨尅，只有唱《军中绿花》的时候，才能感受到“她”的一面。
但不管是哪种，都限于自己的国家、军队。提到外国、外军，再用“她”就有点不合适了。不合适在哪儿？在暧昧。
比方说，一个姑娘养狗，在公园里边溜它边说：“来，到妈妈这儿！”如果你抢上前去，掏出一根香肠：“儿子，来，爸爸给你香肠！”这就不妥了。不妥在你占了人家姑娘的便宜。——称外国、外军为“她”，何以如此含情脉脉？个人出国旅游一圈，回来要表示自己对法国爱得不得了，称之为“她”，没问题；官媒称之为“她”，就有把别人老婆当自家老婆的暧昧了。
“他”、“她”和“它”的区别，不止于语法问题，还是政治问题。比方说，把上帝叫做“他”，在中国，问题不大；在西方，就需要商量——谁说上帝就得是男的？这暗含着一种性别歧视。
假如给一首歌命名，God is a ___。如果必须从man, woman, boy, girl之中选，唯一能入选的就是girl。不会God is a boy，因为boy这个词首先体现的色彩不是性别，而是年龄。这是由于在大多数人的想象里，god通常是男性形象。也不可以God is a Woman，因为Woman是以Man为词根的。
在汉语的语境下，就没有这么麻烦。古代，用来指代第三人称，常用的词就是：其、彼、他。这三个词，都模糊了性别色彩。如果要消除“自他对立”，用“其”就可以；体现“自他对立”，表示other，就用“彼”和“他”。
“他”在古汉语里没有性别色彩，“她”和“它”都含摄在内。近代受了西方文法影响，才有了“他”、“她”的区分，更有把“妳”、“你”区分开来的，但不流行。“妳”字过去是有的，意思是“奶”，也就是“乳”。我高中同桌给女生写情书，通篇是“妳”，在我眼里满纸都是乳房。
汉文化里，正因为阴阳的讨论太复杂多变，一事一物无法断然判其阴阳。《红楼梦》里，曹雪芹借湘云之口，向翠缕阐述了他对万事万物的阴阳判分。但是，汉语语境下的阴阳，并不简单等同于男女。
之所以古汉语里，不区分“他”、“她”，是因为在古代中国，男女关系相对固定，不存在异议。“天尊地卑，乾坤定矣。”并没有区分一物属男属女的需求。属于男人的东西是男人的，属于女人的东西还是男人的，连女人都是男人的。《红楼梦》里有“周瑞家的”、“王善保家的”，但不会把贾琏称为“王熙凤家的”。
在这种语境下，有些男人为了自谦，习惯把自己的东西叫做“拙什么”，自己的书，叫“拙著”，自己的文章，叫“拙文”，乃至自己的老婆，也叫“拙荆”。不过，一旦一物高于自己，就不能再“拙”了，因为此物已经不属你所有了。当今有一位不太通的学者，对人提及自己老师，称“拙师”。老师知道后说：为师有那么拙吗？
因此，古代“拙荆”、“贱内”可以丈夫用来称呼妻子，但妻子称呼丈夫就要用“外子”，而不能用“贱外”，不然人家会说：这女人还真是贱！为什么呢？因为夫妇一伦中，夫为尊，可以自“贱”以谦，妇为卑，就不可以自“贱”以下了，那就自暴自弃了。这正是“高者抑之，下者举之”的道理，是要符合“损有余而补不足”的原则的。妇人提及丈夫称“外子”，“子”是尊称，和“孔子”的“子”一样，表示“先生”。
今天，语境变了。一个妻子如果给丈夫面子，可以对人称丈夫为“我家先生”，如果不给丈夫面子，就称“我家干活的”。男人再敢“贱内”试试？回家就得跪搓衣板了。提到老婆，男人应该说“我家领导”，就像过去女人说“我家掌柜的”一样。
所谓“掌柜”，就是“掌”着“柜子”，因为值钱的家当全在柜子里。谁掌柜，谁就控制了经济大权。现在一般都是女人掌柜，男人在外边提到老婆，说“我家管钱的”、“我家领导”，都是贴切的。
但无论哪种情况，都仅限于自己家庭。就算在过去，称呼自己老婆贱内，可以；称呼别人老婆“你的贱内”，别人就一耳瓜子扇过来了：你老婆才贱！同样，今天提到自己老婆可以“我家领导”，提到别人老婆，就不一定适合说“你家领导”，万一上海人碰到个东北人，来这么一句，对方说：“我们家跟你们家治理结构不一样，在我们那儿，大老爷们才是领导。”
