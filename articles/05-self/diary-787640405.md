# 情绪警报仪

主题：自我、情绪与人际关系

看视频新闻，一对夫妻因为尿盆该放哪儿吵了起来，丈夫情绪激动，妻子担心他伤害自己和孩子，报了警。民警来后丈夫还挥舞着菜刀砍桌子，劝说无果，采取措施，丈夫被带走，刑事拘留了。民警在采访中多次说，“他的情绪始终处在一个高点上，下不来”。

我希望未来的科技能够出一款“情绪警报仪”。类似现在的手环，只不过，测的不是身体指标，而是情绪指标，情绪指标应该能够通过一些生理上的数据波动反映出来。假如按照佛教的分类，警报仪上可以有贪、瞋、痴、慢四项，或者再加上“疑”。数值从0到100，某一项低于30就说明该项稳定，高于70就危险，每项都低于30，说明情绪稳定；低于20，非常稳定；低于10，就是禅定状态了吧。睡眠状态下，指标也不会很低，痴甚至要比清醒时还高。

这样一来，我们就能知道谁是真正的“大师”，谁是江湖骗子。假如一个人几个月来平均指标低于20，那他非常厉害了。数据是不会说谎的。假如有人成天谈玄论道，喝茶讲经，测72小时情绪数据，平均60，那说明不太行。隐居在终南山的高人，带他到三里屯、后海酒吧、海天盛筵、澳门赌场待上几个小时，如果数据没啥变化，还是二三十，那就真是高人。看一个人在医院、殡仪馆、婚礼现场、空难飞机上的情绪数据变化，可以知道他是不是情绪真的稳定，有多稳定。这样，在寻找生意伙伴和生活伴侣的时候，也能有个重要参考，避免让身边埋下一颗定时炸弹。

平常人，可以借助情绪警报仪对自身情绪有个直观把握，情绪一旦飙升，马上被仪器提醒。比如某项升到70以上，就会引发警报，升到80以上，会引发更强的警报声，甚至你不能像按掉闹铃那样把它解除，除非情绪平复下来，指标滑落，它才消失。这样，我们对自己在做什么、处在怎样的状态会有更清醒的认知。

正在大街上走，突然后面猛按高音喇叭，“瞋”的情绪会随即从30飙到80，如果有人情绪还是30，要么他是大师，要么他是聋子。飙升是“苦受”引起的，耳根和声处和合产生耳识、苦受，苦受引发瞋的情绪涨起。不过，这样的飙升会迅速回落，因为响了一下后，就不再响了，也没有对你的耳膜造成实质性伤害，瞋的情绪会从80很快回落到70、60。但如果换种情况，一辆汽车从旁边经过，轧到水坑里，溅了你一身泥，瞬间瞋的情绪从30飙升到80，但下来会很缓慢，因为泥溅到身上，不像声音响一下就消失。衣服的脏会持续下去，而那辆车早跑了。不过，当你渐渐接受这是不可改变的事实后，瞋的情绪也会降下来，慢慢降到75、70，或者有别的事情发生，夺走你的注意力。这也和你当时的状态有关，假如你是刚买的昂贵裙子第一天穿，尤其是去参加重要宴会的路上，瞋的情绪会更高；穿着便宜的地摊货回家，就会相对低。

我们需要了解自己在什么样的情况下容易产生情绪。对小孩来说，往往看到好吃的会产生情绪，对成年人来说，看到好看的、想要的或者引发过去痛苦、仇恨记忆的，容易产生情绪。不同的人有相通之处，又有所不同，旧地重游的情绪，往往和别人不同，尤其是伤心地的重游。经过观察总结，有望让自己避免陷入情绪的洪流。

情绪像暖气管道的热水，似乎平静温和，但在很多生锈的接口处有崩裂的隐患。一旦炸裂或者不小心拧开，在极高的水压下，是难以拧回去的。然而，危险到来之前，我们甚至会放纵情绪的蔓延、享受情绪的蔓延。情绪的蔓延能让人感受到“自我”的存在，多少有舒服、安全的感觉。《般若经》中说，很多人听了空的道理会吓得半死，身毛倒竖，这不夸张，因为他们真正了解到了空的可怕，而深层的宁静是在巨大的可怕退潮后才逐渐显现的。而大多数人因为下意识就拒绝空，拒绝面对真相，所以哪怕天天抄《心经》，读《金刚经》，也不觉得空有什么可怕。

飙升的情绪容易被观察到，暗自滋长的情绪就难以察觉。假如某情绪指标突然从30蹿升到80，即便没有情绪警报仪，你也一样能察觉。但如果情绪是润物无声地爬升，从30悄悄到35、40、45、50……，很多人就难以及时警觉了。这可能发生在我们刷短视频的时候，看个搞笑视频，突然笑了，这笑是你没防备的，你也不知道从不笑到笑中间发生了什么，机理如何，你的情绪数据是怎样变化的。在看一场电影、阅读一篇文章、注目一张海报的时候，都会引起情绪的变化。

这些都还是容易监测的。如果情绪警报仪熟悉你的数据，它甚至可以通过对图像、声音的捕捉来预测哪些环境会引起你的情绪变化。嗅觉也可以监控，但稍微复杂些，触觉就有些难了。而最难的，莫过于心里想什么。有时候，仅仅一个概念就会让人兴奋或者愤怒，因为概念会勾起背后很多深层次的记忆。好在，概念也是由一些符号诱发的，或者因为看到什么画面，或者因为听到什么音乐，如果能把那些画面、声音、气味都摒除，置身于不同画面、声音、气味的环境，对情绪往往能起到有效的改良作用。但也有少数人，即便外在环境改变，也难以将他的心从某些极有吸引力的黑洞中拔出，那就难免遭受强烈痛苦了。

我们需要了解的是，某些东西对心的沾染，不是一天两天、一次两次形成的，是无数次串习的结果。像训练肌肉一样，每一件事情的串习，会让心和事情之间，和某些概念之间形成联系，这些联系会因为相近相似的行为被加强，也会因为相反相左的行为被削弱。我们越熟悉它是如何被加强和削弱的，就越容易让心从束缚中挣脱。只是，事物的相似相近与相反相左，实在难以察觉分辨。一个自以为坚定的学佛人，高喊着吃肉的人都该下地狱、遭天谴，他很难了解自己的诅咒和屠夫的宰杀是近似的。
