# 开放式关系是怎样伤害人的？

“开放式关系”这个表达，其实隐藏了一个字，就是“性”。我们说“开放式关系”，它是一个偏正短语，中心词是“关系”。表面上看，“开放式”好像是修饰“关系”的，限定“关系”的，其实不是，它隐藏了一个字，或者说一个含义，就是“性”。关系有千万种，同学关系是不是关系？哪个同学关系不是开放性的？你的小学同学，没有任何一个会提着刀站在你门口，说：我不允许你再跟其他人做同学。没有吧？同事关系有没有？开放不开放？也开放。

我们之间的关系，作者和读者的关系，主播和观众的关系，开放不开放？你们不介意其他观众来听吧？我也不介意你们随时就走，去听其他人的直播吧？——你看，单说关系的话，这个世界上99%的关系，它本身就是“开放式”的，那你再用“开放式”来限定关系，岂不是多此一举吗？可见，“开放式”要限定的词，表面上看是“关系”，实际上不是一般的关系，而是一种特殊的关系，和性有关的关系。如果说“开放式婚姻”，这个就很明确，因为婚姻就是一种特殊的关系。婚姻在正常情况下是不开放的，所以才用开放式来限定它。还有一种近似于婚姻的关系，就是恋爱关系。“恋爱关系”也有排他性、封闭性，本身不开放。为什么这些关系不开放？

婚姻关系当中的人，比方说丈夫对妻子，他限制不限制妻子跟别的男人说话？一般来说，是不限制的。正常的说话、合适的说话是不限制的。因为这些说话、交流，跟性没有关系。上街买个菜，交流个工作，都会跟异性接触、说话，没有限制。但是，也有一种说话，叫聊骚。带有暧昧、挑逗、暗示、撩拨性质的说话，限制不限制，对一般人来讲，都是要限制的。因为它已经和性有关了。有没有关系，取决于交流的内容。

所以说，“开放式关系”，实质上不是要表达普通的关系，而是在与性有关的事情上，放开限制。但是，使用这个词的人，他可能不好意思或者说刻意要隐藏“性”这个最关键的、具体的字。以便让这种限制的放开显得更合理。因为别的可以后天建立的关系，几乎都是开放的，都没有排他性。

注意这个地方说的“后天建立”。关系有先天的，有后天的。先天的关系，你是没有办法改变的。你不能说“开放性的父子关系”，王健林、王思聪，他们的关系能不能开放，王思聪找别人当亲爹，王健林找别人当亲儿子，这都实现不了。干的可以，亲的不行。这个关系你永远没有办法改变。戒律上有所谓“五逆罪”，前两个就是杀父杀母，那这个指亲生父母还是养父养母？比方说一个小孩，刚生下来就被亲生父母遗弃了，被养父养母养大，那么，他杀哪个是五逆罪？大家觉得呢？亲生的。养的不是。这是先天的关系。

但我们知道，这个世界上，人都是要死的，现在活在世界上的人，和一百年前的、和一百年后的，几乎都不一样了。那么，后面出来的那些人，他们的先天关系是怎样产生的？通过性。通过他父亲和母亲的性行为产生的。不可以改变的先天关系，就是这样产生的。而且是唯一合乎伦理的产生之道。如果不通过这种方式，你说我克隆，无性生殖，这是违反人伦的。除了性关系，其他任何关系都不能产生先天的关系，所以不能拿别的任何关系和这个关系来类比，来套。它们有本质的不一样。

我们想，猫狗对于它们的父亲母亲，是不是没有感情的？我家小猫，是捡的，人家把它遗弃了。遗弃的原因我不知道，但是很简单，没有别的原因，就是母猫生了一窝小猫，主人养不了，就扔了。从原来的主人扔它或者把它送人的时候，它就注定这辈子不会再见到它的母亲了。它和它的母亲之间，也没有什么感情。更谈不上去赡养。这就是动物之间的关系。动物里面有“赡养老人”这种概念吗？没有。动物的生命是非常悲惨的。相比人来说。有人不觉得啊，有人觉得宠物猫可幸福了。那是你的观点。我不这么认为。人类社会有各种节日，我们会过年，猫狗永远不会。你能不能想象取消了所有的节日的生活？动物的生命里是没有节日的。人类有隔代的关系，爷爷奶奶可能会对孙辈很宝贝，动物里面没有，猫狗甚至不知道自己的孙辈。

人之间有这么一种关系，抚养子女，赡养老人，这是义务。这是先天的关系带来的。有个词叫“天伦之乐”，天伦之乐是从人伦来的，是在人伦的基础上，由先天的关系，带来的一种快乐、幸福。动物没有这种天伦之乐。所以动物的精神享受，相比人要贫瘠很多、匮乏很多。

开放式婚姻会侵蚀乃至摧毁“天伦之乐”。一个人如果保持开放式关系的话，那么，性伴侣对他来说，不是独一无二的，那么，生下来的孩子对他来讲，也不是独一无二的，而且由于双边的开放性，男的如果不做亲子鉴定，他都不能知道小孩是不是他的，即便小孩是他的，他对小孩的感情，和封闭的婚姻关系中，父母对小孩的感情，也是有明显差别的。古代的封建帝王，他的性关系是半开放的，我们注意到太子和皇帝之间的关系往往很不好，要竞争太子的皇子之间的关系更不好。这当然有权力带来的吸引力，还有一个重要原因是，太子的父亲的婚姻关系是半开放的，这也就意味着，一个皇帝生的儿子越多的话，他花在一个儿子上的精力和心血往往就会少。那感情自然会薄。

开放式婚姻中产生的小孩，和父母的关系会相对淡薄。因为很显然，你不是唯一的，你是偶然的。一般来说，夫妻之间越恩爱，他们对和对方生下的孩子的爱也会越多。但他如果和伴侣之间是开放的关系，那么，父母和孩子之间的关系，虽然是先天的，也在一定程度上削弱了，开放化了。这样的小孩他得到的不是天伦之乐。他在生下来的时候，一种基于人伦的幸福可能，已经被先天地剥夺了，或者至少是削弱了。削弱的根源在哪儿呢？在于他的父母保持的这样一种关系。所以，开放式婚姻实际上是剥夺他人的幸福（也就是儿女的幸福）来满足自己肉体上的欲望的一种方式。

有人说，我不要孩子，不要孩子会剥夺谁的幸福呢？——哪怕你不要小孩，你内心当中也会住着一个小孩。你希不希望你对自己的伴侣来说是独一无二的？你希不希望你的伴侣看你，就跟看大街上的路人甲一样？——不管你希不希望，你内心里住的那个小孩，他是肯定不希望的。除非你把内心里住的那个小孩也杀死。而你一旦把内心里住的那个小孩杀死，你不介意你老婆看别的男人跟看你一样的时候，实际上你们的伴侣关系荡然无存了。你对他就没有感情了。我们对外物产生感情，其实就来源于内心住的那个小孩。你可以牺牲他的幸福、剥夺他的幸福，去换取你的满足，但这个是要付出代价的，他会报复你的。
