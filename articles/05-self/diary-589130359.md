# 难得相信自己是平凡的人

[文集首页](../../README.md) · [本类目录](../../catalog/05-self.md)

作者／署名：王路  
主题：自我、情绪与人际关系

知乎上，有人问：总是觉得自己很多方面不如别人，怎么办？
其实没有办法。无论你过得多么好，还是有很多方面不如别人。
我现在，经常在晚上六七点，打开地图看看路况，看到北京堵成一团糟，想到自己不用上班，就觉得比很多人幸福。有时候，在快餐店吃汉堡和鸡翅，再要个冰淇淋，就会边吃边想，世界上有很多人，不如我现在吃得开心呢。
朋友说，为什么你的幸福总是建立在别人的痛苦上呢。我也说不清到底是不是这回事，毕竟，很多幸福来自跟别人的比较。同样，很多痛苦也来自跟别人的比较。北京的路况不会因为我不上班而更堵，但我想到不用挤地铁，就会对自己的生活满意很多。
其实，我上班时，也不用挤地铁。因为没有房子，在哪上班，就在哪租房。后来甚至连坐班都不用了。
唯一的例外，是刚毕业那会儿，单位跟外面公司有合作，老是需要我跑腿送文件。那时候经常挤地铁，赶上早高峰，挤了好几班都挤上不去，我就想，自己挺幸福的，别人天天都得上班，我一星期也就送一次文件。
其实，挤地铁的人里，十之七八都比我工资高。我那时候，一个月2600块钱，是2012年。出门办事本来可以打车，但打车票要等到一两个月之后才能报。领导工作马虎，常常把我的票搞丢，或者把我的票当成他的票，我又不方便解释，干脆就不打车了。好在当时地铁还没涨价，到哪儿都是两块钱。下了地铁如果还有一段路，我就走过去，反正是上班时间，就当遛弯了。
刚工作的头几年，特别穷。要靠写文章来补贴日用。但也没觉得太糟糕。唯一糟糕的是，文章常常刻薄。当然现在也会有。不过越来越能理解，如果文章刻薄、犀利（它们往往是一码事），一般都是作者有心结需要纾解，又不愿意去选择艰难的路，或者是不懂得如何选择。
就好比有人不高兴了，爱对人家发脾气。他觉得脾气就像桶里的水，倒出来，桶就空了。其实不是。脾气像桶里的空气，只要有桶，就有空气，越是可着劲儿往外倒，越能感受到空气。放那儿不动，虽然有，也感受不到了。
知乎上那个问题，我的回答是：不如别人就对了，如果能高兴地看到自己不如别人，很多问题就迎刃而解。随喜赞叹别人胜过自己的地方，没有比这更大的功德了。
当然，理论上是这么回事，实际上做起来很难。我也做不到。看到别人涨工资自己不涨，还是郁闷。看到别人学一样东西很快上手，自己怎么都学不会，还是挫败。
因此，相信自己是平凡的人就尤其重要。相信自己是平凡的人，才能接受自己记忆力一年比一年差，皮肤一年没一年好，身体机能各方面一年不如一年这些真相。
不是相信自己平凡，是相信自己是平凡的人。一个人即便口头上承认自己平凡，还是挡不住心里想，平凡的人也有不平凡之处，平凡的岗位也能做出不平凡的事。实际上，平凡的岗位基本上做不出不平凡的事，即便有，和不平凡的岗位做出的不平凡事相比，也平凡得不得了。不然怎么能叫平凡的岗位呢。
讲不平凡，都是骗人的。讲别人伟大，是恭维。讲自己伟大，是吹牛。相信自己不平凡，那就是自欺了。很多人公开场合不断强调，自己就是个普通人。心里未必这么想。一个普通人不会强调自己是普通人。没有哪只猫会跑到你面前说，看，我是一只多么普通的猫啊！
心里不肯承认自己的平凡，要跟平凡的人生较劲，很多烦恼、痛苦和错误，就是这么来的。
人为什么作恶？一个人要想发现自己的力量，作恶是最简单的方法。你想给笔记本电脑装系统，怎么装都装不好，想下载个东西，下来下去发现都是恶意程序，好不容易找到正确的，又要注册，注册完了又要金币，金币攒够了，花好几个小时下完了，发现不能用，人就崩溃了。之所以崩溃，是因为你自始至终都在努力做建设性的事情，最终发现徒劳。于是强烈地感受到自己的无能。
破坏性的事情就很简单。抓起笔记本砸到地上，立马能看到成果——想成一件事不容易，想坏一件事太容易了。破坏也是改变世界，虽然是把世界往糟糕的方向变。这样改变世界，又快又直接。
人们怕自己无能。但无能是无法撼动的事实。所谓无能，不是什么都不能，而是，只能参与，却不能保证结果。因为惧怕正视这个事实，就要努力制造出一些表面上的变化去遮掩。无论是把事情搞顺，还是把事情搞砸，看上去都要比事情一点变化都没有更让人舒服。但把事情搞顺是非常难的，把事情搞砸就很容易。所以很多人，事情但凡经过他的手，没有搞不砸的。正是因为他急切地想证明自己不平凡。
人们需要看到结果，才能相信自己的意义，了解自己的力量。如果一件事情没结果，哪怕很用力，还是会觉得无力。
《伊索寓言》里有个故事，驴子驮一包盐，觉得重，耍滑头，该过桥的时候不过，要从河里走，淌了一趟水上来，盐包轻了一大半。驴觉得自己聪明。商人要治驴，下次驮盐之前先让驴驮一包棉花，驴又从河里淌，上岸累得半死。
人的小聪明跟驴一样。因为偶然的机缘和运气，一些事情成了，就觉得自己牛，不肯认为自己平凡。直到后来驮棉花累得半死，才发现自己还是不行。
王维有一首诗：木末芙蓉花，山中发红萼。涧户寂无人，纷纷开且落。枝头绽开的像芙蓉一样的辛夷花，在深山吐出她的红萼。清寂的涧户没有人经过，她们落了又开，开了又落。一个甘心平凡的人，就像涧底的辛夷花一样，在无人知晓的地方，安静地开，安静地落。
