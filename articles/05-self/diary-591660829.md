# 写日记的坏处

作者／署名：王路  
主题：自我、情绪与人际关系  
页面时间：2016-11-12 23:03:23

小学五年级时，班里有个差生，性格孤僻，成绩倒数，经常作恶，还被带到警察局里过。一天中午，几个学生在教室打闹，不小心把他课桌碰翻，掉出来一本日记。他当时不在，同学就打开看了。我也看了，里面大部分内容都忘了，但有一句话印象深刻：我也想做高材生。
从小，老师就鼓励学生写日记。不是那种需要交给老师批改的日记，而是把自己每天所见所想写下来。前人有记日记的习惯，清末民初，风气尤盛。曾国藩、鲁迅、郑孝胥、阎锡山，蒋介石，无不记日记。似乎记日记是很好的习惯。但就我个人记日记十多年的经验来看，这个时代记日记，也有坏处，坏处常被人忽略了。
我是从大学一年级开始频繁记日记的。小学、初中、高中也试过，一般是新买了笔记本，觉得挺好，就打算记日记，字也工工整整，写了几天，想不出写什么了，字也歪歪扭扭了，就放弃了。到了大学，初次离开家乡，颇有些不适应，就渐渐养成了记日记的习惯，多的时候，一天记好几次，日记上都写上几点几分。间断的时候，一般是寒假回家，天冷没暖气，写字不方便，又走亲戚，也就停掉了。到大四毕业，记了19本日记。
那四年是我记日记最勤的时候，也是比较压抑，不太顺利的时候。时隔多年，我才慢慢意识到，过得不开心和记日记，有相互助长的作用。不是一切时候，但有时候确实如此。
人什么时候愿意写点东西呢？除了本身就有面向公众写作习惯的人之外，一般人平时是不大写东西的。但碰到一些事情，心里有些波澜，或者突然空闲下来，感到孤独空虚，就容易萌生写点什么的想法。
写作有两种，一种是面向大众的写作，一种是私人化的写作。这是约两个极端说的。实际上，我们平常的写作常介于二者之间。如果你写的东西希望看得人越多越好，就是面向大众的，但面向大众也并非面向所有大众，比如，你虽然希望更多人看，却不希望自己父母或者学校老师、老家亲戚、公司领导看到。私人化的写作比如书信、邮件，最极端的情况是私密日记。
私密日记有个好处，可以借此梳理自己的生活。失恋了，写个日记，希望好好分析分析，从对情感的困惑中走出来。要升迁了，写个日记，展望一下未来。新年了，三十岁了，写个日记，记下有哪些愿望想实现。总之，不常写日记的人，偶然写日记了，多半有想开启新生活的打算。
在日记中观察自己过去一段时期里过得好不好，哪些地方做得不错，哪些地方还要努力，是记日记的好处。它有助于人去跟自己内心对话，去更全面更细致地认识自我。但同时，也衍生出不好的地方。
由于记日记是跟自己的对话，没有记日记习惯的人，碰到事喜欢跟别人讲，到别人那里讨主意，或者求安慰。一旦有了记日记的习惯，会发现跟自己对话比跟别人对话舒服得多。失恋了找闺蜜倾诉，闺蜜说，那个渣男有啥好稀罕的，你本来有一肚子话想讲，讲不出口了。也许她不是不想听你讲，而是双十一正忙着抢东西，怕你耽误她抢货。
说话需要时机。越是贴近内心的话，对时机要求越高。有些话一定得喝掉半斤白酒后才好开口，一个男人不会在上班时间跑到战友办公室里说，我老婆出轨了，一定得说，晚上一块喝点酒吧，心里不舒服。喝到半夜，餐厅打烊，再换到路边摊上喝，讲话的时机就慢慢到了。
由于越是藏在内心深处的话，对人、对时机、对氛围的要求越高，有些想说的话就只能憋在肚子里。情侣之间打电话，本来有件事特别想说，看到对方心不在焉想挂电话，就没法说了。
但日记不挑这些。你什么时候想写日记，日记本都不会拒绝你，也不会对你写的事表露出厌倦。你也不用担心什么时候结束话题。更不用担心万一说了不该说的话，以后感到难堪。
正因为这些，通过日记和自己交流，容易让人上瘾。尤其是人在长期的苦闷当中，找不到适合倾诉的人，就更容易依赖日记，依赖和自己的交流。如果过得好，工作忙，交际多，日记自然而然就少了，顶多是流水账式的记几笔，浮光掠影，不会像失意时长篇大论，剖析内心。
这是尤其应当留意的。当一个人过于依赖和自己交流的时候，对和别人交流的需求就淡了。如果没有记日记的习惯，碰到事还会向闺蜜倾诉，记日记记得很痛快的时候，很多事你就不愿意跟别人讲了。所以，失意的日记，其实是一种社交。自己和自己的社交。由于这种向内的社交，人开始摒弃向外的社交，慢慢就有了孤僻的倾向。
孤僻并不是最可怕的。更可怕的是，在这个过程中，人容易固化自己的认知。当你和另一个人交流的时候，相左的意见会被提出来，你会得到反馈，于是有机会看到自己对世界的理解和他人不一样。但在写日记当中，日记本从来不会反对你，批评你，你自以为是的观念容易得到巩固和加强。有可能你对世界的看法已经大错特错了，也没有人告诉你，你反而会益发深信。有可能你的精神已经开始有点不正常了，但在你看来，那是众人皆醉我独醒的深刻。
写日记的初衷，本来是为了梳理生活，更好地了解自己，认识自己，但如果摒除了同外界的交流互动，而陷入自我情绪的漩涡，想理解认识自己就更难了。
我看到那位小学同学的日记，心想，如果他能有哪怕一个朋友，能有一个人愿意听他说“我也想做高材生”这种话，也许他就不会走向孤僻作恶的道路。当然，孤僻的性格多半来自家庭的不睦，父母的疏于照管，但当一个敏感幼小的心灵，寻求不到外界的支持安慰，而不得不转向自己消化咀嚼的时候，孤僻的种子就得到霑溉迅速萌发了。
