# 同学，集赞不好

早上在公众号后台看到一条留言：“我就是在朋友的介绍下开始关注你的文章的，请不要让我们失望，更不要让我们粉转路。”
搞不明白怎么回事，很纳闷，不知道她是谁，也不知道哪里得罪了她。于是去查她以前的留言，发现了这几条：
“一句厂家不按点赞票数选就可以把人打发了吗。”
“我是发到微信群里面，发红包给人家才点赞的。”
“还在朋友圈也发了。”
回想起来了。以前，我在公众号上做广告，厂家说，留言最用心的两位，有礼品赠送。她给别人发了红包，求别人给她的评论点赞，最后赞数上升到了第二，就来留言问我怎么不给她礼物，我说，不是按赞数选的。
为什么不按赞数选呢？其实最早是按赞数的，但因为我常把一些其他评论放出来，比如“王老师，今天加块肉吧”，这种评论的赞数会比评价产品的高得多。后来再做广告，商家就改了文案，文案写的就是“最用心”，不是“赞数最多”。
但这位网友，因为拉了赞，却没拿到奖品，不太高兴，觉得我让她失望了。
这件事，让我挺感慨。写公号两年多，还有一些感慨的事情。
有次，我给读者免费结缘书，每人一套。因为免费，要的人就特别多，最终只送了前面的2900多位。在整理地址时我发现，有的读者，用一个微信留了许许多多不同地址，连省份都不一样。我想，她大概是借这个机会把亲戚、朋友、同学、老乡，一人送了一套。
那个活动过去很久之后，有人告诉我，他在旧书网上买到了。我上去一搜，果然，一本卖39块。
还有的网友，经常在我的文章下留言，“赞赏不多，一点心意”，留过几次之后，我就记住头像了。觉得挺感谢，就把鼠标移上去，看看他一共赞赏过多少次。竟然发现，赞赏次数是0。这位老兄大概不知道，后台是可以看到赞赏次数的。
我也收到过很多次这种留言：文章这么烂，还好意思骗赞赏？我也会忍不住把鼠标移上去，没有一次是例外，他们的赞赏数都是0。
在评论里批评我、指点我、告诫我、教育我的人，我也会好奇地看看他们有没有赞赏过，也基本上是0。倒是那些说话和和气气的，哪怕是和我观点相左，也彬彬有礼地指出的读者，赞赏得比较多。这也让我更加相信佛教所说的，爱施与的人更快乐。
几年前，我在国际广播电台上班。有个不知道哪里的男子，冒充我们日语部的员工，开了个微博，说是国际台日语部官方微博，有几十万粉丝，比真正的官微都多得多。后来大家一打听，根本不知道这人是谁，就一起举报，新浪把他删号了。
没想到的是，这个人又重新注册一个号，还是冒充我们单位某部门，一夜之间又涨了一万多粉。怎么涨的呢？也很简单。他发一条微博，有奖转发，奖品是国外某个牌子的巧克力还有红酒，价值三千多元。一夜之间，就有六千多用户转发。
我们做微博的编辑，每天兢兢业业挑内容，配图，认认真真做，一条转发量也只有十几。看到骗子的微博，她们都要哭了。
但是没有办法，很多时候，人性就是这样。
以前我在运营部门也待过，里面的事也清楚一点。很多事情，其实动动脑筋就能想明白，不过还是有很多人不知道。
比如，但凡厂家搞活动，你要看是送小礼还是送大礼，如果是送小礼，广泛地送，也可以参与。如果送大礼，广泛地送是不可能的，预算不够。——iphone6刚出的时候，有个同事提议公司采购100台送给用户，预算六七十万，做一场“现象级”的营销，被领导一秒钟否决了。
公司送奖品，如果送的不是自己的产品，基本上都不是自己出钱买的，都是资源置换。和电影院谈合作，电影院给点票。如果是低端手机，或者少量高端手机，也可能是跟手机商合作。如果是苹果最新产品，你放心，基本上不是跟苹果公司的合作，那种你想通过抽奖赢，是不太可能的。能抽到的，一般都是员工的亲戚朋友。
虽然这是套路，但每次用这种套路，还是有很多用户疯狂地参与。也许他们觉得，即便只有千分之一的概率，也划算。
不排除有公司真的愿意给用户大奖，但要知道，那种运营的性价比是很不划算的。而且，即便拿到奖，我想，也未必是好事。守株待兔的事，不会好。所以我从来不买彩票，也不参与有奖征集。
说到有奖征集，也是坑。比如，看到朋友圈里有人转某知名导演为新电影招募演员的消息，写得很具体，要求长相好，身高多少，不能整过容等等，符合条件的加微信或者给某个邮箱发简历照片。其实根本不是真的要招演员，就是为了宣传电影。
一本书出版前，作者常常向读者征集书名。说自己绞尽脑汁想了好多，编辑都不通过，只好向读者求助，集思广益，被选中的有什么奖。其实，搞不好征集书名的时候，书已经下印厂了。——这时候往往会说，书的原名叫什么，但我们觉得还不太满意。——这就是为了避免读者误打误撞取到一个给原名一样的名字，其实原名就是定了的，就是要让大家参与进来，记住这本书。你在拼命想名字的时候，人家正在偷着乐呢。
募捐、公益的事情，这种就更多了。所以，参与请尽量谨慎，问问自己的动机和发心。尤其是，不要轻易去发动别人。在你很确定这是一件好事，关键是对别人也很好的时候，再去发动别人，才容易避免过失。
