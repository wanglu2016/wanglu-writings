# 撕裂与分歧

安倍遇袭那天晚上，我刷朋友圈，看见凤凰网的前同事转一条视频。是安倍中枪前后的几十秒。微信视频号有一点我很烦，只要手指碰到视频，它就默认你点了“隐藏赞”。有时候，想往后拉进度条，而进度条是隐藏的，你点上去找，它就算成你点赞了。

关键是，你还不能直接取消。想取消，需要再点一下，把“隐藏赞”变成“公开赞”，之后点第三下才取消。——这就意味着你已经“赞过”了。我不知道是谁这么设计的。我比较反感这种设计品位。它就跟充一个月的会员，系统会每月自动扣费，而取消又很隐蔽麻烦一样。它强迫你把“隐藏赞”变成“公开赞”之后才能取消，这是很恶心的事情。

总之，没有办法，我只能多点两下，先把“隐藏赞”变成“公开赞”，再取消它。这时候，我收到一条微信。我取消后，退出视频，回复了微信。过了会儿，担心没有取消成功，又从朋友圈里找出那条视频点进去，发现竟然真的没有取消，仍然显示我赞过。我赶紧再点取消，又从别的入口进去，再三确认。

我认识个代上车牌的小伙子。因为加了微信，能在朋友圈看到他的生活。有次他女儿不在家，儿子玩得疯，他发朋友圈说“你姐不在家，你来当大王”。他还晒七夕发给老婆的红包。老婆买了榴莲，他晒图说“败家娘们儿”。后来他的车换成了奥迪，经常晒仪表盘骂太费油，说“油门都不敢踩了”。安倍遇袭后，他发朋友圈：一个快70岁的老人被枪杀，你们还在那儿庆祝，底线在哪里？道德在哪里？——接下来几行空白之后：酒席在哪里？我坐哪一桌？配着撒花欢呼的表情。

我不意外。尽管之前，我从没见他对公共话题发表过看法。曹雪芹写贾宝玉、赵姨娘、薛蟠、邢大舅，他们不是生活在今天，甚至都不是历史上真实存在的人，但是，他们对于类似安倍遇袭的反应，是可以推测的。像代上车牌的小伙子发的朋友圈，如果是薛蟠发的，我一点儿也不奇怪。但绝对不会是薛宝钗发的。尽管薛蟠的挥金如土、游手好闲、吊儿郎当和上牌小伙子截然相反，但我觉得他们在某些事情上的理解和趣味会类似。

小伙子很实在、朴素。对家人、对朋友，应该都没啥说的。他也没有恶意，只是觉得好玩儿。我一看那条就知道是他转的，而且能想象他在别处看到那条评论的样子：“哈哈哈，谁写的，太XX有才了！” 于是随手转到朋友圈。

因为移动互联网，我们很容易接触到形形色色的人。老话说，“人上一百，形形色色”——“一百”主要是为了押韵，因为“色”字读sai。但今天，如果谁的朋友圈只有100个人，那也太少了。上一千都不算多。由此，朋友圈常常给人“撕裂”的感觉。但我不觉得撕裂真正存在——那只是因为人们有机会接触了解跟自己不一样的人的想法。我在朋友圈看到过顺丰小哥的内容，十条里有九条是顺丰广告，剩下一条你猜是什么？——因为过年放鞭炮，他被派出所处罚并写了保证书发在朋友圈，表示深刻认识到了错误，决心悔过。

二十年前，我们不会那么容易听到和自己不太一样的人的声音。现在更容易了。古代绝大多数老百姓，一辈子并不需要与多少人的生活发生联系。但今天，我们需要与太多人发生联系。所谓“撕裂”，我觉得倒是一种便捷的方式，帮助自己了解谁是和自己拥有近似价值观的人，谁不是。

如果没有这些，了解一个人是不容易的。你可能要跟他接触很长时间，甚至是一起共事很久，才发现难以磨合、难以接受的地方。而有了这些，是可以事前预测的。所以，并不是“曾经是朋友，后来因为某个议题，失去了朋友”，而是本来就是两类人，只是曾经缺乏足够的了解，误认为是朋友。

“误认为是朋友”并不是说别人就不好。人家可能也不错。只是在某些事情上，和自己的理解确实不一样。如果一起相处共事，在面临决策的时候，就会出现分歧乃至冲突。“不是朋友”也不意味着不能进行有限的合作，和适当的互助。只是，并不因为合作和互助，就把对方看成朋友。

“是不是朋友”，并不是由个人乃至双方意愿决定的。而是有客观基础的。客观基础就是：你们对世界的理解、对生活的理解是否近似。再具体点儿说，对一种行为是不是得体、是不是高雅、是不是有品位，你们拥有相似的看法。

大家都认为好或者不好的事情，是没有区分度的。你不能靠它区分出周围哪些人跟你的价值观、审美、判断力接近。但让朋友圈“撕裂”的事件往往是可以的。不同的人，早早知道彼此的不同，并不是坏事。
