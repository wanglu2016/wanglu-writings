# 解脱的关键在如何对待感受

[文集首页](../../README.md) · [本类目录](../../catalog/05-self.md)

作者／署名：王路  
主题：自我、情绪与人际关系  
页面时间：2020-09-03 20:46:36

辛苦不止是一天到晚都得干活，更体现在，哪怕闲下来，脑子仍然会被某些事情牵缠，不自觉地要去想它。我们常说“思想的自由”。而解脱，是“不思想的自由”。换句话说，我不愿意去想一件事情，完全可以不去想它。没有任何外力或者外境，能够逼迫我、诱导我，去想任何一件事情，这是真正的自由，也是解脱。彻底的自由，不是不愿意做的事情可以不做，而是不愿意想的事情可以不想。

我们都做不到这一点。“不想什么”的自由，被剥夺最厉害的人，可能是精神疾病患者。我们也多多少少地被剥夺。比如，早上中了五百万彩票，你能在得知中奖后一天不去想它，该干嘛干嘛，那你很有本事。如果突然检查出癌症，猝不及防，要说在之后的24小时里一秒钟也不要想它，你做不到的。

好在这样的事情并不多。一般只有少量时候、少量事情，拥有占据我们大脑不出来的势力，如果变成大量时候、大量事情，就需要去看精神科了。

想一件事情，佛教叫“造业”，造的是意业。造业在很多情形下，是身不由己的。比如头疼，疼得越厉害，注意力越难从头疼上移开。产生重大刺激的事情，很难不去想。小事就可以。是中午买菜还是晚上买菜，说不想，就可以不想了。重大的事情，难以不想，是因为它伴随着剧烈的情绪。什么叫大事，对每个人都是不同的，应该说，引起激烈情绪的，就是大事。引起了你激烈的情绪，对你来说就是大事。之所以无法不想，因为背后有情绪的推动。情绪的烈火在底下燃，想法的锅不能不沸。

情绪是心的道路，情绪铺好了道路，心就得沿着道路走。尤其是道路唯一的时候。在花园里散步，想往哪儿走，可以随意。但如果堵在高速上，前面有车，后面也有车，你就只能往前走。贪瞋痴，是“业道”——业行走的道路。要想获得“不想”的自由，必须追溯到情绪的源头，去了解逼迫我们不得不想的动力在哪儿，是怎样产生的。

动力，就是情绪；情绪是怎样产生的呢？从感受中产生。感受是滋养情绪的沃土。我们常说，深陷在情绪中不能自拔。其实，是情绪陷溺在感受中不能自拔。有时候，对待这种症状要用电击，因为电击改变感受。可是，电击只能改变现在的感受，改变不了过去的感受。而发挥作用的感受，可不仅是现在的感受。过去的感受，因为记忆的力量，残余势力会诱导你在稍微闲下来的时候重新回味它，在回味的当下，又产生现在的感受。只要相应的记忆不被移除，就能长久滋养情绪，产生可怕的后果。

未来的技术也许能移除大脑中某些记忆片断，但移除不可能是完全的：一方面，不同的记忆彼此是关联的；另一方面，不仅大脑承载记忆，身体的其他支分也承载少量的记忆，或记忆的印记。比如通过长久的健身，练出了马甲线，哪怕可以删除大脑里的健身记忆，但腹部的肌肉仍然保留了健身的痕迹。酗酒的人删除了大脑里的记忆，但酒精肝还在；老烟民删除了抽烟的记忆，被烟熏过的食指和牙上的黄斑还在。不过，它们的影响是微弱的。

以上，用佛教的表述，叫“惑、业、苦”。苦，就是感受；惑，就是情绪；业，就是想法。因为感受，产生情绪；因为情绪，引起想法；因为想法，刺激感受。循环不已，就叫轮回。

“因为想法，刺激感受”，叫造业。比如，想喝可乐，就买一瓶喝。一般来说，没有什么妨碍。真正可怕的，是重大感受的产生，往往会循环到不可逆转的境地。比如创伤经历，带来感受；因为感受，滋生出情绪，情绪陷溺其中，扎根，生长，培植出强大势力，让你越来越难将注意力从它的魔掌中挣脱。

一切成瘾经历，乃至让人深刻的感受，都是如此。任何感受，只要稍微深刻，都是泥潭，是黑洞，都有可能一步步吞噬你。只是有些感受吸引力大，有些吸引力相对弱。一切感受，都可能带来未来的苦。为什么不是必定呢？因为，由感受带来未来的苦，有个条件，就是“取”。这个条件，对一般人来说，总是满足的。

一切大苦的聚集，都是因为取。“取”是什么呢？就是从种种感受中识别快乐的部分，追逐它；识别痛苦的部分，逃避它。

因为取，感受成为情绪滋生的沃土。由乐受滋长贪，由苦受滋长瞋，由不苦不乐受滋长痴。粗暴地讲，追求快乐，就是带来痛苦的原因。越是拼命追逐快乐，越会迅速陷入痛苦。逃避痛苦，也是痛苦产生的原因。越是拼命逃避痛苦，越会带来未来的痛苦。

想要快乐而不得，对自己往往是一种保护。我们都没有本事驾驭快乐和痛苦。不快乐也不痛苦的感受，我们也没本事驾驭。只是，强烈的快乐和痛苦，总是容易成为精神崩溃的直接诱因，而不快乐也不痛苦的感受不太会。我们生活在庸常无聊的日子里，甚至有点讨厌它，其实，它很好地保护了我们。如果痛恨庸常而不肯接受，痛苦马上就会来临。

寻求解脱，一言蔽之，就是不受感受的迷惑。自始至终，就是这一点。不被感受吸引，也不排斥感受，而是认清它的本质，明白它从哪里来，到哪里去。

想让心摆脱奴役，获得“不想”的自由，要从感受下手。不苦不乐的感受，是最不滋养情绪，也最不容易推动造业，最随顺解脱的，叫“舍受”。要产生这种感受，需要远离苦的感受，也放弃乐的感受，这叫“行舍”。行舍是良好的情绪，推动我们造好的业，并从未来的痛苦中解放，也从未来的快乐中解放。所谓解放，是你仍然可以享受快乐，但不受它奴役。

一言蔽之，当快乐的感受产生，应当保持高度清醒，不得意忘形。痛苦的感受产生，也一样。这是解脱的关键。
