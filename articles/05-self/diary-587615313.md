# 我们的婚姻没有比王宝强更好

昨天很大的雾霾，王宝强穿一身黑西装，坐着红色代步车进了朝阳法院。两场诉讼，一场他提出离婚的诉讼，一场作为被告接受对马蓉诽谤的诉讼。
不知挑选红色车来法院，有没有想讨个吉利的考虑。庭审从下午一点持续到六点，雾霾没有散，却更重了。降临的夜色里，王宝强走出法庭，飞快地钻进一辆黑色轿车，逃离了大众视线。
换车是不想被记者堵到并拍个不停。这一消息已然没有八月份刚爆出马蓉出轨时令人激动。当时万人空巷。去餐馆吃饭，东西南北四个桌都在说王宝强，下楼坐电梯，七十多岁的老太太也在谈王宝强。热劲在几个月后渐渐散去，却依然有媒体批评王宝强扬了家丑，说是为了扩大社会影响去炒作。这样的舆论在这样的天气映衬下相得益彰。
媒体照片上，重霾昏沉的日色里，一行人簇拥着王宝强。镜头让人有点凄凉。那些穿黑西装的跟班对王宝强的簇拥，和搞媒体的人对王宝强的簇拥没有多大区别，只是在表面上，他们得到王宝强更多的信赖，相较之下，媒体就不太客气了。
但无论是以怎样的姿态簇拥，我们当中有谁，像王宝强那样背着这么大的被世人视作丑闻的帽子在熙熙攘攘的人群里来回穿梭呢？
王宝强是孤独的。人们看他的生活像看他拍的戏一样，甚至比看他拍的戏更来劲儿。那么多簇拥在他周围的人，都是观众，只有他一个人是演员。
观众之所以爱看演员，并不是演员在秀自己的生活，而是演员在表演观众的生活。那些陪着王宝强进入庭审现场的人、围观在法院门口拍照直播的人，躲在电脑背后写稿子的人、刷着朋友圈看热闹的人里，有多少人的婚姻忠贞永固情比金坚？
寥寥无几。
上月见个朋友，他说，出轨没有什么不能接受的。“谈恋爱的时候我就先说好，我会撩别的妹子，你想撩帅哥，我也不介意。” 他说这样比较好，开诚布公，无论开始还是分手，大家都不吃亏。“我不会去伤害别人，如果是不能接受的姑娘，我就瞒着她。” 他对女朋友的事从来不过问，他说，不过问是比较好的相处方式，有些事情你知道了，对你是伤害。出轨是人性，与其因为互相伤害而痛苦，不如为了彼此照顾而瞒着。
他谈论这些的时候，很平静。平静得让人不容易想象，仅仅在两三年前，他还会因为失恋难受得蹲在路边走不动。那个时候他已经三十岁了。
不过，在这个时代，两三年已经很漫长了，漫长得足以改变很多事情。很少有情侣的关系经过了两三年还没有发生什么变化，要么是分手，要么是结婚，要么是结了婚再离婚。
前几天，我爸妈来北京，我专门带他们看了《从你的全世界路过》。我自己平时不看这种电影，我带他们看是有目的的。 我爸后来问到我找对象结婚的事，我就说，不好找，找不到合适的。他说，你没找怎么知道找不到合适的？我说，昨天的电影你也看了，你觉得我找里边哪个女孩你能满意？现在谈对象，都得像电影里那样瞎搞。
当然，要论长相，哪个我都满意，毕竟是演员嘛。但要谈到过日子生活，我们真保证不了自己就能比王宝强顺。王宝强的婚姻，不说是这个时代每一个人的婚姻，也至少是大多数人的婚姻。——这么讲很武断，每个人的出轨史不会写在脸上，但脸上依然可以写下很多信息：寂寞、倦怠、中年焦虑。
好几年前，上班的时候，大家搞一场活动，弄到凌晨一点，坐中巴回单位，领导说吃火锅，明天不上班了。一个女的要回家，旁边的男同事说，你回去先洗澡，等我哈。一车人哈哈大笑。没有人不知道这是玩笑，也没有人不喜欢这样的玩笑。时代留给我们一具具渴望慰藉的精神和肉体。
有个时尚行业的朋友，想在国内策划狂欢节。她说，这种节在美国很流行。现代人压力大，总需要机会放松放松，舒缓情绪。在方圆几百里没有人的地方，弄个篝火晚会，有啤酒，有音乐，有烧烤，男男女女，想干嘛干嘛。几天之后，回到公司，照样正常上班。
也许在未来婚姻会渐渐变得更像一种生活模式，就像手机，平常是日常模式，什么时候，想打开飞行模式，就打开了。回到家里，面对伴侣子女，再回到日常模式。
但婚姻的本义不是如此，结婚的时候戴到无名指上的戒指，是戒律的意思。有些戒律是一旦受了，要终身护持的。未来也许会不一样，想取下，就取下了。
昨天见了个写文章的朋友杨小米，她在月子行业做咨询，碰到的台湾的客户比较多，她说，“人家的观念跟我们就不一样，人家结婚时就约定20年后要离婚，过了20年，开开心心地去离婚，还宴请好友。我问她们，要是重来一次，你还会选择20年后离婚吗？人家说，要是重来一次，我早就离婚了，20年太长了，自由多重要啊！”
她说，据她的观察，凡是女性嫁给比自己大十多岁的男人，没有不出轨的。她身边的人都是这样。我想给她的话加一些限定条件，比如在北京上海这样的一线城市，或者我们这代人。要是这么一棍子打死，简直不敢想象，因为周围实在太多这种搭配了，他们的生活看起来美满，他们的婚姻看起来幸福。
有多少人的婚姻像王宝强一样，在没有曝出裂痕的时候，看起来和睦美满值得颂扬。只是，眼睛看见的世界能被相信几分呢。那是经过文饰的，打了重重粉底又涂上胭脂，还用修图软件360度无死角修过的模样。一旦洗掉妆容，就会看见婚姻的千孔百疮。
大漠风尘日色昏，红旗半卷出辕门。在漫天风沙里，望着王宝强远去，令人悲伤得不能自已的是一张张卸过妆的众生的脸。
