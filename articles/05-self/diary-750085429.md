# 河南没有那么硬核，也绝对不是硬心肠

[文集首页](../../README.md) · [本类目录](../../catalog/05-self.md)

作者／署名：王路  
主题：自我、情绪与人际关系  
页面时间：2020-01-26 18:09:55  
来源：[https://www.douban.com/note/750085429/](https://www.douban.com/note/750085429/)

从腊月二十九起，就看到网上流传的“河南硬核”的帖子，我这个春节就在河南，给大家汇报一下我的情况：

腊月二十九，就是“硬核”帖出现的那天，我和我爸、我叔去乡下烧纸，在二堂哥家吃饭，大人小孩加起来有差不多二十个人，围着一张桌子吃，不是分餐制，也没有任何人戴口罩，而且，其中一个是从武汉回来的。我们都知道他刚从武汉回来，但当时除了我，没有人意识到潜在的风险。虽然我意识到了，但也知道自己没有能力和习俗抗衡，反而容易让亲戚不愉快，就提都没提，跟大家一起吃了饭。

那天晚上，又同学聚会。在这个节点聚，不用说有风险。但即便留在家，也是跟亲戚聚。所以我干脆跟同学聚去了。同学都是从外地回来的，但他们当时对疫情好像也不敏感，或者大家都像我一样，虽然心里敏感，但不好意思提。当时，还有同学说，过完年约出来打牌。

除夕那天，我比较焦虑。一边是网传的所谓“河南硬核”的帖子，一边是我身在河南，周围却根本没有谁重视疫情的现实。除夕中午，我叔一家四口来我家吃饭，晚上，我妈又打电话喊我舅来，我舅说不来，我妈坚持要他们来，加上我叔一家，又是十来个人吃饭。席间，大家的咳嗽、喷嚏，不说此起彼伏，也没有太消停过。

小叔一家临走时，爸妈让他们初一中午来，他们说晚上再来，爸妈坚持要他们中午就来。他们回去后，我刷着手机上的疫情，心里很焦虑，但我爸一点意识都没有，除了抢红包，就是看春晚，觉得疫情跟自己没有关系，“都是小事儿”“很正常”“历史上出现得多了”“死有什么可怕”，说起来还带着嗤之以鼻的神情。我没克制住跟他吵了几句。吵完我有点后悔，回到房间，很难受，但是一点办法都没有，很强的无力感。

初一早上，我上街走了一圈，想观察观察到底我们这儿有多少像网上帖子说的那么“硬”。街上人没有往年多，但也不算太少，戴口罩的大概一半左右。偶尔看到一两个流动字幕循环播放疫情防控的提示。回到家，我妈也从朋友圈看到了一些疫情消息，她的瑜伽群中开始有人说不要走亲戚之类的话，还说我们县东关医院已经有一例了。我不知道真假，但起码，我妈开始提高警惕了。中午，没有打电话喊小叔他们来，他们也没来。我的焦虑平复了不少。

我们县的普通老百姓，也就是从初一开始慢慢重视起来的。到了晚上，虽然还是了喊小叔他们来吃饭（他们很快要回浙江了），但我想，只要往后别再走亲戚就好。我妈警惕提高了，我爸还比较滞后。我妈说，就不走亲戚了。我爸说，可走可不走的就不走了，该走的还是得走。又说，人家要来，你总不能不叫人家来。我爸要出去走走，我妈说戴上口罩，我爸不戴，说人家街上哪有戴的，就你戴，人家还以为你有病呢。实际上，那会儿街上已经大半人都戴口罩了。我妈说起网上有走亲戚被亲戚拒绝甚至报警的，我爸说：那才怪！

实际上，当我爸开始对疫情有点认识的时候，乡下也开始采取措施了。初一晚上，同学告诉我，乡下开始号召不让走亲戚了，某些到邻县的路也封了。这下我就比较放心了。如果连乡下都宣传到、意识到，应该不会有太多人来我家了。

今天初二，午饭后，我又去街上看了看，人流最密集的一家商场停业了，别的商场没停。通知上说，从今天中午12点开始停业，开业时间等待防控指挥部通知。但旁边又贴了好多张商场自己的温馨提示，上面说，“决定闭店几天”。估计他们预期过几天就能正常开门。

这时候又看朋友圈的舆论，开始有些局部反转的倾向，有些人批评大家对武汉人太苛刻、太冷漠，尤其是批评河南人太冷漠。就像病毒的变异，前几天的“硬核”，现在有向“硬心肠”转变的舆论倾向。

我不太认同类似贴标签的做法，动不动就说河南人怎样、东北人怎样、广东人怎样、福建人怎样。如果说在过去，地域对人的影响还比较强的话，今天这个时代，应该已经大大地弱化了。我在外面这些年，对“老乡”是没什么感觉的，不会因为一个人是老乡而增加亲近感，也不太喜欢谁总是拿“老乡”甚至“本家”说事儿。也碰到过河南人，问是哪儿的，说信阳的，等我说出自己是驻马店的，才告诉我其实他也是驻马店的。我理解，但觉得毫无必要。

我不太欣赏以标签标榜自己、定义他人的做法。具体点儿说，对那些有着强烈的地域认同感、民族认同感、团体认同感、职业认同感、爱好认同感，乃至性别认同感的人，我不太容易生起很多好感。

当然，这话也不能说死，如果说死，自己也坐实了通过标签来评判人的倾向。有些职业，确实对社会、对大众的贡献更多一些，也更被大家需要。如果因此说这些职业崇高、神圣，我也不排斥，只是，当这种说法流行后，就容易造成一种结果：从事这种职业、岗位的人，可能会觉得自己比别人崇高、神圣。爱岗敬业当然是好的，但如果爱岗爱到觉得自己比别人崇高神圣，那就容易出问题。爱家乡、爱地域，也都一样。

虽然前几天网上都在说“河南硬核”，河南硬不硬核我不知道，反正在我身边，从亲戚朋友前几天的表现来看，还是软塌塌的。我虽然没有遍及整个河南的样本，但也能约略推知，实情怕是和某些帖子宣传的有所出入。看截至目前的确诊数，河南也是除湖北外相对比较高的，尤其是信阳。朋友圈也开始出现信阳口罩及防护设备不足的求助贴。

其实，我们没有那么泾渭分明的界限。如果有人真的以为河南怎样硬核，和其他省份有什么不同，恐怕难免在什么时候又用“硬心肠”等负面评价来重新定义河南。能这样以“河南”来定义一群人，也难免以“东北”“山东”“浙江”等来定义别的人群。恐怕除了制造对立，起不到太多积极的效果。

在这个节点，采取措施防止人们乱跑，当然不是针对武汉人，只是武汉人更容易引起重视。如果以此理解为不欢迎武汉人，那恐怕是在形成不必要的对立情绪。什么叫武汉人？如果一个地地道道的武汉人，这半年都没在武汉待，别人也不会把他当目前所谓的武汉人。而一个根本不生在武汉、长在武汉，只是在武汉上学而放了假的人，现在也成了“武汉回来的人”。难道就要因此觉得这是亲友对自己的嫌弃甚至歧视吗。人有多么脆弱，才总是喜欢以某些标签来定义自己。

佛教说，如果谁伤害你，尽量不要恨他。不仅因为嗔恨没有任何好处，还因为，真正伤害你的不是他，而是烦恼，在烦恼面前，他做不了主。他受烦恼的驱使，自身是被动的。真正的罪魁祸首是烦恼。

如同烦恼，人们不欢迎的是病毒。就算是名医，如果感染了，也要把自己隔离开。总不能因此觉得人家不欢迎他吧。

人和烦恼不是永远在一起的，就像人和病毒不是永远在一起的。今天健康的人，明天也可能成为携带病毒者。一个压根儿不是武汉人的人，只因为去武汉出了一趟差，也同样享受“武汉待遇”。一个根本没去武汉出过差，也和武汉没有交集的人，也会因为接触过感染的人，而享受“武汉待遇”。接下来，随着病毒在人与人之间的传播，不管你有没有去过武汉，都会享受“武汉待遇”。在这个意义上，谁又不是武汉人呢？在目前，那些不能直接为疫情作出贡献的人，避免走亲访友，避免不必要的接触，由此降低感染传播的几率，这对自己对别人都有好处。能这样做的，谁又不是“硬核”的河南人呢？但如果因此就把人家送的礼物和红包扔下楼，恐怕也并不值得拍手叫好。硬核不硬核，要看具体事情，吃个鸡蛋还硬核，那就把牙硌掉了。避免标签化，也许能帮助我们在特殊的时机作出更妥善的选择。

很多时候，不是爱你就要离你近一点，有时候，爱你倒要离你远一点，因为离近了难免伤害到彼此。
