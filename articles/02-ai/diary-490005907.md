# 关于 Claude Opus 4.8 写作的要点

1、永远不要让模型“写一篇文章”。如果你让模型“写”，无论是写任何东西，模型的目标就会收敛到“写”上，而不是真正回答问题。它的焦点就会从内容偏向形式。对写作来说，“写什么”比“怎么写”重要得多。而一旦你要求模型“写”，目标就必然变成“怎么写”而不是“写什么”。所以，要看模型的写作水平，绝对不能让它知道自己是在完成一个“写作”任务。




2、模型的后训练会让它必然带着一些很糟糕的毛病。这种毛病可能是部分中位数的读者需要的。比如，开头带个帽子，结尾来个总结，顺便问“如果你需要，我还可以怎样怎样”。这种毛病的源头可能是以前在模型不主动这样的时候，部分高质量用户会在提示词中主动要求“如果你想到了哪些我没想到的问题，请主动提出来”。模型这样做会受到奖励，也就渐渐把一些额外的需求内化了。在我看这是糟糕的一步。再好的提示词，如果固定为提示词模版，对模型都是约束而不是解放。它会让模型的输出更偏向特定的采样路径，极大地限制了回答空间。这也是为什么我在进行创意写作的时候，很排斥workflow和skill。那都是为标准化和可复用准备的。但有些内容你想要的恰恰是让模型取一个难以复用的采样路径。




3、我们要放弃“文章”的观念。最好的文章都不是以“文章”的形式出现的。《论语》不是文章，是谈话。把现实中活生生的场景复刻到文章里，无论多栩栩如生，都损失了很多。不过，活生生的东西的呈现往往是粗粝的，没有加工和修饰。如果把AI的回答直接拿出来当成文章，会显得别扭，它不会从头向陌生的、大众化的读者交待必要的背景。这会损伤“可读性”。但如果你不存在对“文章”和“写作”的刻板理解，就完全可以接受这种代价。
