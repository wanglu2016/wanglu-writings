说卡牌、盲盒、奶茶"就是宗教"，是一种夸张。更准确的说法用凯瑟琳·贝尔的概念：它们是被高度"仪式化"了的消费行为。所谓仪式化，就是一种普通行动通过特定的程序、禁忌、时间节点和群体认可，把自己与其他行为区隔开，获得了特殊地位。买一包卡和买一包纸巾，在经济上都是交易，在意义上却完全不同。

这条思路在学术上也有渊源。人类学家玛丽·道格拉斯与经济学家伊舍伍德合写的《物的世界》（1979）就提出，消费是一种仪式过程，商品是让文化分类变得可见的标记。此后消费者研究中出现了一批经典文献：鲁克（Rook）1985年的《消费行为的仪式维度》；贝尔克（Belk）等人1989年的《消费行为中的神圣与世俗》；麦克拉肯（McCracken）则把消费分为占有、交换、打理、舍弃四类仪式，分析意义如何从文化转移到商品，再从商品转移到个人。下面的分析就在这个框架里展开。

一、为什么偏偏是青少年：阈限期的人需要"小圣物"

青春期是一个没有成年礼的阈限期

范热内普和特纳告诉我们，传统社会用成年礼把一个人从"孩子"送到"成人"：先分离，再经过阈限期，最后以新身份聚合。现代社会取消了大部分正式的成年礼，却把阈限期拉得极长：从十一二岁到二十出头，一个人既不再是孩子，又不被当作成人，身份始终悬而未定。

特纳晚年区分了两个概念。部落社会的"阈限"是强制的、全体参与的；现代社会的"类阈限"（liminoid）则是自愿的、分散的，发生在休闲、艺术和市场里。卡牌圈、谷子圈、盲盒圈正是典型的类阈限空间：没有长老主持，入会仪式是自发的，而主持仪式的"祭司"很大程度上是企业。

在"结构"之外寻找"交融"

学校是一个高度结构化的环境，有成绩排名、班级职务、作息表。特纳说，人在结构之外会寻求一种平等、直接的共同体体验，他称之为"交融"（communitas）。

课间一起开卡包、周末在卡牌店对战、在谷子圈里"出、收、换"，这些场合暂时悬置了学校里的等级：一个成绩平平的孩子可能因为手里有一张稀有卡而成为焦点；两个素不相识的初中生可以因为交换一枚吧唧而建立联系。卡牌提供的，是一个在正式结构之外、由同龄人自己定义价值的小世界。

圈内术语是边界，外人看不懂正是目的

道格拉斯说，分类体系划定群体边界。卡牌圈的 R、SR、SSR、UR、闪卡、镭射、编号卡，谷子圈的吧唧、色纸、立牌、痛包，盲盒圈的隐藏款、端盒、雷款，这些词对家长来说是黑话，对圈内人来说是身份认证。外人看不懂，恰恰是这套分类的功能之一：它标出了"我们"与"他们"的边界，而青春期正是最需要这种边界的时期。

心理学家温尼科特的"过渡性客体"概念也可以参照：幼儿依恋毛毯、玩偶，借此从依赖母亲过渡到独立。青少年手里的小卡片、小挂件，也可以理解为从家庭归属过渡到同伴归属的"过渡性圣物"。

二、拆开一包卡：一场微型仪式的全过程

如果用民族志的眼光观察一个孩子开卡包，会发现它有完整的仪式结构。

开包之前：巫术出现在不确定性之处

马林诺夫斯基观察到，特罗布里恩岛民在风平浪静的潟湖捕鱼不施巫术，出海捕鱼时则仪式繁多：巫术出现在技术无法控制的不确定领域。

抽卡和盲盒的核心正是不确定性，于是"玄学"大量涌现：挑货架最里面那盒，用左手抽，开包前洗手，去"欧皇"刚抽出隐藏款的门店沾运气，盲盒圈里还有"摇盒"，即通过摇晃、掂重量来猜里面是哪一款。这几乎就是弗雷泽巫术分类的现代翻版："沾欧气"是接触巫术，认为运气可以通过接触传递；模仿好运者的动作是顺势巫术，认为同类相生。

开包的过程：一个可控的阈限

真正开包时，许多人不会一下撕开，而是慢慢撕开封口，把卡片一张张推开，最后一张要露出一角、再露出一半。这是在人为地延长和放大阈限期，制造悬念。

乔纳森·Z. 史密斯有一个深刻的洞见：仪式是一个受控的环境，现实中不可控的因素在这里被暂时排除。青少年生活中的不确定性，比如成绩、升学、人际关系、父母的期待，大多是沉重而无法掌控的。一包卡里的不确定性则是被刻意制造、又被严格限定的：结果揭晓只需几秒，代价只是十几块钱，失败了明天还能再来。抽卡是在练习面对不确定性，而且是在一个安全的沙盒里练习。

怀特豪斯的"宗教性模式"理论也适用于此。开包那一刻心跳加速、屏住呼吸，属于"意象模式"：高唤醒、刻骨铭心，形成强烈的情景记忆。很多人多年后仍记得自己第一次抽到稀有卡的场景。

揭晓：圣显与神圣等级

伊利亚德说，神圣会通过"圣显"突然闯入世俗世界。一张金色闪卡在一叠普通卡中出现，就是一次微型圣显。

涂尔干说，神圣与世俗的区分是宗教的根本特征，而且神圣性不在物本身，而是集体赋予的。从材质上说，一张 UR 卡和一张普通卡几乎没有区别，都是印刷纸片。让它神圣的是一整套集体承认的稀有度体系。

神圣物随之带来禁忌，也就是涂尔干所说的"消极膜拜"：拿稀有卡要捏边，不能碰卡面；抽出后立即套上卡套、放进卡砖或磁吸框；有人拿卡前还会戴手套。

道格拉斯的"污秽即位置不当之物"在这里尤其贴切。卡面的折痕、白边、划痕、印刷偏移，就是"污染"。于是出现了专门的评级机构：卡片被送去检验、打分、封装进透明硬壳，打上等级。这相当于一套圣物纯洁性认证制度，与宗教传统中鉴定舍利真伪的做法在结构上并无二致。

展示与交换：让群体确认

坦比亚说仪式有"表演性"：说出即完成，展示即确认。开箱视频、晒卡帖，就是把私人的圣显变成公共事件。

社会学家柯林斯的"互动仪式链"理论可以解释为什么晒卡如此令人满足。一场成功的互动仪式需要几个要素：人们共同在场，拥有共同的注意焦点，彼此察觉对方在关注同一件事。满足这些条件，参与者就会获得"情感能量"，并产生对群体符号的依恋。一群孩子围着看一个人开出隐藏款，一起发出惊叹，就是教科书式的互动仪式。

交换则对应麦克拉肯所说的"交换仪式"，也呼应莫斯对礼物的研究：卡片在人与人之间流动，建立起一张关系网络。

收纳与陈列：随身携带的神龛

卡册是圣物匣。更有意思的是谷子圈的"痛包"：人们在透明包上有序排列同一个角色的几十枚吧唧，精心构图，背着出门。从仪式研究的角度看，这就是一座可移动的神龛，一种公开宣示信仰归属的方式，就像香客背着进香袋，或者泰国人把佛牌挂在胸前。

"吃谷"这个说法也值得玩味。买谷子被称为"吃"，这让人想起罗伯逊·史密斯对献祭的解释：献祭是信众与神共享的圣餐，通过"吃"，把神圣力量纳入自身。

出坑：舍弃仪式

麦克拉肯所说的第四类仪式是"舍弃"。退坑时要"出二手"，清点、拍照、定价、打包，与一段身份告别。许多人会留下一两张最珍视的卡，就像搬家时保留一件旧物。

三、奶茶店：日常仪式、历法仪式与朝圣

日常：个人的小礼仪

奶茶是高频、低唤醒的消费，属于怀特豪斯所说的另一种模式，即"教义模式"式的日常重复。"三分糖、少冰、加椰果"的固定搭配，就像一段个人化的礼仪程序，每天或每周重复一次，标记出工作、上课之外的一小段属于自己的时间。

甜也有它的人类学史。人类学家明茨（Sidney Mintz）在《甜与权力》（1985）中说明，糖在英国从奢侈品变成工人阶级的日常必需品，本身就伴随着一整套社会意义的转换。今天茶饮店纷纷推出"零卡糖"，有报道说头部品牌在2026年都上线了赤藓糖醇或甜菊糖苷选项。这可以用道格拉斯的"洁净与危险"来理解：糖是欲望，也是"污染"；"少糖""去冰""零卡"是一种协商，让人既能享受，又完成了一次小小的自我洁净。

历法：发明新的节日

2020年"秋天的第一杯奶茶"突然流行，是一个极好的案例：互联网在几天之内发明了一个节令仪式。它有固定的时间（立秋前后），有标准动作（赠送奶茶或发一个52元红包），有公开展示（晒图），有社会意义（确认亲密关系）。这完全符合贝尔所说的"历法仪式"与"交换仪式"的特征，而且没有任何宗教机构参与。

联名：神圣时间与朝圣

如果说日常奶茶是"功课"，联名活动就是"庙会"。

2026年7月24日，霸王茶姬与《王者荣耀》及《王者荣耀世界》的联名全国同步上线，首日各地门店排起长队，外卖平台显示前面还有一百多杯在制作，周边迅速售罄。排长队、限时限量、先到先得，这是一种世俗化的朝圣。

更值得注意的是周边与饮品关系的倒置。2026年春节期间就有报道：二手平台上多款奶茶周边加价出售，喜茶一款手账本在闲鱼上突破50元，霸王茶姬的冰箱贴和保温杯卖到119元；为了地区限定周边，甚至有人专门请人代喝奶茶再邮寄周边。社交平台上还有人说为了周边半个月买了十八杯奶茶。

从仪式理论看，饮品在这里变成了"门票"，周边才是圣物。这很像进香：香客真正带回家的是香火袋、护身符和纪念品，它们证明"我去过、我参与了"。"地区限定"更是直接制造了"圣地"，某件周边只在某座城市有，就像某种香火只在某座祖庙才能求到。J. Z. 史密斯说"一个地方因为举行仪式才变得神圣"，地区限定周边就是用商品在制造地方的神圣性。

还有一个有意思的回响。上一回讲道教仪式研究时提到了福建莆田的仪式联盟；2026年，霸王茶姬在莆田与当地文旅部门、莆仙戏剧院合作，在兴化府莆仙戏文化主题店里安排专场演出。地方戏曲原本是庙会仪式的一部分，如今进入了茶饮店。传统仪式的碎片正在被重新嵌入新的消费仪式之中。

打卡拍照：自指信息

拉帕波特说，仪式传递两类信息：关于永恒秩序的"规范信息"，和关于参与者当下状态的"自指信息"。奶茶杯拍照发朋友圈，传递的几乎全是自指信息：我此刻在这里，我属于这个群体，我跟上了这个节令。

四、四家店，四种"神圣空间"

泡泡玛特：求签、神谱与卡里斯玛的起落

盲盒就是求签。 在庙里摇签筒，掉出一支签，签文决定吉凶；在泡泡玛特，摇一摇盒子，打开，隐藏款决定这一次的"运"。二者都把随机性包装成一次与"命运"的对话，都有"再来一次"的冲动。

IP 形象构成神谱。 泡泡玛特的角色以"家族"形式组织。2026年1月推出的 THE MONSTERS 十周年产品覆盖了家族中的十个 IP 成员。这很像神明体系：主神之外有眷属、有配祀，每个角色有自己的"性格"和故事，信众各有所好。

Labubu 的起落是卡里斯玛常规化的案例。 2025年，泡泡玛特全年营收371.2亿元，同比增长184.7%，仅 Labubu 所属的 THE MONSTERS 就实现营收141.6亿元。到了2026年上半年，THE MONSTERS 收入44.5亿元，仍是第一，但同比下降7.5%；2024年才推出首套产品的星星人收入达到26.5亿元，同比增长580.6%，升至第二。创始人王宁把2026年定义为"调整年"，优先处理上一年快速增长中暴露出来的库存、供应链、门店运营和客户服务等问题。

这正好印证了涂尔干和 J. Z. 史密斯的观点：神圣性不是物本身固有的，而是集体仪式赋予的，也会随着集体注意力的转移而流失。 韦伯所说的卡里斯玛也是如此：魅力型权威爆发之后，要么被"常规化"为稳定的制度，要么消散。

一篇分析文章做了一个很有洞察力的对比：上海的收藏者盯着发售日历、为特定系列排队、与会员交换重复款；2025年美国商场里的顾客买 Labubu，只是因为那个月它无处不在。前一种行为会不断滚大，后一种会自行停下，而在季度收入曲线上，两者看起来一模一样。用仪式理论的语言说，前者是一个有持续仪式实践的"信众共同体"，后者只是一阵流行。泡泡玛特国内注册会员从7258万增至8244万，会员贡献了92.9%的销售额，复购率51.6%，这组数据描述的，其实就是"信众"的规模。

还有一个细节：2026年上半年泡泡玛特毛绒产品收入占总收入的57.2%。挂在包上的毛绒挂件，与泰国人随身佩戴的佛牌在功能上惊人地相似：贴身携带、公开可见、带来安全感和身份认同。上一回讲麦克丹尼尔的研究时说过，泰国人从佛牌和护卫偈中获得的，恰恰是爱、美、安全感和归属感。

名创优品：万神殿与"分灵"

名创优品早已不是早年那家杂货店，而更像知名 IP 的周边开发商：走进 MINISO LAND，迪士尼、三丽鸥、宝可梦、chiikawa 等联名产品占据最好的陈列位置。叶国富透露，公司目前拥有180个国际授权 IP、16个自有原创 IP。

这是一座万神殿。 中国的庙宇常常一庙多神，主殿之外有偏殿，各路神明各司其职，信众各取所需。一家 MINISO LAND 里，不同圈层的人各奔各的"神"。它在上海南京东路开设的首家全球级大店，被形容为年轻人的"吃谷"圣地，试营业首月销售额1203万元；《第五人格》系列首发当天售罄率高达93%。

IP 授权就是"分灵"。 台湾民间信仰中，新建的庙宇要从祖庙"分香""分灵"，借取祖庙神明的灵力，并定期回祖庙进香以更新灵力。名创优品向迪士尼、三丽鸥取得授权，本质上是在借用别人经年累积的"神圣资本"；授权到期就要续约，就像分灵庙需要不断回祖庙刷新灵力。

所以名创优品着力发展自有 IP，就相当于建立自己的祖庙。叶国富说公司2025年才"觉醒"要做自有 IP，仅那一年就开发了15个，他看好的自有 IP YOYO 甚至被计划做成人形机器人，要"陪伴你终身"。一个 IP 形象被装进机器人，这让人想起上一回提到的京都高台寺机器人观音：神像开光的问题，正在以商业形式重新出现。

KKV：丰盛的殿堂与"逛"

KKV 的标志性风格，是按色彩和品类整面铺陈的巨型货架：零食、美妆、文具、玩具层层堆叠，形成视觉上的"丰盛"。

麦克丹尼尔在研究泰国寺庙时发现，泰国寺院的审美逻辑不是极简和留白，而是堆叠和丰盛：佛像、神像、供品、装饰越多越好，丰盛本身就是灵验与繁荣的象征。KKV 的陈列逻辑与此相通：顾客在一片由商品构成的"丰饶景观"中获得的，首先是一种"世界很充足"的感受，然后才是某件具体的商品。

"逛"这个动作也值得分析。人们来 KKV 往往不是为了买某样东西，而是去"逛"：在货架之间漫无目的地走、拿起、放下、拍照。这很像宗教传统中的绕行，转经、绕塔、绕佛。绕行不追求到达某处，行走本身就是意义。购物中心里的集合店，就是城市青少年周末的"绕行路线"上一个个停靠点。

The Green Party 绿光派对：城市里的疗愈绿洲

绿光派对是浙江凯蓝品牌管理有限公司旗下的生活集合品牌，2014年创立，主营时尚配饰、潮流 IP、二次元谷子、毛绒玩具等，与线条小狗、初音未来、LOOPY、卡皮巴拉等三十多个国内外 IP 合作，全球门店已超过1000家。它的定位从最初的"自然生活集合"，经过"新鲜潮流聚集地"，再到如今的"自然玩趣生活集合"，在保持自然、绿色的品牌基因的同时，强调体验感和趣味性。

它的仪式空间逻辑，是在购物中心内部制造一块"自然"飞地。最初它就以门店中的绿植在商场里营造绿色氛围。伊利亚德说，神圣空间是从同质的世俗空间中划出的一块"不同质"的区域。在人工照明、恒温空调、千篇一律的购物中心里，一家布满绿植的店面，就是一个象征性的"林中空地"。

它还被媒体归入以"疗愈力"入选领军品牌榜单的一类，被描述为持续"疗愈"年轻人。"疗愈"一词值得认真对待。涂尔干把宗教仪式分为消极膜拜、积极膜拜和"禳解仪式"，后者用于应对灾祸与苦难。当代年轻人面对学业、就业、内卷的压力，"疗愈""情绪价值""悦己"这些词汇，实际上承担着一种世俗化的禳解功能：通过购买和把玩一件毛绒玩具，暂时安顿焦虑。

绿光派对还强调"一店一策"，在零售空间中融入当地元素，例如杭州湖滨银泰 in77 的新店加入西湖相关设计，南京新百店加入当地商脉文化符号。这是一种"在地化"的神圣空间营造，与名创优品 IP 大店的"全球万神殿"逻辑恰好相反。

五、理论的另一面：当仪式由企业设计

仪式理论不只解释"为什么喜欢"，也提供批判的工具。

谁是祭司？

在传统社会，仪式由长老、祭司、道士主持，受到社群的制约。在卡牌和盲盒经济中，稀有度、概率、发售节奏、限定款，全部由企业设计。企业实际上成了"仪式专家"，发售日历就是它们编订的"历法"。

贝尔提醒我们，仪式化塑造出"仪式化的身体"，人在其中既获得力量，又被权力塑造，并且对这一过程"误识"。孩子感到自己在"碰运气"，却未必意识到"运气"的分布是被精确计算过的。布洛赫也指出，仪式的形式化会压制可辩驳的内容：你无法与一个隐藏款争论它"值不值"，只能说"喜欢就好"。

一个理论上值得警惕的组合

这里有一个我认为值得重视的观察。怀特豪斯的理论中，"意象模式"的仪式（如痛苦的成年礼）是高唤醒、低频率的，因为这类体验代价高昂，人一生只经历几次；"教义模式"的仪式是高频率、低唤醒的，比如每天的祈祷。历史上，高唤醒与高频率很少结合在一起，因为高强度体验本身难以大量复制。

盲盒和抽卡恰恰打破了这个限制：它把"意象模式"的高峰体验，压缩成十几块钱、几秒钟就能获得的产品，并且可以无限重复。这正是它令人着迷、也容易让人失控的结构性原因。

未成年人问题是真实存在的

卡游是这个行业的缩影。2024年它的集换式卡牌销量达到48亿包，按商品交易总额计在集换式卡牌领域市场份额为71.1%。央视财经的调查报道描述：周末商场里的卡游门店挤满了几岁到十几岁的孩子，有的小学生一次花上百元甚至数百元买整盒卡牌。

监管层面，2023年国家市场监管总局发布的《盲盒经营行为规范指引（试行）》规定，不得向未满8周岁的未成年人销售盲盒，向8周岁及以上未成年人销售需确认取得监护人同意，但这只是一份规范性指导文件，没有规定相应处罚。有专家建议强制公开卡牌设计规则和隐藏款概率、设置保底机制，并加强对中小学周边商铺的监管，打击"废卡回收"等变相诱导行为。企业也在调整：卡游近来与帕尼尼合作推出2026世界杯官方收藏卡，并加速布局影视、游戏等更偏成人向的 IP，意在降低对低龄用户的依赖。

从仪式理论出发，可以把这些监管建议理解得更清楚。公开概率，是在削弱"巫术"赖以存在的不确定性；设置保底，是给阈限期设定一个终点；限制向低龄儿童销售，是承认并非所有人都具备进入这种仪式的条件。

但也要警惕道德恐慌

这一代的现象并非史无前例。1990年代末，小浣熊干脆面里附送水浒卡，许多孩子买面只为集卡，面饼扔掉，与今天"为周边买奶茶"如出一辙。央视报道集换式卡牌需加强监管时，卡牌圈里有人欢呼出圈，也有人讥讽这类报道像当年媒体批评电脑游戏是"电子海洛因"。

仪式理论最有价值的地方在于：它既不把青少年的热爱简单斥为"消费主义陷阱"，也不天真地说"孩子开心就好"。它让我们看到，这些小玩意儿承担着真实的社会功能：标记身份、建立同伴关系、在安全范围内练习面对不确定性、在压力之下获得片刻安顿。问题不在于青少年需要仪式，而在于这些仪式的设计权、定价权和节奏，越来越集中在追求增长的企业手中。

当代青少年并没有"失去"仪式，而是在市场中重新找到了仪式。卡牌是护身符和圣物，痛包是随身神龛，奶茶联名是节令庙会，泡泡玛特是求签的庙，名创优品是分灵的万神殿，KKV 是堆满供品的殿堂，绿光派对是城市里的疗愈绿洲。

涂尔干当年说，人们崇拜图腾，实际上是在崇拜社会本身。今天的年轻人围着一张稀有卡、一个隐藏款、一枚限定吧唧欢呼的时候，他们确认的，同样是一个"我们"的存在。区别只在于，这个"我们"的边界和入场券，如今部分是由商家印制的。
