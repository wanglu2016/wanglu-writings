# 自以为是之愚（文/王路）

我写过两次毕业论文。第一次很差，预答辩时，老师非常生气，觉得这个水平根本没法毕业，让我重写。当时离提交只剩一周了。
毕业那年，我拿了奖学金。因为前一年的成绩排在学院前列。为什么成绩还行，论文却烂到如此地步呢？这是个很重要的问题。但我当时一直没有明白，过了好几年，才慢慢明白一点。
一周之内，重写三万字的硕士论文，压力很大。好在老师给了我参考，是曼昆等人1992年的一篇论文，要求我严格按照他的方法，来处理我的问题。照这个思路，四个夜晚之后，我战战兢兢把论文发给导师。今天还记得，收到他邮件时我欣喜地跳了起来。他说，很好。
当时，我一直把这视作一种意外的遭遇，偶然的惊险。我甚至想，假如遇见一位不那么严格的老师，可能就混过去了，不需要大改。如今，我才觉得遇见这事是我硕士期间的很大福气，它直接暴露出我此前二十多年养成的一个非常坏的毛病：不愿沟通。
最糟糕的事情，不是你不会写。不会写，去请教老师，老师会告诉你该怎样写，每一步怎么做。最糟糕的是，你也不问，就凭自己的想法瞎写。还以为写得不错。
以写作为职业之后，会有些读者，给我发来他们的作品，让我看看。有时候我提出一些问题，比如很多故作幽默的段落应该去掉，宣泄情绪的言辞不宜保留，往往有人不认同。他们觉得，我建议去掉的地方，正是写得最好最带劲的地方。——这个毛病，跟我第一次写毕业论文时一模一样。
怕的不是技术差。怕的是看走眼，眼力上就错了，把不对的东西看成了对，把低的东西看成了高。有些东西，乍一看不错，但它很快就会成为你的瓶颈，沿着那条路走两步，就无路可走了。要想走得更远更深，必须把很多自鸣得意的小聪明抛掉。
得真的见过好东西。得见过顶级学者的论文，大师的作品，才知道想象力该从哪个地方展开。有一百条路，九十九条是走不远的，剩下一条走下去，不久又分岔了，但是有走远的可能。这条路，前人指出来了。在起步的时候，要严格追随前人脚印，夫子步亦步，夫子趋亦趋。这是章法。没有章法，一切都是胡来。
我第一次写论文，就是胡来。比如，我要把不同国家按收入水平分别回归分析。我把样本分成三组，前三分之一是高收入，后三分之一是低收入。导师十分生气，说什么是中等收入能由你定义吗，世界银行有标准啊！
作为经济学硕士，快毕业了，处理这种问题居然不知道去查标准，而是想当然，可见当时有多么无知。但更无知的是，我还并不觉得这有什么要紧，我跟室友说，照老师的交待重新回归，跟之前得到的结论没有差别嘛。
这一点，毕业后好几年，才慢慢理解。能理解，是因为我自己写文章改稿子的经历。改了几年，我慢慢觉察出，就算是一个标点符号，一个“的”字和“了”字，去还是留，都有极大的琢磨空间。要不要下一个虚字，都体现出写作者的功夫。而最大的愚蠢，就是自以为是地搬弄小聪明。
写论文的时候，别的同学都是老老实实问老师，每一步该怎么做。我害羞，不好意思问。人家问我怎么也不找老师，我就说，老师太忙，找老师耽误他的时间。其实，老师会不时地请我们吃饭，但在饭桌上，又开不了口，总觉得不是问问题的场合。说到底，是胆小，怕见老师，不敢问问题。
为什么不敢问呢？怕老师觉得自己蠢。吃过多次亏才明白，一两个问题不懂不算蠢，反倒是怕人家觉得自己蠢而不敢请教，才是真蠢。有人喜欢说一句话：我的问题是不是很幼稚？——其实你的问题不幼稚，但你问是不是幼稚这点就很幼稚。
因为害羞，不敢问，不敢主动沟通，吃了多少亏。毕业后，写第一本书，出版社定的选题，见了面吃了饭，定下来让我写了，我却没经验，不知道该怎么写。但又不好意思问，一是怕问起来显得我笨，二是怕人家不让我写了。
于是就一直憋着，憋思路，吃力又不讨好。吭哧吭哧写了两万字，发给编辑看，编辑很无奈，说这完全不是我们想要的，全偏了。然后她告诉我该怎么写，我说，这么简单？很快就给她弄成了，她也觉得不错。假如能及早沟通，会省下多少力气。
《论语》有一句话：子入太庙，每事问。这句话，高中就会背，但真正有切身体会，要在十多年之后。
孔子这样的人，进了太庙，还要每件事都问一问。难道他不懂？当然不是。孔子重祭祀，对太庙的事，可能比掌管太庙的人都懂。但他还是要问问。问，起到两个效果。第一，听听自己所了解的和实际情况是否一致；以前如此，现在有无变化；书上如此，现实有无出入。第二，起到表率的作用。人家会想，以孔子的博学，还要事事都问，我们有什么不好意思问的呢？
网上经常有这样的问题：第一次坐飞机，怎样才能装成经常坐飞机的样子？第一次出国，怎样才能装成经常出国的样子？——装什么呢，不懂的事，问就挺好。越掩饰，越难长进。小地方的人出去，喜欢到处点评，去餐厅吃饭，说这道菜盐放少了，那道菜烧得嫩了，讲这些话什么意思呢？意思是这些我懂，别看你们是大城市，你们有的东西，我们家哪个没有，比这还好。
读大学时，假期回家碰到亲戚，总会问，你是学什么专业的？然后说，你们专业是不是要学什么课、什么课。说了一大堆，其实都不对。知道学校在广州，就会掰着手指把京广线的城市挨个数一遍，表明自己也走到过。
工作之后，也常碰到这样的人。无论你谈什么，他都会发表看法。谈金融，他懂，货币不说货币，说M2。谈互联网，他懂，不就是殴图殴、皮图皮嘛。谈艺术，他还懂，清明上河图里边一共画了一千六百四十三个人。谈创业，他更懂，——你们公司在新三板上市了没有？
但你看孔子，虽然进了太庙，还是要事事向人请教。见识浅陋的人就说：谁说孔子懂礼？到了太庙，什么都问。孔子就说，这正是礼啊。
为什么是礼呢？第一，听听别人说的，验证自己知道的是否准确。第二，看看别人了解的程度，对比自己是否有什么疏漏欠缺。第三，表示对别人的尊重，让人感到舒服，感到自己的知识有价值。
但很多人不是这样。他们生恐别人不知道自己有知识。别人说，知之为知之，他马上就会接上：不知为不知，是知也。这还算好。有人是，别人谈一种看法，刚谈了半句，他就替别人把结论说出来了。等着别人说对，就是这样。有时候别人本来不是这种结论，不忍心戳破他，就点点头，说嗯哪。他就失掉了理解他人的机会，也失掉了迁善改过的机会。
凤凰新闻客户端主笔 王路
