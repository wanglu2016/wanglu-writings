# 从“非离欲得”到“曾修离染得”——有部天眼耳得法的分歧、重构与根通分化

摘要

欲界有情渐次离欲界及前三静虑染，在离第三静虑染第九解脱道初得第四静虑时，是否同时成就第四静虑眼？

这个看似极细的问题，实际打开了说一切有部阿毗达磨发展史上的一道缝隙。早期心论系统明确主张天眼、天耳智等无记功德并非离欲所得，而须由方便求得；《大毗婆沙论》卷141却记录了“五通唯加行得”“唯离染得”的对立说法，最终由评家判为加行、离染二者皆通，并建立“曾习者离染得，未曾习者加行得”的结构；《俱舍论》与众贤继承了后一结构。然而，当对象由“通”转为作为净色的“眼耳二根”时，情况又发生变化：《婆沙》卷149明言“眼耳二根有加行得、离染得”，但卷150、153、156、157、195形成另一套高度一致的技术规则，后来《顺正理论》《显宗论》更明确判定天眼耳根“唯加行得，非离染得”。

本文认为：不能把这一组材料简单化为一个从来无争议的“有部正统说”，也不能把所有冲突强行会通。最强的体系证据显示，在成熟的毗婆沙—俱舍—众贤得论中，天眼耳通与天眼耳根的得已经被严格分开：通可以离染得，根不能离染得；根仅在实际由加行引起现前时暂时成就。《婆沙》卷149则保留了一个真实的文献异常。它可能是宽说、较早或不同层次的理论残留，也可能只是《婆沙》编纂史中未被完全消除的一处不一致。

这不是一项需要被抹掉的瑕疵。它恰恰让我们看到阿毗达磨理论如何在长期论辩中逐渐获得更细的颗粒度。




一、问题的关键不是“有没有天眼”，而是什么东西在什么时候“得”

《婆沙》卷157开宗明义解释：

“得言欲何所显？谓获成就。”

因此，“成就第四静虑眼”不是问一个人有没有能力以后修出天眼，也不是问他是否成就了第四静虑，更不是问他有没有天眼通，而是问：此刻是否存在一个“得”，以第四静虑眼根为所得法。

这首先要求区分三个对象。

天眼根是色法。《婆沙》卷149定义天眼为色界大种所造净色，属于眼界、眼处、眼根；地系于四根本静虑。

天眼通则属于智慧。《婆沙》卷141明确讨论“五通”的加行得与离染得；众贤后来更严格区分：胜无记慧是天眼耳“通”，此慧所引的净色才是天眼耳根。

此外还有眼识。它依天眼根而见色，但又不是根，也不是众贤所谓定相应天眼通慧。

于是，一个自然语言里简单的“得天眼”，在阿毗达磨里至少可以意味着三件不同的事情：

得通、得根、起识。

这篇文章所有曲折，几乎都来自这一点。




二、心论系统的一条旧路线：无记的天眼耳智不是离欲所得

《阿毗昙心论》说得非常干脆：

“当知非一切功德离欲时得。”

随后列举如意足智、天眼智、天耳智，因为它们是无记，所以要“求得”，不是离下地欲时自然得到。

《阿毗昙心论经》保持同样结构：

“方便得者，如天眼耳。彼无记故……”

意思也很清楚：离下地染所得的是相应地的味、净、无漏等定地功德；无记天眼耳不摄在其中，因此另外依方便而得。

这一点到了心论系统后续著作仍然可见。它代表一套非常容易理解的理论：

离染所得，是随地取得的定地功德；天眼耳是特殊无记功德，所以要另外修。

但这里必须加一个文献学警告：不能简单写成“早期《心论》→后来《婆沙》”。《阿毗昙心论》与《大毗婆沙》的相对年代本身有争论，相当有影响的传统甚至认为《心论》是在《大毗婆沙》之后约百年形成的纲要书；现代研究也存在不同意见。

所以更准确的说法不是“最早有部如此”，而是：

有部的心论传统保存了一条非常明确的“天眼耳智唯方便得”路线。

这已经足够重要。




三、《婆沙》卷141：争论真正爆发了

到了《大毗婆沙论》卷141，我们第一次看到问题被公开摆成争论。

五通究竟是加行得还是离染得？

论中首先记录：

“有说，唯加行得。”

又记录：

“有说，唯离染得。”

随后评家判：

“如是说者，皆通加行及离染得。”

然后给出更加精细的规则：从未串习者由加行得；曾串习者可以由离染得；初静虑所引通在离欲界染时得，第四静虑所引通在离第三静虑染时得。普通异生离染所得限于曾习品，而圣者及最后有异生还可以涉及未曾习品。

这是理论上的一次重大重构。

因为一旦承认无记的天眼耳通也可以离染而得，旧的“无记，所以不能离染得”便不再成立。

《俱舍》后来把它压缩成著名的：

“未曾由加行，曾修离染得。”

《显宗论》也沿用这一结构。

于是出现了一个很值得注意的历史现象：

心论传统说：

天眼耳是无记，所以非离欲得。

而《婆沙》评家—《俱舍》—众贤这一线却说：

尽管天眼耳通是无记，曾修之品仍可以离染得。

这显然不是一句话措辞不同，而是得论规则真的发生了变化。

甚至很值得提出一个尚待进一步验证的假说：《俱舍》卷四所谓：

“无记得俱起，除二通变化”

之所以需要把“二通”立为例外，正可能与这种理论扩张有关。普通无覆无记法的得势力弱，只与法俱；可是既然现在承认天眼耳通能够在离染时重新成就、而并不一定正在现前，它就必须从普通无记法的得规则中被剥离出来。

这个假说目前非常有吸引力，但还不能当作历史事实。因为我们尚不能证明“二通例外”这一规则是在何种文本层累中具体形成的。




四、第一次反转：如果通可以离染得，根是不是也一起得到？

这正是原问题真正困难的地方。

《婆沙》卷149似乎毫不犹豫地回答：是。

它问，为什么生在欲界的人能够起色界眼耳根，却不能起色界鼻舌身根？

回答：

“眼耳二根，有加行得、离染得、修所成、通所依性……”

如果只读这一句，几乎没有多少回旋余地。

主语是：

眼耳二根。

谓语是：

有离染得。

如果按照通常阿毗达磨术语解释，那么一个过去曾修第四静虑天眼的人，此生离第三静虑染时，就可以重新由离染成就第四静虑天眼根。

这样一来，原题的答案很可能会发生逆转。

可是，一旦继续往下读《婆沙》，麻烦来了。




五、第二次反转：《婆沙》卷156直接说眼根只成就现在

在整个问题中，我认为目前分量最大的一条材料，并不是卷157，也不是众贤，而是《大毗婆沙论》卷156。

论中直接问：

成就眼根者，在三世二十二根中成就哪些？

回答说，命等八种无记根：

“唯成就现在，非过去未来，势羸劣故。”

这里已经不是从“五蕴”“三性”间接推论眼根。

它直接讨论：

眼根的三世成就。

而天眼明确属于眼界、眼处、眼根所摄。

所以按照卷156的技术规定：

过去眼根不能由现在的得继续成就； 未来眼根也不能由现在的得提前成就； 眼根只有在现在位时，才能由现在得而成就。

这一点非常强。

甚至它比卷157“一切无覆无记色蕴得世不杂”更直接，因为卷157还需要先把天眼归入无覆无记色；卷156已经把规则直接写到了“眼根”上。

如果卷149的“眼耳二根有离染得”严格按技术意义解释，那么两卷之间立刻出现正面冲突。




六、卷150、153、195：冲突越来越难以当作偶然

卷150进一步讨论修得天眼与生得眼的差别。评家最后判：

“天眼天耳必无彼同分，要于用时乃现前故。”

这句话非常重要。

普通生得眼可以存在而暂时不用，称为彼同分；修得天眼不行。它只在实际发挥功能的时候现前。

《俱舍》后来也说，修得眼耳过去、现在、当生都是同分，到了现在位必与识俱而能见闻。

所以修得天眼不像肉眼一样，是一种“装在身上但现在没有用”的稳定器官。

它更像一个只在使用时临时形成的净色根。

卷153又讨论灭尽定有没有“得过去、修未来”，其中一说以天眼耳作比：

“此定无得过去及修未来，如天眼耳。”

评家最终取这一说。

虽然“无修未来”不能简单等同于所有意义上的“无法前得”，但它至少再一次显示：天眼耳不是那种可以跨三世稳定持有的功德。

到卷195，结构几乎完全摊开了。

《婆沙》把天眼天耳与其识、变化心作对比：天眼天耳须“广设加行”，而且只是“暂时成就”；天眼耳识和变化心却可以因离欲染或界地还时“不用功而得”，得后恒时三世成就。

紧接着还说：

天眼天耳“离欲染后能现前”。

这个次序很值得注意：

不是：

离染 → 根已经永久成就。

而是：

离染以后取得能够引发它的条件 → 经加行 → 根现前 → 暂时成就。

到这里，卷149已经不再只是与某一条一般规则冲突。

它面对的是《婆沙》内部一整组彼此支援的技术规定。




七、众贤把模糊地带彻底切开

《顺正理论》卷十二说：

“如天眼耳，无未来修，唯加行得，非离染得。”

单独看这句话，还可以问“天眼耳”是根还是通。

但众贤自己在卷七十六给出了消歧条件：

天眼耳通是定相应胜无记慧；此慧所引的胜大种果，才名天眼、天耳。

同时，同卷又接受：

五通未曾得者由加行得，曾修者可以离染得。

所以众贤不可能同时主张：

“天眼耳通可以离染得”，

以及：

“天眼耳通非离染得”。

卷十二的：

“唯加行得，非离染得”

因此最自然的对象就是：

眼耳净色根。

《显宗论》又重复同样规定，可见这是众贤稳定的体系判断，不是一处疏忽。

至此，成熟的理论结构极其清楚：

通慧：可以加行得，也可以在特定情况下离染得。

净色眼耳根：唯加行得，非离染得；实际使用时才现前并暂时成就。

这正是“根—通分化”的完成。




八、那么卷149究竟是什么？

这时候最简单的做法，是说卷149“其实不是那个意思”。

我认为不应该这么容易。

它的字面太明确：

“眼耳二根，有加行得、离染得。”

如果研究阿毗达磨的人只因为这句话给自己的体系制造麻烦，就把它解释掉，那和看到任何反例都重新修改定义没有本质差别。

所以卷149应该保留下来，作为全案真正的反证。

但现在我们可以更准确地衡量它。

首先，《婆沙》自己允许把因果上相近的法互相借名。例如它明确说，天眼耳“是通果故亦名为通”。这说明“通”的名称确实可以移到作为通果的根上。这样的语言习惯，使卷149把通系统的一些获得性质整体归到“眼耳二根”名下，至少具有文体上的可能性。

其次，卷149正在回答的是：

为什么眼耳可以异界现前，而鼻舌身不能？

它不是专章分析“眼根在三世中究竟有什么得”。

而卷156、157的任务恰恰就是技术分析“成就”“三世得”；卷195又专门比较天眼根、天眼识、变化心在获得方式和成就持续时间上的差异。

因此，从“问题功能”上说：

卷149的证据对象匹配最强，却不是最严格的得论语境； 卷156、157、195的对象和技术语境同时高度匹配。

在这种情况下，我倾向以后者校正前者的字面。

但这只是解释学上的“最强倾向”，不是数学证明。




九、卷186不能替卷149增加太多力量

《婆沙》卷186把天眼作多种分类：

有时分“曾得、未曾得”； 又分四静虑果； 又分生得、修得等。

乍看之下，它似乎印证卷149：

既然天眼根本身分“曾得”和“未曾得”，而通的理论又是“未曾由加行、曾修离染得”，那么曾得天眼根似乎也可以离染而重新得到。

但这一步不能直接走。

“曾得／未曾得”首先只是对现在所现起的天眼所作的一种履历分类：

这个天眼属于过去曾获得过的品类，还是此生此时第一次获得的品类。

它本身并没有说：

“曾得者此次是由离染得。”

完全可能出现：

过去曾经修过某品天眼，现在再次经过加行而现起；它仍然可以称为“曾得品”。

因此卷186确实证明：

天眼根内部存在曾得／未曾得的区分。

但它不能独立证明：

曾得天眼根能够在离染道中由离染得。

这一点必须由别的文本承担。

目前直接承担它的，仍然只有卷149那句异乎寻常的：

“眼耳二根……离染得。”

这反而使问题更加干净。




十、原题现在可以得到一个很强的回答

现在回到最初的问题。

一个欲界有情渐次离欲界及前三静虑染，在离第三静虑染第九解脱道这一刹那，初得第四静虑。

他此时是否成就第四静虑眼？

依《婆沙》卷150、153、156、157、195以及众贤体系：

不但不是必然成就，而是这一刹那必不成就第四静虑修得眼根。

原因可以闭合成一条完整链条。

第一，他此时没有第四静虑生得眼，因为他仍然是欲界生有情，并没有生在第四静虑。

第二，过去曾经现起的第四静虑修得天眼，不能靠法后得继续成就。卷156说无记八根只成就现在，不成就过去未来；卷157也说无覆无记色得世不杂。

第三，未来将起的修得天眼，也不能靠一个现在的法前得提前成就，同样被上述规则排除。

第四，此刻也没有现在天眼根。因为修得天眼“要于用时乃现前”，一旦现在前便处于同分、实际见色状态；而第九解脱道是定中意地心，一身又不能同时起两个识。

所以这一刹那：

没有过去第四静虑眼被现在成就； 没有未来第四静虑眼被现在成就； 也没有现在第四静虑修得眼现前。

结论只能是：

不成就第四静虑眼。

然而他可以在这一刹那由离染取得曾修的第四静虑天眼通。这正是根与通最容易被混淆、而成熟有部理论又最终必须将二者拆开的地方。




十一、真正值得研究的不是“谁对谁错”，而是理论为什么需要越来越细

把这些材料放在一起以后，会出现一个很有意思的思想史轮廓。

心论系统提供一套简单模型：

天眼耳通是无记 → 不随离染而得 → 必须方便求得。

《婆沙》卷141面对更复杂的修行经验和理论问题，把模型改成：

未曾修的通由加行得；曾修的通可以由离染恢复。

于是，无记法的一般得论就出现了压力。

后来《俱舍》不得不说：

无记得通常俱起，但二通、变化是例外。

然而一旦给“通”开了这个例外，又产生新的危险：

那作为通所依、通所引的眼耳净色根，是不是也一起获得？

卷149的语言看起来一度允许这么说。

可是这样会制造新的困难：如果根已经离染得，为什么根没有现前？如果可以成就未来根，为什么眼根又被规定只能成就现在？如果过去根仍然成就，为什么修得天眼又只是暂时成就、只在使用时现前？

于是后面的理论又进一步切分：

通可以跨越其现前时刻而被成就； 根不能。

众贤最终把这个区别写成一句极其清楚的话：

天眼耳根“唯加行得，非离染得”。

从这个角度看，这不是一个孤立名相问题。

它是一个典型的理论分辨率不断提高的过程。

开始时：

“天眼”是一组大致相连的特殊能力。

后来必须分成：

通慧、净色根、眼识。

再后来又分别追问：

哪一个可以离染得？哪一个只能加行得？哪一个可以三世成就？哪一个只在现在位短暂存在？

阿毗达磨就是这样长出来的。




十二、这是不是一条严格的历史演变线？

还不能这么说。

首先，《阿毗昙心论》与《大毗婆沙》的相对年代本身就有争议；相当有力的一种研究传统认为《心论》反而是在《大毗婆沙》以后对有部教义作出的纲要化整理。

其次，我们今天所谓《大毗婆沙》也不能简单看成某一年由五百人写完、从此一字未改的一本书。对《婆沙》不同汉译本的现代比较研究指出，《毗昙婆沙论》与玄奘《大毗婆沙论》严格说并非单纯同本异译，而反映不同文本形态；毗婆沙传统长期存在修订、增补和广释过程。

因此，我们目前能说的不是：

公元某年以前有部认为A，某年以后改成B。

而是：

现存有部文献中能够识别出不同理论层次；在越来越严格的技术性文献中，根与通的得法趋向于被明确分离。

卷149可能是较宽的旧式表达。

也可能属于不同师系。

也可能是后续编纂没有完全消掉的理论残层。

甚至也可能就是一处没有办法完全会通的矛盾。

目前证据还不能在这四种可能中作唯一选择。




十三、《心论》系统应该算哪一级文献？

如果以研究“有部最后的迦湿弥罗技术体系”为目的，我不会把《阿毗昙心论》《心论经》《杂心论》与《发智》《六足》《婆沙》《俱舍》《顺正理》完全放在同一级。

《发智》《六足》是根本阿毗达磨材料；《婆沙》是毗婆沙传统自身的大型解释与裁决；《俱舍》《顺正理》《显宗》则是印度内部直接对这一体系进行再组织、争辩和系统化的核心文本。

心论系统更适合称为：

印度有部内部的一级思想史证据，但不是判断迦湿弥罗毗婆沙技术细节时的最高裁决文献。

这和汉地《光记》《宝疏》完全不同。

后者可以帮助我们了解唐代以后怎样理解《俱舍》，但原则上不能拿后人的解释去裁决印度一级文献之间本来存在的冲突。

而心论系统虽然“权威等级”不等同《发智—婆沙》，它本身就是印度有部真实思想传统的一部分，所以在研究：

“这个理论怎么变化的？”

时，它的价值反而非常高。

它不是裁判。

它是化石。




十四、结论

现在，我们可以把答案压缩成两个层次。

就体系性的教义判断而言：

成就第四静虑，并不必然成就第四静虑眼。

欲界有情离第三静虑染、第九解脱道初得第四静虑时，依《婆沙》卷150、153、156、157、195以及众贤体系，此刹那不成就第四静虑修得天眼根。他可以由离染得到曾修的第四静虑天眼通，但天眼根本身唯依加行实际引起，且只在发挥作用时暂时成就。

就文献史而言：

“眼耳二根是否有离染得”在现存有部资料里并非从来没有裂缝。

《婆沙》卷149明确留下了“眼耳二根有加行得、离染得”的字面判断。它无法轻率删除。

但它同时受到《婆沙》自身更严格的多重材料限制：眼根只成就现在，修得天眼无彼同分、要于用时乃现前，天眼天耳广设加行而暂时成就；众贤最终则直接说“唯加行得，非离染得”。

因此，最贴近全部材料的表述不是：

“卷149错了。”

也不是：

“天眼根其实可以离染得。”

而是：

卷149保存了一种把眼耳根与其通果系统紧密统摄的说法；随着得论越来越精细，通与根最终被拆开，离染得被保留给通，而作为无覆无记色的修得眼耳根被限制为加行现起时的暂时成就。卷149究竟代表较早层次、宽说习惯、师系差异还是未消除的矛盾，目前不能最后判死。

也许真正值得记住的，并不是“第四静虑眼到底在哪一刹那得到”。

而是这样一个阿毗达磨史的细节：

一个理论体系越追求精确，就越会被自己早期那些“差不多可以这么说”的句子追上。

于是它不得不继续切分。

从“天眼”，切出通与根；

从“得”，切出加行得与离染得；

从“成就”，切出现在、过去和未来；

从“修得”，切出修果与修本身；

最终，一个看起来只有几个字的问题，逼出了整个体系的版本历史。

这可能正是阿毗达磨最迷人的地方。
