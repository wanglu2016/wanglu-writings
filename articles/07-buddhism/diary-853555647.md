# 《俱舍》性价比超高问题大曝光

前一篇文章，《俱舍十大问题一览》中，我说，学《俱舍》一定要率先解决性价比高的问题。性价比高的问题就是那种，花一天的时间，所得比漫无目的地学一个月还多的问题。那篇文章中的第6题就是。——前提是第6题你不会，如果你已经会了，那没办法了。只有零基础或者基础比较差的情况下，才有比较大的提升空间，比较快的提升路径。
第6题其实就是《俱舍》里面的几个颂，牵涉到如下问题：
1、善等业以善等法为哪些果？
2、三世业以三世法为哪些果？
3、诸地业以诸地法为哪些果？
4、学等业以学等法为哪些果？
5、见所断等业以见所断等法为哪些果？
看了这五个题目你基本上就明白了：它们都是同一类的问题。我在“十大问题”中称它们为“因果问题”，并举了第一题作为例题。第一题如果明白了，后面四题自然不难。
——如果你现在要学习《俱舍》，但还不能独立地（也就是在不看书的情况下）把这五道题回答出来，那么，请放下手头的书，不管你有八本参考书还是五十本参考书，那些都不重要。先把这一题做了。否则，一个月之后，甚至半年一年之后，你的阿毗达磨水平可能还在原地踏步，原地踏步的表现之一就是，上面这五道题你还是一题都不会。但是，如果你现在开始读这篇文章，跟着理解上面的五道题，去CBETA上搜索文章里提到的颂并阅读相关长行，一天时间，不说完全理解，也是可以理解60%的吧。所以说，如果基础还不够好，你应该高兴，因为你有“由此虽劳少少功力，而能越渡大大问流”的方法——这句话见《俱舍》卷20，指的是“十大问题”中的第8题。但当你基础已经很好的时候，性价比超高的学习方法就不存在了。
先说第一题：1、善等业以善等法为哪些果？
首先要知道相关的术语：三性、六因、五果。——这三个术语在《俱舍术语要点一览》的《根品》部分。
三性是：善、不善、无记。
由于“无记”可以分为“有覆无记”“无覆无记”，“三性”可以分为四种：善、不善、有覆、无覆。“三性”还可以分为两种：净、染。净是：善、无覆无记。染是：不善、有覆无记。
上面关于“三性”的分别是最、最、最基本的（不是结巴，是强调），必须掌握。如果这都不知道，那就收拾书包回家吧。
来看题目：善等业以善等法为哪些果？
“善等业”，就是：善业、不善业、无记业。“善等法”，就是：善法、不善法、无记法。“等”这个字在阿毗达磨中是最常见的一个有内涵的字——其他常见的字不像它那么有内涵，也就是说，当我们看到“等”的时候，一定要知道“等”的是什么。
问“为哪些果”，首先必须知道果有哪些，这就是五果：异熟、增上、等流、士用、离系。
现在，我们拆分这道题目——两个“等”字让我们把一道题拆成三的二次方道题：
善业以善法为哪些果？善业以不善法为哪些果？善业以无记法为哪些果？不善业以善法为哪些果？不善业以不善法为哪些果？不善业以无记法为哪些果？无记业以善法为哪些果？无记业以不善法为哪些果？无记业以无记法为哪些果？
以上九道题，合起来问，就是：
善等业以善等法为哪些果？——看明白了吧？“等”就是举一反三，两个等，就是三的平方。
先看其中第一道：善业以善法为哪些果？——果一共就五种，我们把五种果依次带进来试试行不行，就知道了。首先，异熟果行不行？那肯定不行。
什么叫“异熟果”？颂曰：“异熟无记法，有情有记生。”——异熟果是无记法。那我们就知道，凡是以善法、不善法为果的，这个果肯定不能是异熟果，因为异熟果既不是善的，也不是不善的。
再看第二个：增上果行不行？——太行了。什么叫“增上果”？颂曰：“后因果异熟，前因增上果。”——如果你不懂颂，就翻到《根品》六因四缘五果那里去看长行（最简单的办法是把颂放到CBETA里面搜，一搜就出来）。“前因”什么意思？前因就是能作因。因为在介绍六因的时候，颂曰：“能作及俱有，同类与相应，遍行并异熟，许因唯六种。”——“能作”放在第一个，是最前面，所以叫“前因”。“前因增上果”就是说，能作因生的果是增上果，那么，什么叫能作因？颂曰：“除自余能作。”——除了自身，其他的法都是“能作因”。能作因要么不生果，要是生果，就是增上果。增上果的范围太广了，善法、不善法、无记法都可以是善业、不善业、无记业的增上果。
再看等流果。颂曰：“同类遍等流。”——同类、遍行因生的是等流果。——如果你不熟悉，就去看同类因、遍行因的定义。千万注意，不要去看现代解释、白话翻译，就看《俱舍》原文，看《正理》《婆沙》《显宗》，不要看别的。《光记》《宝疏》《颂疏》都不要看。
看了就知道，等流果当然是可以的。
士用果呢？士用果也可以。“俱相应士用”。离系果呢？离系果是善，善业可以证得离系，也可以。
现在，我们知道九个问题中第一个的答案了：
问：善业以善法为哪些果？答：增上果、等流果、士用果、离系果。
同样的方式考察第二问：善业以不善法为哪些果？
异熟是必须排除的，等流也不行，离系当然要排除，因为离系是善。所以，答案是：增上果、士用果。其中，士用果是可以无间生或者隔越生的。——不清楚就去看士用果的定义，千万不要靠打比方来理解士用果。“士用果”跟“人”或者“士”没关系。
第三问：善业以无记法为哪些果？异熟自然要放进来。等流反而不行。增上必须可以。士用没有问题。离系照样不行。答案是：异熟果、增上果、士用果。
现在，我们就回答了前三个问题，这三个问题合起来是：善业以善等法为哪些果？——注意，这里只有一个“等”，不像例题中有两个“等”。
这个问题的答案，就是《俱舍》里四分之一个颂：
初有四二三。
初，指的是善等业中，第一个是善业。四、二、三，就是刚才说的：善业，以善法为四种果：除了异熟；以不善法为二种果：增上、士用；以无记法为三种果：异熟、增上、士用。
“初有四二三”，就回答了前三个问题。
中间三个问题：不善业以善等法为什么果？
依此类推，答案是：中有二三四。——不善业以善法为二果：增上、士用；不善业以不善法为三果：增上、等流、士用；不善业以无记法为四果：除了离系。
注意，这里面有一个细节：不善业以无记法为等流果，这是可以的。——在我目前翻阅过的现代学术论文中，还没有见哪一篇提到这个问题讲的是对的。《佛光大辞典》“等流果”的条目错了，DDB一开始也是错的，因为是在线辞典，我给了反馈，马上修改了。千万记住：
不要以为不善业的等流果就是不善的，它也可以是无记的。
这就是我们前面说的：由于“无记”可以分为“有覆无记”“无覆无记”，所以“三性”可以分为四种：善、不善、有覆、无覆。“三性”还可以分为两种：净、染。净是：善、无覆无记。染是：不善、有覆无记。
“不善”和“有覆无记”，都是“染”。不善的等流果，不会是无覆无记，但可以是有覆无记；有覆无记的等流果，不会是无覆无记，但可以是不善。
要对此搞得更清楚一点，需要看颂：“上二界随眠，及欲身边见，彼俱痴无记，此余皆不善。”——如果暂时还不想花那么多功夫，只看《俱舍》“中有二三四，后二三三果”后面的长行就可以了。最好再看看《正理》：
“等流果者，谓见苦所断一切不善业，及见集所断遍行不善业，以欲界中身边见品诸无记法为等流故。”
——这就解释了哪些不善业以哪些无记法为等流果。
这个解释如果你是第一天学习《俱舍》，恐怕不好看懂。为什么只说“见苦所断一切”“见集所断遍行”？——这又牵涉到重要术语：四谛、见所断等、遍行惑等。见《俱舍术语要点一览》的《界品》《根品》《随眠品》。
这里没说“见灭所断”“见道所断”“修所断”不善业，以及“见集所断除遍行”的不善业，为什么？因为，身见、边见，只在“见苦所断”一部下有。——现在，又有必要引入一个概念了：三界十五部。
“三界十五部”的概念是根据“三界”“四谛”“见所断等”来的。
见所断等是：见所断、修所断、非所断。
其中，见所断又根据四谛分为四种：见苦所断、见集所断、见灭所断、见道所断。
“非所断”的不在这里边掺乎，见修所断，如果不考虑三界，是五种：见苦、见集、见灭、见道、修——所断。五部配上三界：欲界见苦所断……无色界修所断，共十五部。三五一十五。
“等流果”有个特点：颂曰：“同类遍等流。”它是同类因、遍行因所生。而同类因有个特点：颂曰：“同类因相似，自部地前生。” ——这说的是有漏同类因。它需要自部、自地、前生，才可以。
而不善业，只在欲界有——这又牵涉到《业品》《随眠品》的内容。不善业的等流果，只能在欲界。那么，欲界的有覆无记法，是什么呢？只有两种：身边见品。也就是颂曰：“及欲身边见。”
身边见，在五部中，只有见苦所断。颂曰：“谓如次具离，三二见见疑。”——我就不解释每一个颂的意思了，如果都解释，基本上这一个例题就能牵涉到《俱舍论》30%的颂了。这也是为什么说它是系统性的问题，性价比超高。读者不明白的，按图索骥，去看长行即可。
那么，只有欲界见苦所断的不善业，和见集所断的遍行不善，才能是它的遍行因或同类因。为什么要有个“见集所断遍行”？颂曰：“于见苦已断，余遍行随眠”，“见苦集所断，诸见疑相应”等。
这里说到“遍行因或同类因”，它们有什么差别呢？除了“见苦集所断，诸见疑相应”，还有一个颂：“除得余随行，亦是遍行摄。”——两种不善业：如果是欲界见苦所断贪、瞋、慢及彼相应无明诸品，这些就是同类因不是遍行因；如果是遍行心品，不善“得”也不是遍行因而是同类因。
细说起来，稍微有点复杂了。
不过，你发现没有，如果你暂时不打算搞清楚“具体哪些不善业以哪些无记法为等流果”的话，而只是记住“不善业可以以无记法为等流果”，那就完全不需要涉及上面那些内容。——记住一点，不懂的，先跳过去。先看你能看懂的。
回过头来看后三个问题：无记业以善等法为哪些果？
“后二三三果。”——无记业以善法为：增上、士用；以不善法为：增上、士用、等流；以无记法为：增上、士用、等流。——没有任何难度。唯一稍难的还是“以不善为等流”：
《俱舍》：“谓有身见、边执见品诸无记业，以诸不善为等流故。”
为什么这里把《俱舍》提出来？如果你去比较《正理》，会发现《正理》这里用的是“五部不善”。《俱舍》的“诸”就是五部，《正理》只是说得更明白：由于见苦所断下的不善也是可以用复数的，生怕有人误以为身边见只以自部不善为等流果，实际上以五部不善为等流果，为什么呢？以为它们是遍行惑，是遍行因。而在“不善业以无记法为等流果”的题目中，“不善业”是分为“遍行”和“非遍行”两类的。
上面所有这些，就是“十大问题”中的例题6：善等业以善等法为哪些果？
答：“善等于善等，初有四二三，中有二三四，后二三三果。”
同样的方式，对于后面四个例题：
2、三世业以三世法为哪些果？
3、诸地业以诸地法为哪些果？
4、学等业以学等法为哪些果？
5、见所断等业以见所断等法为哪些果？
第二题答案是：“过于三各四，现于未亦尔，现于现二果，未于未果三。”
过去业以过去法为：异熟、增上、等流、士用。
过去业以现在法为：异熟、增上、等流、士用。
过去业以未来法为：异熟、增上、等流、士用。
现在业以未来法为：异熟、增上、等流、士用。
——这些牵涉到业和法的时间顺序，过去业和过去法同在过去，只要过去法比过去业晚，就类似于现在法、未来法和过去业的关系，比较简单。同样，现在业对未来法，也是如此。这就叫：
“过于三各四，现于未亦尔。”
现在业以现在法为：增上、士用。——异熟不可以，因为异熟果必然是在因后面的，不能同时；离系更不可以，因为离系是离世，不是过去、现在、未来法。所以离系果根本不参与这个问题。等流果也不能同时。这就叫：
“现于现二果”：增上、士用。
未来业对未来法呢？多了一个异熟。——因为“现在”是一个时间点，而“过去”和“未来”都是无限的时间区间，所以现在业和现在法不存在时间上的前后，必然是同时的，但未来业和未来法，就可以存在前后关系。因此，未来业可以以未来法为异熟果。——那么，为什么不可以是等流果呢？
问得好。颂曰：“遍行与同类，二世三世三。”——遍行因和同类因，只在过去、现在世有，未来世不存在；而异熟因在未来世存在。
我们发现，这里并不是九句：没有提到现在业以过去法为什么果。——因为，果可以与因同时，可以在因之后，也可以压根不能说同时或前后（离系果），但是，绝对不存在果在因之前的情况。这就是《俱舍》说的：
“不说后业有前果者，前法定非后业果故。”
《顺正理论》这里，和《俱舍》一模一样。——既然一样，也就是说在这个问题上没有任何争议，板上钉钉的事，为什么我还要多提一嘴呢？因为今天有学者认为，《顺正理论》认为有果在因之前的，称为“逆向因果”——那个看法发表在了《哲学研究》上。随后有人写阿毗达磨的博士论文，还特意引用了。——这俩人我都认识，但认识归认识，错了归错了。
问题三：3、诸地业以诸地法为哪些果？
同地业以同地法：四果。——除了离系。事情非常清楚：离系不是任何地所系。——说到这里，又想到一个掌故，有人的阿毗达磨博士论文中，搞不清楚“在何地”和“何地系”的区别，恐怕把“系”理解成我们说的“张三系驻马店人”这种“系”了。阿毗达磨中不是这样子的：“系”表示拴住，驻马店能拴住张三，张三就是“驻马店系”，驻马店拴不住张三，张三就算在驻马店，也不是“驻马店系”。
除了那篇博论，别的学术论文中搞不清“系”和“在”的也大有人在。“系”的意思很清晰，而“在”的意思就很丰富，具体参考《大毗婆沙论》的四种在：自体在、器在、现行在、处在。——阿毗达磨的概念不是可以靠想当然理解的，都有严格的定义。一定要按照定义、按照原文来考虑问题，不要靠打比方、解说来考虑问题。
说完同地业，异地业呢？异地业以异地法为哪些果？
首先是增上、士用。——注意到没有？增上、士用这俩哥们儿哪里都有。异熟法只在自地，离系法不系于地，自然要排除的。那么等流果呢？
刚才说过，等流果是同类因和遍行因所生。同类因的话，“同类因相似，自部地前生”——这说的是有漏法，后面还有，“道展转九地，唯等胜为果”——这是无漏法。所以，对无漏业来说，要加个等流果。这就是颂：
“同地有四果，异地二或三。”
后面还有两个问题：
4、学等业以学等法为哪些果？
5、见所断等业以见所断等法为哪些果？
——限于篇幅——主要是我该吃晚饭了，就先不说了吧。其实都是类似的。前面三个问题理清楚，后面不会有什么难的。这五道题目合在一起，就是我列的“十大问题”中的第6题。
如果你在看这篇文章之前不会，能看到这里，大概是可以理解20%的，再去对照原文（再强调一遍，原文说的是奘译《俱舍论》）仔细想一想，一天的时间，搞清楚60%，应该不是很难吧？
如果在搞清楚上面这些问题之前，不按照这种方式学习《俱舍》，而是一句一句地翻译、又靠打比方来联想，别说一个月，那样学半年、一年，恐怕还是对阿毗达磨如何入门不得要领。
