# 想学好阿毗达磨，关键的素质在哪些地方？

1、

学习阿毗达磨其实要求在阿毗达磨之外的一些素质或者禀赋。比如，对证据等级的识别。你要知道《婆沙》的分量远远超过《光记》。《婆沙》《俱舍》《正理》没有而《光记》有的观点，有可能是普光自己的理解，而那种理解可能是错的。这种发挥和补充在《光记》中比比皆是，有些很好，有些未必就好。这也是我不提倡从《光记》入手学习阿毗达磨的原因。但很多人因为所在团体指定《光记》作为参考，也就主要依《光记》来学。这可能是个歧途。有人甚至连《俱舍》都看不懂，找来一些日本注疏，就觉得高大上，那是掉到坑里了还不知道。日本的快道林常是阿毗达磨学得比较好的，但他的书中仍然有些问题，而且极其不适合初学。至于现代的，可以说错误很多了。我见过一些人，因为看不懂一样东西，无法分辨对错，于是觉得很厉害。这样的学习，就近似自欺了。无论学什么，自己不骗自己，对自己诚实，可能是个首先要具备的素质。

2、

《俱舍》本身不同内容的重要性差别极大。像《世间品》就相对次要，而《定品》重要，《随眠品》难；重要是因为它在知识网络的节点上，次要是因为某个说法完全不是节点，删掉它完全不影响对整个体系的把握。而在节点上的、结构性相对强的知识，往往不易理解，这就导致很多人倾向花时间在那些琐碎的、不重要、甚至是错误的知识上。有人在群里问问题的时候，我明明知道最应该告诉他的是“这个问题不重要”，但可能因为不熟，还是会告诉他那里到底是怎么回事。这在很多时候会滋生误导。很多时候，更好的回答是：这个问题问错了；《光记》现阶段没必要看；这里你可以先不管；你应该去看某某颂和长行。——这种回复通常不会被当成好的回复，因为并没有解决提问者的问题。但很多时候，直接回答提问者的问题，恰恰是把提问者带沟里。而很多人学习阿毗达磨，不能用阿毗达磨的语言准确地表述问题，那么这种问题就无法被回答，至少无法用阿毗达磨的方式回答。面对这种问题，最好的回答可能是：你这问的就不是阿毗达磨，跟阿毗达磨没有关系。——但这可能也是最差的回答。

3、

阿毗达磨中的很多知识，其实是应当抛弃或者说扬弃的，比如讲出入息的六妙门，传统上说，注意力随着入息在体内游走，随着出息观察它的去向甚至直到天边。那是古人在没有解剖学知识下的粗糙类比，今天我们完全可以知道，入息进入肺之后，氧气氮气分离，已经无法找到一个点说那是入息所在的位置，至于出息弥散到空气中，不可能注意力聚焦在真实的【出息】上。地狱的种种分类、中有的种种特点，都是如此。它可能让你觉得有意思，但更重要的是，觉得有意思的同时，不要把那些说法太当回事。太当回事的话，可能会阻碍你了解那些说法是怎么出现的，为什么会出现。很多时候，论上留下一种说法，既不是因为它正确，也不是因为它始终是共识，可能是当年有十个不同的说法，后来持有另外九个说法的人和团体死掉了，说法没保存；你看到的是恰好保存下来的那个。甚至，有些说法保存到今天的也有五个，而你只看到了一个，就以为那是唯一的说法。

4、

【中有】在《婆沙》里留下了辩论的痕迹，让我们知道，佛陀时代【中有】到底是什么，完全没有留下足够的证据和共识；古代（《俱舍》更前）的论师还在争辩【佛到底是否说过中有】【阿含提到的中有到底是什么】，然后才是【中有的各种理解】。【六波罗蜜多】一开始不是六个，是四波罗蜜多，六个是后面的发展。《婆沙》有很多随着有部的发展发现先前的矛盾又修改内容的地方。——如果一个人学习阿毗达磨，而不能把这些层次拎清，他就很难明白自己学的东西是【一种说法】【一种观点】，他容易把那当成【一些知识】。【说法】不排斥其他说法，甚至几种相反的说法可以共存；而【知识】会排斥矛盾的知识。越学习《婆沙》，就越明白阿毗达磨的很多内容甚至几乎所有内容都是【说法】而不是【知识】。而不少阿毗达磨的学习者会把那些看成【知识】——这是极其关键的一点。后者让人没有办法学好阿毗达磨，因为在阿毗达磨内部、发展史上，本身存在极多的出入和张力。
