# 佛教和心理学能掺乎吗？

[文集首页](../../README.md) · [本类目录](../../catalog/07-buddhism.md)

作者／署名：王路  
主题：佛教与阿毗达磨  
页面时间：2023-08-18 20:01:22

我认识一些搞心理学的朋友，虽然谈不上深交，但他们大部分都有个特点：喜欢输出——有什么观点往往喜欢第一时间说出来，而且会重复地说（这和学佛的挺像），久而久之，我也就熟悉他们不同流派的一些基本观点了。

他们当中亲近佛法的人是有一些的。而我接触的学佛人，对心理学感兴趣的也不在少数。于是就经常看到，有人把心理学和佛教掺乎起来。甚至还有《佛教心理学》这种书。对此，我是什么感觉呢？觉得比《佛教量子力学》强一点吧。

我不太主张二者的掺乎。今天有个词叫“工具人”，是贬义，说不把人当人，而是当工具；我觉得，把佛教和心理学掺乎到一块儿，就容易有这种倾向：把佛教当工具。说明白一点，就是拿着佛教的只言片语，把它解释成根本不是佛教的意思，并告诉大家：看，佛教还是挺好的。——这还不如不信佛的人，不信佛的人至少不容易让别人误解佛教。

来举几个例子。

1、苦

佛教认为，世间的一切都是苦。这是佛教对世界的根本理解。佛陀所说的一切，无外乎四谛。四谛当中，首当其冲的是苦谛。虽然到了大乘佛教，又有“无量四谛”“无作四谛”的说法，但“世间是苦”这个根本认知是不可改变的。如果不接受这种认知，谈佛教的一切，无论谈得天花乱坠、旁征博引，都是错的。

把佛教和心理学掺乎到一块的人，据我的观察，很少讲到苦——或者是由于不知道，或者是由于没有认识到苦的重要，或者是有意忽略——不管怎样，不讲苦，谈佛教是谈不到点子上的。

2、爱

世间喜欢讲爱。心理学工作者尤其喜欢讲爱。我知道的一些僧侣，也喜欢讲爱。——但是，在佛教中，“爱”在90%的语境下是贬义。这90%的语境，基本上和世间讲“爱”的语境是吻合的：不仅包括男女之间的爱恋，也包括父母子女之间的关爱，对生活的热爱，对事业的追求，等等。

佛教把烦恼叫做“结”，结有九种，第一个就是“爱结”。“爱结”的意思是，“爱”是把人和人、人和事物缠绕在一起的东西。“爱”是“贪”的同义词。三界的爱，都是结。欲界的爱，属于“五下分结”；色界、无色界的爱，属于“五上分结”。

如果不把“爱”打上负面的钢印，那就不要谈佛教。否则，只能是对佛教的曲解，或者因为不了解而曲解，或者虽然了解但要随顺世间而曲解。说儒家提倡爱，仁者爱人，一点问题都没有。儒家提倡爱，很好；佛教否定爱，也很好。重要的是，得知道他们各自的观点是什么。不要把不是张三的东西说成张三的。

佛教里，的确有10%的语境下，爱是褒义词。那个语境下，“爱”等同于“信”。说到“信”，又是个扯不清的话题。信，是有特定对象的。不是说缅甸打来一通电话，你信了，“信为道源功德母”。佛教的信，指的是信四谛、三宝：信苦、信集、信灭、信道；信佛、信法、信僧。首当其冲的，是信世间是苦。对这些相信，不犹疑，是爱——“爱”只有在这种语境下，才是好的。

3、梦想

“梦想”在世间的语境下是个好词。但在佛教里是臭狗屎。所谓“远离颠倒梦想”。“梦想”是要远离的——不要做梦，要抛弃幻想，面对真实：面对世间的一切都是苦的真实。

有梦想的人是蒙昧的人，不清醒的人，不理智的人，自欺欺人的人；也是可怜的人。不过，有梦想的人一点儿也不觉得自己可怜，反倒觉得没有梦想的人可怜：人没有梦想，跟咸鱼有什么区别？在他们看来，一个个阿罗汉就是一只只晒在海滩上的咸鱼，永世不能翻身。

4、正念

“正念”的话题我好几年前就写过，而且不止一两次了。我觉得挺遗憾，学佛的人也很少搞清楚什么是正念。我曾经推广过一个冥想课程，他们给了文案后，我说，别的都挺好，但麻烦你们把“佛教里的正念”那两句删掉——佛教的正念不是这个意思，你可以讲“心理学界的正念是什么什么”，但不要说“佛教里的正念”是这些，因为还真不是。

佛教里的正念，是正当的忆念。念，就是记住。正，就是正确。严格来讲，正念是无漏的。《俱舍论》叫“七觉八道支，一向是无漏”。任何一个教正念的老师，不管他是谁，不管他来自哪国，他在讲“正念”的时候，都是没有正念的。不过，如果不抠那么严，放宽标准，把“正念”解释为“善的念”，他在讲正念的时候也可以有正念。

这不是重点。今天讲正念的很多人，基本上是在讲冥想。但是讲的冥想和佛教的冥想又不太一致。罗伯特赖特有一本书叫《洞见》，原名叫《为什么佛教是真的》，出中文版的时候，出版方请我写个书评，现在豆瓣上点赞最多的那篇就是我写的。我注意到赖特说得很好，他是真去看了原始文献，然后提出一个批评：今天的冥想老师总是让大家“停下来，闻闻玫瑰花香”，很少有人教大家“停下来，闻闻大便”。

是的，赖特抓住了重点。佛教的冥想，或者说禅观，在入门的地方，有两扇门，所谓“入修要二门，不净观息念”——一个是不净观，一个是持息念。不净观就是对治贪的，也就是对治爱，所谓“为通治四贪，且辨观骨锁”，什么叫骨锁？就是骷髅，skeleton。这是佛教冥想的第一道门。不经过这一道门，对佛教的冥想来说，就是没入门。

观察身体的冥想，佛教叫“身念住”，身念住是怎么观呢？首先是用不净的行相观。观的时候，不是想“这是手，这是脚，这是头”，而是想“这（手）是不净，这（脚）是不净，这（头）是不净……” 熟练之后，不再用不净的行相，而是用苦谛下的四行相：这是苦、这是非常、这是空、这是非我。不是要知道头是头、脚是脚，而是要知道头是苦，脚是苦，自己的身体是苦，他人的身体是苦，所有的身体是苦，世间的一切是苦。

上面这些，还不是最重要的。因为冥想本身，在佛教里面，远远没有人们以为得那么重要（虽然也不算不重要）。

冥想是有前提的，失去了前提，冥想就没有意义。但今天教冥想的人，很少去强调冥想的前提——一旦强调冥想的前提，可能会发现大家都不满足，因此也就没必要冥想了。冥想的前提是什么？所谓“将趣见谛道，应住戒勤修。闻思修所成，谓名俱义境。具身心远离，无不足大欲，谓已得未得，多求名所无……”——这篇文章里引到的颂都是《俱舍论》里的，这一段在《贤圣品》的开头。——说白了吧，如果你欠人钱没还，干的有对不起别人的事，或者是还没有放弃发财出名的想法，你还有事业要干，那么，冥想对你来说没有意义。如果你说话嘴上还带“他妈的”，冥想对你来说没有意义。如果你还没有戒掉烟和酒，冥想对你来说没有意义。

当然，不从佛教角度看，你可以赋予冥想种种意义，可以觉得冥想太有用了，太有帮助了。但最好不要把那种冥想和佛教的冥想掺乎到一起。虽然掺乎到一起的人也很多，但我们最好能知道它本来是什么。

根据佛陀的教导，真正重要的是布施与持戒。不仅重要，而且根本。安顿身心的办法，并不是在欠了一屁股烂债的时候，手机一关，躲到山居酒店里闭关去了，禅修一段时间，债主找不到人暂时消停了，他也按点儿吃饭睡觉调整得神清气爽了，于是觉得“禅修就是好”，“乔达摩教的这一套你别说还真有点儿意思”——实际上，佛教认为，这没有意义。

佛教不是教人通过盘腿坐在那儿解脱，而是教人通过约束自身的行为解脱，通过净化自己的思想解脱。净化思想不是靠闭上眼睛去冥想，或者指望发现世界上的美好，而是通过对世间是苦的体认。
