## 编排说明

原始采集包含 2,312 篇日记、43 篇长书评、24 篇长影评／剧评，共 2,379 个来源条目。合并重复与同文版本后为 2,321 篇；依作者决定排除 103 篇，形成这份 2,218 篇文集。

标题统一去掉开头的“王路：”。正文保留采集文字，未作改写；同文采用较完整版本，并保留来源和有实质差异的段落。页面显示时间可能为编辑时间。主题按内容主旨编排，跨主题文章可通过原文、推荐和长评索引交叉阅读。

长评论目录包含 40 篇书评和 24 篇影评／剧评；不含短评或评论区回复。转载文章保留原作者署名。正文已有的 AI 使用说明保持原样。

本仓库保存 90 张正文图片引用对应的本地文件（共 90 个不同文件）；另有 130 张图片仅保留在线地址。音视频及外部附件未打包。因此全文可下载，部分媒体仍依赖原网站。
